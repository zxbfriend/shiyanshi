# 补料声光报警：生产提供方确认清单

更新时间：2026-10-28
用途：供客户设备、自动化、工艺、运维和SMP实施人员确认声光设备接入依据，作为生产提供方设计、逐设备启用和验收输入。此文不表示客户已确认、接口已联通或现场验收已通过。各条未填写或未核准时保持待确认，不补默认值。

## 1. 当前证据和接入边界

客户[声光报警器接口文档](../../接口文档/中试补液/中试补液相关文件/声光报警器_REST_API接口文档.md)列有 `GET /alarmService/api/open`、`/flash`、`/close`，请求未列设备标识或参数；成功与失败示例均可能为 HTTP 200、`ResultCode=1`，以文档中的 `IsSuccess` 区分服务报告结果。文档没有说明该结果是否代表实物动作，也没有提供命令ID、幂等规则、查单或实际状态回读协议。接口版本、现场行为及安全部署方式须另行核验。

需求和原型提供了告警方式、反应器与声光设备关联及中试人工关闭入口。2026-10-28产品确认仅中试使用声光报警器，小试没有，取代原型中小试共用报警器的描述；代码中的中试范围限制尚待补齐。原系统资料中的正常启动闪烁、完成关闭、异常开启为历史参考，是否在SMP采用尚未确认，不自动启用。

SMP当前具备M07异常事实到M09规则和投递、M02受控OPEN/OFF端口及客户接口传输的代码与隔离测试。生产 `SoundAlarmDeliveryCapability`、`SoundAlarmOffCapability` **尚无已核准实现或装配**；隔离测试的 `TEST_ONLY` 能力及回环服务不能当作生产提供方或现场验收。缺少可信映射、共享聚合、命令身份和能力证据时保持阻断；声音/灯光提示不替代实际停料，声光失败不延误必要STOP，关闭报警器不消除故障、不解除停止保护或自动允许恢复。

正式边界见[M02设备适配契约](../../详细设计/02-实验室与资源管理/三类实验室设备适配契约.md)、[M09通知投递与恢复契约](../../详细设计/09-告警与通知管理/通知投递与恢复契约.md)、[M07业务观测与告警交接](../../详细设计/07-补液运行与任务执行/业务观测采样与告警交接.md)及[统一方案](../../接口文档/SMP小试二期与中试补料调度统一方案.md)。本清单不替代正式契约；各项的责任人、完成日期、文档版本和批准结果由实施时填写。

## 3. 建议客户交付材料

1. 逐设备清单和接线/部署图：实验室、反应器、培养与声光设备、共享关系、服务实例、网络位置及配置版本。
2. 带版本的绑定历史接口或可信记录说明，包括变更前后有效期、取证及历史保留方案。
3. `open/close/flash` 正式协议、错误码和回执语义、鉴权/TLS资料、限时与重试/查单能力，以及灯光、声音和状态回读说明。
4. 共享告警、人工消音、关闭范围、重响、并发和异常处理的业务规则与批准记录；正常闪烁若需启用另提供确认。
5. 异常原因与通知规则映射、生效修订、数据源UTC与历史时间口径说明、提供方部署与运维权限清单。
6. 真实设备联调授权、联系人、验收记录模板及切换回退措施。

## 4. 具备条件后执行的验收

所有测试使用明确标识的专用测试对象；以下涉及实物的步骤必须取得设备、现场条件及明确操作授权。每例记录输入身份、事件发生时间、规则修订、设备目标、投递/命令ID、服务回执、实际反馈或现场证据、处理结果和操作者。不得使用历史示例地址、时间或参数冒充核准配置。

| 验收项 | 执行与期望结果 |
|---|---|
| A01 绑定及配置 | 核验事件发生时绑定和当前绑定一致，设备、实验室和服务实例准确；解绑或更换目标、历史绑定缺失时阻断，不调用其他设备。 |
| A02 补料异常通知 | 对核准的补料异常及已启用规则，核对M07原事实→M09规则/投递→M02原命令→指定报警器的记录；分别记录服务受理与可用的实际声光证据。 |
| A03 非通知与时段 | 不通知、未启用声光、时段外、原修订缺失、非UTC或时间质量不明时按契约阻断或仅记录；不得向设备发送。 |
| A04 停料独立性 | 声光服务不可用、失败或超时的情况下，核对必要STOP和实际停料观察继续执行；声光结果不伪造停料、计量或资源释放。 |
| A05 人工关闭 | 有授权且目标明确时，核对M09-016原命令、M02调用和服务/实物结果；无权限或绑定不明时阻断；关闭不代表故障处理或安全复位。 |
| A06 共享及重响 | 多来源并发、其中一项恢复、人工关闭及随后新异常，逐条按已核准的归并、消音和重响规则核验；规则未核准时保持阻断，不以示例代替。 |
| A07 未知与重放 | 服务收到请求后响应丢失、进程重启或租约过期时，记录原身份与UNKNOWN；有核准查询/幂等时按原身份核对，无能力时不得盲目重发。 |
| A08 传输和回执 | 核对现场TLS/授权、各响应的 `IsSuccess` 与错误语义；断连、慢响应、重定向和重复调用不绕过受控入口。结果与物理动作分别留证。 |
| A09 并发与来源隔离 | 多工作器竞争同一投递只形成受控调用；其他业务来源/模板的声光投递不被补料工作器领取。 |
| A10 启用与回退 | 在核准配置、生产能力、权限及监测齐备后按设备组启用；验证停用、配置回滚和未决命令处理，保留完整原始记录。 |
