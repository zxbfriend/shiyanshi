DO 100%校准标准

通过 OPC 持续读取 DO 的瞬时 PV 值，然后计算这组数据的标准差（sd），当 sd ≤ 0.1 时，就表示信号已经稳定，可以执行校准。

1、sd≤ 0.1 稳定2min 标准差（Standard Deviation，简称 sd）

允许的最大波动范围。这个 0.1 的单位取决于传感器输出：若输出为 % 饱和度，则 sd ≤ 0.1%；若输出为 nA，则 sd ≤ 0.1 nA。

2、100%DO value：80±40nA

传感器输出的原始电流值应为 80 nA，允许波动范围为 ±40 nA，即合格区间是 40 nA ~ 120 nA。

当sd稳定后通过标签读100的值，通过标签表的162行NA_PV的那个标签拿到电流值，并通过157行SPAN_NA下发给设备

3、通过标签抓取设备温度，并将大气压和温度设法给设备

DO零点值

1、读取 SN：输入序略号，确认是哪支电极。

读取存储的零点：通过诊断接口（或 ISM 专用接口）读取该电极芯片中存储的零点值（Zero 或 Offset）。

方案A：直接查询 iSense SQL 数据库

   └── 按序列号（SN）作为索引，读取对应的零点值

2、作为初始基准写入：将这个历史零点值写入变送器的零点参数，作为本批次的起始基准。

3、重新校准（可选）：在灌注培养基后、通气前，根据实际环境执行零点校准，用本次测量的真实值覆盖历史值。

DO校准算法

1、OPC DA 读取 DO.PV 持续读取，多次抓取后计算 sd，当持续2min， sd ≤ 0.1 ，表示信号稳定，可以执行校准。

1.1. 每秒读取1次 DO.PV，存入滚动缓冲区（保留最近120秒的数据）

1.2. 每秒重新计算一次最近120秒数据的 sd

1.3. 维护一个连续达标计数器：

   ├── sd ≤ 0.1 → 计数器 +1

   └── sd > 0.1 → 计数器清零

1.4. 当计数器 ≥ 120（即连续120秒 sd 都 ≤ 0.1）→ 判定稳定


2、开始调用method_oxygen_air_cal方法进行DO100%校准


3、方法执行完之后通过诊断接口可以直接读取参数SEnSor Cur和SEnSitvty

SEnSitvty用来判断slope是否满足条件

SEnSor Cur用来判断100%DO value是否满足条件

如果满足则校准成功，记录100%DO value的值
