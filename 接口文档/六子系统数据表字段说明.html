六子系统数据表与字段说明

梳理 BGA、Osmo6060、OsmoPro、Vicell、Cedex、CedexOrder 六个实验室检测设备子系统在代码中实际读写的 MySQL 数据表及字段，并标注所属功能模块与源文件。

目录

  1. BGA — 血气分析仪子系统
  2. Osmo6060 — OSMO 6060 渗透压仪（串口）
  3. OsmoPro — OSMO Pro 渗透压仪（Socket）
  4. Vicell — Vi-CELL XR 细胞计数子系统
  5. Cedex — Cedex 生化分析子系统
  6. CedexOrder — Cedex 下单/启动辅助子系统
  7. 跨项目共享表对照

OsmoPro

OSMO Pro 渗透压仪子系统（Socket）

项目路径：SubDeviceService.OsmoPro
核心文件：OsmoProService.cs、OsmoPROSocketClient.cs
差异：无 OSMOType/串口字段；LabDeviceNo = OSMO；UI 勾选 ckbUseDB 可关闭 Order/Task 写入（结果/设备/删除始终写库）
OsmoPro 与 Osmo6060 共用 CDP_Testing_OSMO* 全套表，字段含义相同。以下仅列出与 6060 的差异点。

1. 设备注册（仅 IP/Port，无 OSMOType）

2. 订单 / 任务（_isUseDB 门控）

OsmoProService.DBInserOrder / DBLogInSample / DBStart / DBCancel（需 _isUseDB=true）· DeleteOrderRequest（始终执行）
数据表涉及字段说明
CDP_Testing_OSMOOrder全部字段同 Osmo6060order 命令写入；del_order 软删
CDP_Testing_OSMOTask全部字段同 Osmo6060log_in/start/cancel 写入（门控）
CDP_Testing_OSMOTaskDtl全部字段同 Osmo6060log_in 插入；结果回写始终执行

3. Socket 结果回写

OsmoPROSocketClient.UpdateOsmoResult
数据表字段与 6060 差异
CDP_Testing_OSMOTaskDtlOSMO, BatchID, Status, EndTime, Last_update_timeWHERE 仅用 TestingOSMOTaskID + SampleID（无 PositionNo）
CDP_BatchBatchCode, BatchID, CurrentOSMO, IsDelete同 6060
Auth_CultureCultureCode, IsDelete同 6060
CDP_Testing_OSMOTaskStatus, EndTime, Last_update_time全部样品有结果后立即关闭（无延迟）

4. 实验室设备状态 & 认证

数据表字段功能
CDP_LabDeviceLabDeviceNo(='OSMO'), DeviceStatusIsNeedLabDevice=True 时更新
Auth_UserAccount, Pwd, IsDeleteConfirm.cs 退出登录
