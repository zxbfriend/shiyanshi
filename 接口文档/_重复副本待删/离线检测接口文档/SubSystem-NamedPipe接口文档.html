SubSystem Named Pipe 接口文档

文档来源：BGAService、CedexOrderService、CedexService、OsmoSixService、ViCellService  |  生成日期：2026-06-15

1. 通信协议总览

1.1 管道地址（Pipe Name）

子系统服务类Pipe 名称启动方法
BGABGAServiceBGAServiceStartServerPipe("BGAService")
Cedex 设备配置CedexServiceCedexPipeStartServerPipe("CedexPipe")
Cedex 订单CedexOrderServiceCedexOrderPipeStartServerPipe("CedexOrderPipe")
OSMO 6060OsmoSixServiceOsmoSixPipeStartServerPipe("OsmoSixPipe")
ViCell XRViCellServiceVicellPipeStartServerPipe("VicellPipe")

客户端连接方式：使用 Windows Named Pipe，管道名即为上表中的 Pipe 名称（本地连接）。

1.2 请求报文格式

{command}|{payload}
字段类型说明
commandstring命令名称，与各 Service 中 AddProcessor 注册名一致
payloadstring业务参数；无参数时传空字符串，但 必须保留分隔符 |

示例：

log_in_check|
result|J
log_in|[{"SampleID":"S001","RackNo":"J","TubeNo":1}]
若请求不符合 command|payload 两段格式，返回 SubsystemParamsError。

1.3 响应报文格式

{CommandName}|{ErrorCode}|{ResultDataJSON}
字段类型说明
CommandNamestring回显请求命令名
ErrorCodelong（十六进制字符串）由 ErrorCodeLevel + ErrorType + SubsystemErrorNumber 拼接后转 16 进制
ResultDataJSONstring成功或失败时的附加数据 JSON；无数据时为空字符串

ErrorCode 组成：

组成部分格式说明
ErrorCodeLevel2 位十六进制SuccessLevel = 成功；ErrorLevel = 失败
ErrorType2 位十六进制通常为 SubsystemErrorType
SubsystemErrorNumber4 位十六进制具体业务错误码枚举值
后缀00000000固定填充

2. 公共响应对象 NamePipeResult

属性/字段类型说明
CommandNamestring命令名称（内部赋值，响应时回显）
ErrorLevelErrorCodeLevel错误级别（只读）
_errorCodeLevelErrorCodeLevel错误级别
_errorTypeErrorType错误类型
_subsystemErrorNumberSubsystemErrorNumber子系统错误编号
_resultDataobject附加返回数据，序列化为 JSON 写入响应第三段

构造函数：

签名说明
NamePipeResult(SubsystemErrorNumber, object resultData = null)根据 errorNumber 是否为 0 自动判定 Success/Error
NamePipeResult(ErrorCodeLevel, ErrorType, SubsystemErrorNumber, object resultData = null)完整指定各级错误信息

3.2 命令详情

log_in_check

请求log_in_check|
成功SubsystemSuccess
失败见下方常见错误码

常见失败错误码：

SubsystemErrorNumber含义
BGANotRunning设备未配置或未运行
BGADeviceException设备号/型号异常
BGAOtherSampleTesting有其他样品正在检测或测样间隔不足
BGATwoPointCheckDoing两点校准进行中或即将到期
BGATwoPointCheckMissing缺少两点校准记录
BGAOnePointCheckMissing缺少一点校准记录
BGAOnePointCheckDoing一点校准进行中
BGAFiveMintusTip5 分钟校准提示
BGASampleSended样品已发送
BGAJsonExceptionJSON 解析异常
BGASubSystemError系统异常

log_in / sendOrder / cancel / cancel_sample / result / refreshResult / queryPortName / saveDevice

命令请求格式说明
log_inlog_in|{RequestOrderModel JSON}自动填充 BGADeviceID、Mode=3、Created_by=0；TEMP 默认 33
sendOrdersendOrder|{RequestOrderModel JSON}不强制 Mode=3，会保存 Order 信息
cancelcancel|成功 SubsystemSuccess；失败 BGASubSystemError
cancel_samplecancel_sample|{sampleId}sampleId 为样品编号字符串（非 JSON）
resultresult|出参 int：最近任务 Status；0 无记录；7~14 映射为 7
refreshResultrefreshResult|"{sampleId}"Status 3/5/7 且有 SEQNo 时发送 SMP_REQ
queryPortNamequeryPortName|出参 List<string>；失败 BGAUnKownPort
saveDevicesaveDevice|{TestingBGADevice JSON}失败 BGASubDeviceMacOrIpOrDeviceNoRepeat / BGAJsonException

8. 任务状态码参考（result 接口通用）

Status含义（通用）
0无任务 / 无记录
1已创建 / 待开始
3检测中
5进行中 / 等待完成
7已完成
99已取消
各子系统对 Status 有额外映射逻辑，详见各 result 命令说明。
