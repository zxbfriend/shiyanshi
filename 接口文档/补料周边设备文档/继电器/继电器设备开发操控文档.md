# ZL6042 继电器设备开发操控文档

## 1. 历史部署参数

| 项目 | 历史值 |
|---|---|
| 程序 | `ZL6042RelayService.exe` |
| 本地 HTTP 服务 | `5028` |
| 设备 TCP 端口 | 日志显示 `4196` |
| 重连间隔常量 | `10`（程序内部值，单位需结合实现确认） |
| Socket | TCP Stream |
| 发送超时 | `3000 ms` |

设备 IP、端口和设备清单由发布包中的 `Static/Conf` 或现场配置决定；当前 release 目录缺少完整设备清单，日志中出现的地址只能作为历史运行证据。

## 2. 报文

历史配置命令（无空格十六进制字符串）展开如下：

| 操作 | 报文 |
|---|---|
| 开 | `01 05 00 10 FF 00 8D FF` |
| 关 | `01 05 00 10 00 00 CC 0F` |
| 状态查询 | `01 01 00 10 00 04 3C 0C` |

报文带 RTU 风格 CRC，通过 TCP Socket 发送。由于没有 MBAP 头，文档不将其命名为标准 Modbus TCP；最终协议名称和输出含义需以设备手册确认。

日志中的 Base64 响应：

```text
AQEBAZBI
```

解码为：

```text
01 01 01 01 90 48
```
