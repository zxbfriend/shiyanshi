# 网口梅特勒设备开发操控文档

## 1. 证据边界

当前资料中未找到独立的梅特勒 EXE、DLL、配置或运行日志。以下内容仅来自 `feed softwae/总结.txt` 中的接口地址和返回示例，不能当作完整厂商协议或生产部署结论。

## 2. 历史接口

```http
GET http://192.168.1.155/homeStatus.json
```

历史示例返回重量单位为 `kg`，重量字段是带空格的字符串：

```json
{
  "weightUnit": "kg",
  "tareUnit": "kg ",
  "netWeight": "   28.040 ",
  "tareWeight": "    0.000 ",
  "grossWeight": "   28.040 ",
  "NetDelivered": "...",
  "DInputs": "...",
  "DOutputs": "...",
  "SCALE_TYPE": "...",
  "TFTConnectionStatus": "...",
  "Current_Control_Rate": "...",
  "Flow_Target": "..."
}
```

`...` 表示总结文本未完整给出对应字段值，不是设备实际报文的省略替代品。

## 3. 采集实现建议

1. 按可配置周期发送 HTTP `GET`，不要把周期写死。
2. 设置连接、读取和整体请求超时；记录 HTTP 状态码、响应原文和请求耗时。
3. 对 `netWeight`、`tareWeight`、`grossWeight` 先 `Trim()`，再用不变文化解析 Decimal。
4. 同时保存 `weightUnit` 和 `tareUnit`，禁止默认把所有数值转换成 kg。
5. 将 `TFTConnectionStatus`、`DInputs`、`DOutputs` 等状态字段原样保存，并在手册确认后映射为业务状态。
6. 区分设备离线、HTTP 错误、JSON 错误、字段缺失和数值解析失败。
