# 外置泵设备开发操控文档（历史程序内称 BT100S）

## 1. 历史部署参数

| 项目 | 历史值 |
|---|---|
| 程序 | `ModBusPumpService.exe` |
| 串口 | `COM11` |
| 波特率 | `9600` |
| 数据位 | `8` |
| 停止位 | `1` |
| 校验位 | `Even` |
| 从站地址 | `1` |
| 本地服务端口 | `19011` |
| 轮询周期 | `1500 ms` |

## 2. 历史代码中的地址参数

| C# 调用参数 | 历史程序用途 | 程序实际编码到报文的地址字节 |
|---:|---|---|
| 十进制 `3100` | 速度 | `0C 1C` |
| 十进制 `3101` | 方向 | `0C 1D` |
| 十进制 `3102` | 运行状态 | `0C 1E` |

反编译代码写的是无 `0x` 前缀的 C# 数字字面量 `3100`、`3102`，所以程序按**十进制**传入并转换成 `0C1C`、`0C1E`。

**厂商手册核对（2026-09-06）**：本目录已有[雷弗蠕动泵通讯文档.docx](雷弗蠕动泵通讯文档.docx)。其包含 BT100S 等型号的寄存器表明确标注“地址（十进制）”，3100 为转速、3101 为方向状态、3102 为运行状态。因此该表对应的报文地址字节为 `0C 1C`、`0C 1D`、`0C 1E`，与上方历史程序地址编码一致；此前“当前目录没有泵手册”的说明已过时。

手册中 BT100S 等型号的转速寄存器值除以10为实际转速，3102 的0表示停止、1表示运行。不同系列的范围及倍率存在差异，需按现场型号、固件匹配对应表项。本次仅完成文档核对，尚未通过现场抓包或实机通信验证；历史 COM11、波特率、从站地址等不能据此视为当前部署值。

程序调用功能码 `03` 读取保持寄存器、功能码 `06` 写单个寄存器，并按 Modbus RTU CRC 生成请求。

## 3. 历史程序理论生成的请求帧

以下帧由反编译代码逐字节复算，证明“历史程序会发送什么”，**不等于已经由现场抓包确认的正确设备报文**：

```text
读取十进制 3100..3102：
01 03 0C 1C 00 03 C7 5D

速度 10.0：写十进制 3100 = 100：
01 06 0C 1C 00 64 4A B7

运行：写十进制 3102 = 1：
01 06 0C 1E 00 01 2B 5C

停止：写十进制 3102 = 0：
01 06 0C 1E 00 00 EA 9C
```

## 4. 使用边界

已提供手册的上述寄存器表采用十进制地址，不采用先前假设的 `0x3100/0x3102` 候选帧，已移除该假设分支以免混用。若现场使用不同型号或固件，应依据其对应手册重新核对寄存器、转速倍率及串口参数，再用实机读写或抓包验证。
