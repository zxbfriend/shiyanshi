1. 总体说明

SMP 系统支持两种登录方式：

  • 域账号登录（AAD / SAML）：默认模式，用户点击登录后跳转 Microsoft Azure AD 完成身份认证。
  • 本地账号登录：用户在登录页切换后，使用账号密码调用 api/auth/login。

AAD 登录采用 SAML 2.0 协议，后端使用 AspNetSaml 组件（命名空间 Saml）生成 SAML Request、解析 SAML Response。 认证成功后，系统不会直接把 Azure 用户信息写入 Session，而是：

  1. 从 SAML Response 中提取用户 Email；
  2. 用 Email 匹配本地 Auth_User 表；
  3. 生成本系统 JWT Token，写入前端 localStorage，后续 API 通过 Authorization 请求头鉴权。

配置注意： AuthController 读取的是 ida:RedirectUri，而 Web.config 当前写的是 RedirectUri（无 ida: 前缀）。 若运行时 redirectUri 为空，SAML Request 中的 AssertionConsumerServiceURL 可能不正确。建议统一 Key 名称。

3. 完整调用流程

[1] 用户打开 /WuXiBio/login ↓ [2] 默认显示 AAD 登录按钮（IsLocalLogin = false） ↓ 点击「登录」 [3] 前端 loginController.aad() → GET api/auth/aad-url ↓ [4] 后端 AuthController.Privacy() → AuthRequest.GetRedirectUrl(authority) → 返回 Azure AD SAML 登录 URL ↓ [5] 浏览器跳转到 Azure AD（ida:Authority） ↓ 用户输入域账号密码 / MFA [6] Azure AD POST SAMLResponse → api/auth/callbacksaml （RedirectUri） ↓ [7] 后端 AuthController.ADDCallback() → Response(samlCertificate, SAMLResponse).GetEmail() → Redirect WebIndex?code={加密email} ↓ [8] 前端 /WuXiBio/loading?code=xxx → loadingPageController.init() → GET api/auth/user-login?code=xxx ↓ [9] 后端 AuthController.UserLoginExt(code) → GetByEmail(解密code) → 加载模块树、生成 JWT、写登录日志 ↓ [10] 前端写入 localStorage（loginUser / authorizationData / ModuleSetting） → 跳转 /WuXiBio/home/dataManage/setting/project

[Route("aad-url"), HttpGet, AllowAnonymous]
public IHttpActionResult Privacy()
{
    try
    {
        AuthRequest authRequest = new AuthRequest(clientId, redirectUri);
        string samlRedirectUrl = authRequest.GetRedirectUrl(authority);
        _logger.Info($"aad-url:{samlRedirectUrl}");
        var response = Ok(new BaseResponse<string>
        {
            Data = samlRedirectUrl
        });
        return response;
    }
    catch (Exception ex)
    {
        throw;
    }
}

5.3 SAML 回调 — ADDCallback() / api/auth/callbacksaml

[Route("callbacksaml"), HttpPost, AllowAnonymous]
public RedirectResult ADDCallback()
{
    string responseString = HttpContext.Current.Request.Form["SAMLResponse"];
    _logger.Info($"callbacksaml:{responseString}");
    string email = new Response(samlCertificate, responseString).GetEmail();
    return Redirect(webIndex + "?code=" + SecurityHelper.Encryption(email).Replace("+", "¤"));
}

5.4 域账号换取系统登录态 — UserLoginExt() / api/auth/user-login

[Route("user-login"), HttpGet, AllowAnonymous]
public async Task<IHttpActionResult> UserLoginExt(string code)
{
    BaseResponse<User> response = new BaseResponse<User>() { IsSuccess = false, ResultCode = 0 };
    try
    {
        var user = _userService.GetByEmail(SecurityHelper.Decrypt(code)).Data;
        if (user == null)
        {
            response.ResultMessageCode = EnumMsgCode.SE500001.ToString();
            return Ok(response);
        }

        var roleInfo = _roleService.GetRole(user.UserId).Data;
        if (roleInfo != null && !roleInfo.Status)
        {
            response.ResultMessageCode = EnumMsgCode.SE500102.ToString();
            return Ok(response);
        }

        var ipAddress = Request.GetClientIpAddress();
        if (ipAddress.Equals("::1")) ipAddress = Computer.IpAddress;

        user.LoginMachineId = Convert.ToInt32(SystemConstant.LABINDEX);
        LoadModuleTree(user);
        response.IsSuccess = true;
        response.ResultCode = 200;
        response.ResultMessageCode = EnumMsgCode.SE500004.ToString();
        response.Data = user;
        response.Token = GenToken(user, user.LoginMachineId);
        UserLoginHelper.SetCurrentLoginMac(user.UserId, ipAddress);
        try
        {
            var userLoginLog = new UserLoginLog()
            {
                UserId = user.UserId,
                LoginTime = DateTime.Now,
                LoginIP = Request.GetClientIpAddress(),
                Browser = Request.GetUserAagent(),
                PCName = Request.GetClientPCName(),
                MAC = "00:00:00:00:00:00",
                OS = Request.GetOSVersion(),
            };
            _roleService.SaveUserLoginLog(userLoginLog);
        }
        catch (Exception ex)
        {
            response.ResultCode = -1;
            response.ResultMessageCode = EnumMsgCode.SE500104.ToString();
            _logger.Error("Sign Log", ex);
        }
        response.IsSuccess = true;
        response.ResultCode = 1;
    }
    catch (Exception ex)
    {
        _logger.Error("Login", ex);
        throw ex;
    }
    return Ok(response);
}

5.5 JWT 生成 — GenToken()

private static string GenToken(User user, int machineId)
{
    var jwtcreated =
       Math.Round((DateTime.UtcNow - new DateTime(1970, 1, 1, 0, 0, 0, DateTimeKind.Utc)).TotalSeconds + 5);
    var payload = new Dictionary<string, dynamic>
        {
            {"iat", jwtcreated},
            {"userId", user.UserId},
            {"machineId", machineId}
        };
    return JWT.JsonWebToken.Encode(payload, Constants.SecretKey,
        JWT.JwtHashAlgorithm.HS256);
}

private void LoadModuleTree(User user)

}

7. 注意事项

  • 用户映射规则：AAD 登录依赖 SAML 中的 Email 与本地 Auth_User.Email 精确匹配；若 Azure 返回的邮箱在系统中不存在，会返回 SE500001。
  • callbacksaml 不由前端直接调用：该接口由 Azure AD 服务器 POST 表单触发，前端 authRes.callbacksaml 仅作资源定义，实际流程是浏览器被 302 重定向到 WebIndex。
  • Token 鉴权：登录成功后 JWT 存入 localStorage.authorizationData，后续请求由 JWTAuth 过滤器校验。
  • 本地登录切换：登录页默认 IsLocalLogin=false，即默认走 AAD；点击底部链接可切换到本地账号登录。
  • IsSpecialCultureTest：当前代码库中仅定义于 SystemConstant，与 AAD SAML 主链路无直接调用关系。
  • 第三方依赖：SAML 处理依赖 NuGet 包 AspNetSaml 2.1.3（AspNetSaml.dll，命名空间 Saml）。
