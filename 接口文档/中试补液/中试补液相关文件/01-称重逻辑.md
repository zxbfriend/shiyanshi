# 称重逻辑

## 1. 入口与数据来源

页面位置：`NPPGUI/views/downBio/dashboard/dashboard.html` 的 Weigh 区域。

前端控制器：`dashboardController.js`。

设备列表：

```js
$scope.scaleList = await getEquipmentListByType(1);
```

称重操作统一进入：

```js
$scope.testingdtl(item, key, type, CancelResult)
```

后端统一入口：

```csharp
DashboardService.InsertPreBatchTestingDtl(OperationDetailRequest request, int userId, string ip)
```

数据主要落在：

- `CDP_PreBatch_TestingWeight`
- `CDP_PreBatch_TestingRecord`
- 称重采集归档通过 `_scaleDataService.SaveScaleData(...)`

## 2. 测试项映射

| 前端 key | TestItem | 含义 | 页面操作 |
| --- | ---: | --- | --- |
| `TareWeight` | 1 | 皮重 | Capture / Cancel |
| `RoughWeightBefore` | 3 | 取样前毛重 | Capture / Cancel |
| `NetWeightBefore` | 5 | 取样前净重 | Capture / Calculate / Cancel |
| `RoughWeightAfter` | 7 | 取样后毛重 | Capture / Cancel |
| `NetWeightAfter` | 9 | 取样后净重 | Capture / Calculate / Cancel |

## 3. 操作类型

| OperationType | 含义 | 说明 |
| ---: | --- | --- |
| 1 | Capture | 从秤采集重量 |
| 5 | Cancel | 撤销当前字段结果 |
| 7 | CALC | 计算净重，只允许净重字段使用 |

前端校验：

- Capture 时必须选择秤。
- Capture 时必须满足设备校准标记。
- Calculate 时前端会清空设备字段，并把校准标记置为 `true`，实际计算由后端完成。

## 4. Capture 采集逻辑

后端流程：

1. 查询当前 `PreBatchTestingID` 对应样本。
2. 查询或创建 `CDP_PreBatch_TestingWeight`。
3. 对称重测试项调用 `_deviceApiService.GetWeight(...)`。
4. 得到 `Weight` 和 `WeightUnit`。
5. 写入 `CDP_PreBatch_TestingRecord`。
6. 调用 `SetPreBatchTestingWeight(...)` 写入对应称重字段。
7. 写入称重归档数据 `ScaleSaveDataModel`。

采集记录值格式：

```text
Value = request.Value + unit
```

例如：

```text
5.12g
0.005kg
```

## 5. 净重计算逻辑

只允许以下两类计算：

- `NetWeightBefore`
- `NetWeightAfter`

后端限制：

```text
NetWeightBefore 需要已有 TareWeight 和 RoughWeightBefore
NetWeightAfter  需要已有 TareWeight 和 RoughWeightAfter
```

业务公式：

```text
取样前净重 = 取样前毛重 - 皮重
取样后净重 = 取样后毛重 - 皮重
```

单位处理：

| 情况 | 处理 |
| --- | --- |
| 皮重单位和毛重单位一致 | 直接相减，结果沿用皮重单位 |
| 单位不一致，某一方为 `kg` | 先把 `kg` 换算为 `g`，再相减 |
| 单位不一致 | 结果单位为 `g` |

核心函数：

```csharp
private decimal? CaculateWeight(decimal? roughWeight, decimal? tareWeight, string roughWeightUnit, string tareWeightUnit)
```

逻辑等价于：

```text
if tareWeightUnit != roughWeightUnit and tareWeightUnit == kg:
    tareWeight = tareWeight * 1000

if tareWeightUnit != roughWeightUnit and roughWeightUnit == kg:
    roughWeight = roughWeight * 1000

netWeight = roughWeight - tareWeight
```

显示字符串通过：

```csharp
ConvertNetWeight(string roughWeight, string tareWeight, string roughWeightUnit, string tareWeightUnit)
```

该方法会保留两边输入小数位中较大的精度。

## 7. 撤销逻辑

撤销时：

1. 前端弹出撤销原因对话框。
2. 请求仍进入 `InsertPreBatchTestingDtl`，`OperationType = 5`。
3. 后端写入 `CDP_PreBatch_TestingRecord`，记录撤销原因。
4. `SetPreBatchTestingWeight(...)` 对应字段传入 `null`，清除当前称重项数据。

## 8. 已知注意点

`InsertPreBatchTestingDtl` 中计算操作记录 `Value` 时，部分分支使用 `GetWeightByPrecision(weightBefore, weightAfter, place)`，该方法内部是：

```csharp
return Math.Round(Convert.ToDecimal(weightAfter - weightBefore), place, MidpointRounding.AwayFromZero);
```

但实际落到称重字段时，又通过 `CaculateWeight` 和 `ConvertNetWeight` 重新计算为 `毛重 - 皮重`。因此如果排查操作记录中的 `Value` 与字段值不一致，应重点核对这段记录值计算方向。
