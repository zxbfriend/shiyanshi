TaskQueue 自动取测与自动补料

基于 TaskQueueService.cs 整理创建任务时的入参、出参及落库表字段。

1. 操作类型

OPIDCode名称说明
1SAMPLINGTEST自动取测机器人取样 + BGA/Vicell/OSMO/Cedex 等检测
2FEEDING自动补料POSITION1/2/3 三位置补料，含体积与泵速

创建后 Mode = Auto(3)，Status = Pending(1)，由外部 Core Service 拾取执行。

2. 创建流程

POST api/taskQueue/add-taskqueue
校验反应器 / 接种状态 →（补料）校验补料单元连接 → 时间区间校验 → GetBatchOPRequestListByRequestRule（Rule/Interval 展开多条）→ （取测）ConsumableCalCulation 耗材预估 → 逐条 AddTaskQueueAndSpeed → InsertTaskQueueAndSpeedEntitys 落库

保存前可先调 POST api/taskQueue/check-taskqueue 做当日重复检测/补料预警。

3. 请求入参 BatchOPRequest

字段类型必填说明
LabDeviceIDListList<int>是所选反应器 LabDeviceID 列表
OPIDint是1=自动取测，2=自动补料
LabIdint是实验室 ID
batchOPSubModelListList<OPSubModel>是子操作及参数，见下节
StartDate / EndDateDateTime?Rule/Interval 时规则起止日期
ExecuteTimestringRule 时每日执行时刻，如 08:00:00
IntervalintInterval 时间隔分钟数
IsAddbool?校验用check-taskqueue 时区分新增/编辑
TaskQueueID / BatchOPIDint?编辑时仅 edit-taskqueue 使用

3.1 子操作 OPSubModel

字段说明
OPSubID / OPSubCode / OPSubName子操作标识（来自 OP 模板）
isCheck是否勾选；落库为 CDP_Batch_OP_Sub.Value
oPParameterList该子操作下的参数列表

3.2 参数 OPParameter（oPParameterList 元素）

字段说明
OPParameterID / ParameterID参数定义 ID
Name参数名（如 TESTINGTIME、FEEDINGVOLUME、DILUTIONFACTOR）
Value参数值，写入 CDP_Batch_OP_ParameterValue.Value
oPParameterSubListCedex 分析项勾选，写入 ParameterSubValue 表

4. 自动取测（OPID=1）子项与参数

OPSubCode含义常见参数
TESTINGRULE检测规则（常勾选）TESTINGTYPE / RULETYPE（Now/Timing/Rule/Interval）、TESTINGTIME（ParameterID=43）
BGABGA 检测取样体积等
VICELLVicell 检测DILUTIONFACTOR 等
OSMO渗透压检测取样体积等
CEDEXCedex 检测分析项在 oPParameterSubList；限值 TopValue/BottomValue
RESERVEDSAMPLE留样体积；前端保存前 ×1000（μL）
RESERVEDSAMPLEHARVEST收获留样（灌流）同上 ×1000

自动取测除 TESTINGRULE 外至少勾选一个检测子项。GLLY（OPSubID=36）仅灌流培养才写入。

5. 自动补料（OPID=2）子项与参数

OPSubCodeOPSubID含义常见参数
POSITION15补料位 1FEEDINGNAME（物料编码，可自动从大液瓶带出）、FEEDINGVOLUME、POSITION1FEEDINGSPEED
POSITION26补料位 2同上
POSITION37补料位 3同上

落库前服务会：按反应器查大液瓶信息填充 FEEDINGNAME；泵速为空时从 CDP_Workflow_BatchSupplyConnectionDtl 或配置默认值补齐；并写入 Auth_UserFeedingSpeedSetting 记录用户泵速偏好。

创建前 Controller 会调用 CheckSupplementaryConnection 校验补料单元连接。

6. 规则展开 GetBatchOPRequestListByRequestRule

场景条件结果
单次无 Rule/Interval原请求 1 条
Rule 每日StartDate + EndDate + ExecuteTime按天复制多条，TESTINGTIME = 日期 + ExecuteTime，类型强制 Timing
IntervalStartDate + EndDate + Interval>0按间隔分钟复制多条，TESTINGTIME 递增

入参：BatchOPRequest；出参：BaseResponse<List<BatchOPRequest>>，Data 为展开后的请求列表。

7. 校验 CheckTaskQueue

入参：BatchOPRequest（同创建）。出参：BaseResponse。

场景逻辑失败码
取测 + Now当日同批次 BGA/OSMO/CEDEX/VICELL 是否已有结果SE5004817（ResultCode=-1，带 msg）
取测 OPID=1所选反应器当日是否已有同 OP 任务SE5004817
补料 OPID=2所选反应器当日是否已补过相同液体SE5004817

ResultCode=1 或默认表示通过（仅预警时 ResultCode=-1）。

8. 耗材计算 ConsumableCalCulation（仅取测）

入参：labId。出参：BaseResponse，库存不足时 IsSuccess=false。

读取未执行 TaskQueue + Batch_OP，结合子项 BGA/VICELL/OSMO/CEDEX/RESERVEDSAMPLE 及 LoadSample 未完成记录，对比仓库 EP 管、Tip、Vicell 杯、Osmo 杯、Cedex 杯库存。补料（OPID=2）不走此步骤。

9. 创建核心 AddTaskQueueAndSpeed

入参

参数类型说明
requestBatchOPRequest单条（已展开）请求
userIDint当前用户

内部根据 LabDeviceIDList 关联查询：

  • CDP_Batch + CDP_Location_Combinations + CDP_LabDevice
  • 条件：反应器在列表中、批次未完成（Status < Completed）、未删除
  • 每个反应器生成一条 BatchOPModelRequest（含 BatchID、LabId、ReactorID、OPID、子项列表）

出参

BaseResponse：ResultCode>0 成功；0 反应器无有效批次（SE500230）；-1 异常（SE500030）。

13. 取测 vs 补料差异

项目自动取测 OPID=1自动补料 OPID=2
子项TESTINGRULE + BGA/VICELL/OSMO/CEDEX/留样POSITION1/2/3
耗材校验有（ConsumableCalCulation）无
连接校验无CheckSupplementaryConnection
泵速记忆无Auth_UserFeedingSpeedSetting
物料名自动填充无FEEDINGNAME 从大液瓶
执行结果表CDP_Testing_* 检测任务CDP_Batch_OP_Exec 实际补料量
