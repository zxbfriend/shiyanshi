SLMS Workflow 各步骤 · 表 / 字段操作说明

前端目录：app/views/bio/dashboard/workflow； 后端：WorkflowController + WorkflowService。 下文按页面步骤列出对数据库表字段的 INSERT / UPDATE / 软删操作。

总览与状态流转

Workflow 为左侧导航自由选择（非强制线性向导）。核心枢纽是 CDP_Workflow，培养生命周期落在 CDP_Batch.Status。

1 Start BatchWorkflowType=1 · 建批并启动培养
2 InoculationWorkflowType=3 · 接种
3 Feeding Unit ConnectionWorkflowType=5 · 补料单元连接
4 Feeding (Other)WorkflowType=17 · 其他补料
5 Feeding (Manual)WorkflowType=19 · 手动补料
6 Sampling (Manual)WorkflowType=21 · 手动取样
7 Supply Liquid SamplingWorkflowType=7 · 取样单元换液
8 Supply Liquid FeedingWorkflowType=9 · 补料单元换液
9 Waste CleanWorkflowType=11 · 废液清理
10 Material ImportWorkflowType=13 · 物料导入
11 Complete BatchWorkflowType=15 · 结束培养

CDP_Batch.Status 主线

1 New → 4 DisinfectantFill → 5 StartBatch → 7 Inoculation → 9 Producting → 10 Harvesting → 11 Completed  |  99 Canceled
体积约定：前端多为升(L)，入库时通常 ×1000 存为毫升。
流程约定：Start 插入 CDP_Workflow（+ 子表）；Finish 写 Creation_FinishBy / Creation_FinishTime；Cancel 多为 IsDelete=true + 子表 Status=99（物料导入例外）。

公共表约定

表关键字段说明
CDP_Workflow WorkflowType, UserID, LocCombinationID, Created_by, Creation_time, Creation_FinishBy, Creation_FinishTime, IsDelete, IsSatellite 所有步骤的流程主表
CDP_Batch Status, CurrentVolume, StartBatch*, Inoculation*, Supplementary*, Complete*, Cancel* 培养批次生命周期
CDP_Item_Serials Quantity, ItemStatus, BatchId, ItemSerialNumber 库存条码；Finish 时常经 WarehouseService 插入/替换/退役
CDP_Location_Combinations / CDP_Location_Controls / CDP_LabDeviceSub Status, ItemDefID, Speed 等 工位、控件、泵子设备配置
ItemStatus 常见值：0 在用空闲 · 2 反应器已绑定 · 28 已替换下架 · 30 培养结束后退役
旁路服务：_taskQueueService.InsertTaskQueueEntitys 写操作 OP；硬件泵/消毒/冲洗多走 CoreService，不直接写业务主表。

1. Start Batch

WorkflowType = 1 页面：startBatch/ · 服务：SaveWorkflow / AddStartBatch / SetBatchStatus / FinishStartBatch / CancelStartBatch / LastStep

选择反应器工位，建批次、扫条码、消毒/冲洗确认后正式启动培养。

Start — 创建流程壳

表操作字段说明
CDP_Workflow INSERT WorkflowType=1, UserID, LocCombinationID, Created_by, Creation_time=now, IsDelete=false 完成字段为空

Mid — 添加批次 AddStartBatch

表操作字段说明
CDP_Workflow UPDATE IsSatellite 是否卫星批
CDP_Batch INSERT WorkflowID, LocCombinationID, ReactorSerialNo(=Barcode), BatchCode, BatchName, MediumVolume/CurrentVolume=Volume×1000, MediumLotNo, MediumName, MediumTemp, StartTime=now, Status=1, StartBatchTime, StartBatchUser, ProjectID, PreBatchID, CultureID, RefillVolume/RefillVolumeAtf×1000 草稿批次
CDP_Workflow_PerfusionSure INSERT ATFStatus, ScaleStatus, BasicMediumStatus, ControllerStatus, ATFControlStatus, ReactorStatus, ATFPillarStatus, PumpStatus, CreateTime 灌注确认项（若适用）

Mid — 消毒管线 SetBatchStatus

表操作字段说明
CDP_Batch UPDATE Status=4 (DisinfectantPipelineFilling) 进入消毒管线灌充阶段

Finish — FinishStartBatch

表操作字段说明
CDP_Workflow UPDATE Creation_FinishBy, Creation_FinishTime=now 关闭流程
CDP_Batch UPDATE StartBatchTime, StartBatchUser, Status=5 (StartBatch) 正式启动培养
CDP_StartQueue UPDATE BatchID, Status=3 若存在 Status=1 的设备排队
CDP_Item_Serials INSERT 反应器: ItemStatus=2, Quantity=Medium+Cells, BatchId；取样/补料桶: ItemStatus=0 经 WarehouseService.InsertStartBatchItemSerials
Batch OP / TaskQueue INSERT OP=CULTUREFLUIDFILLING, Mode=5, Status=5 + MEDIUM* 参数 经 taskQueueService
Finish 后调用 EnvRecHelper.StartCultureLabDevice() 刷新环控采集设备列表。

Cancel / LastStep

表操作字段说明
CDP_Workflow SOFT DEL IsDelete=true CancelStartBatch
CDP_Batch UPDATE Status=99, CancelUser, CancelTime, CancelDescription Cancel / LastStep

2. Inoculation

WorkflowType = 3 页面：inoculation/ · 前提批次 Status=5 · 子表 Status：1接种 / 2手动填参 / 3完成 / 99取消

Start — AddInoculationWorkflow

表操作字段说明
CDP_Workflow INSERT WorkflowType=3, UserID, LocCombinationID, Created_by, Creation_time
CDP_Workflow_BatchInoculation INSERT BatchID, Status=1, CellsVolume=0

Mid — NextInoculationBatchInfo

表操作字段说明
CDP_Workflow_BatchInoculation UPDATE CellType, CellsVolume×1000, SampleID, InitialVCD, InitialViablity, AvgDiam, InitialCellLotNo, TargetViableCellNumber, Status=2, DisChargeStatus, DisChargeVolume 保存手动接种参数

Finish — FinishBatchInoculation

表操作字段说明
CDP_Batch UPDATE CellType, CellsVolume×1000, CurrentVolume += Cells−Discharge, CurrentVCD, CurrentViability, InitialViableCellNumber, Status=9（若已有 SupplementaryUser）否则 Status=7, InoculationTime, InoculationUser
CDP_Item_Serials UPDATE Quantity += CellsVolume − DisChargeVolume×1000 反应器序列号体积
CDP_Workflow UPDATE Creation_FinishBy, Creation_FinishTime
CDP_Workflow_BatchInoculation UPDATE PipeInstallationStatus, SoftwareStatus, Status=3
CDP_Testing_BGATask UPDATE SampleID（特殊 culture 时） 可选
Batch OP INSERT OP=INOCULATION, Mode=5, Status=5 taskQueue

Cancel

表操作字段说明
CDP_Workflow SOFT DEL IsDelete=true
CDP_Workflow_BatchInoculation UPDATE Status=99（原 Status<3）

3. Feeding Unit Connection

WorkflowType = 5 页面：supplementaryConnection/ · 子表 Status：1连接中 / 2补料单元连接 / 3完成 / 99取消

Start — AddSpplyConnectionWorkflow

表操作字段说明
CDP_Workflow INSERT WorkflowType=5, UserID, LocCombinationID, Created_by, Creation_time
CDP_Workflow_BatchSupplyConnection INSERT BatchID, Status=1

Mid — NextFeedingConnectionDtl / SetSupplyConnectionStatus

表操作字段说明
CDP_Location_Combinations UPDATE Status, Last_updated_by, Last_update_time
CDP_Location_Controls UPDATE ControlType=1: Status + ItemDefID；ControlType=3: ItemDefID=携带物料 + 审计字段 液体/瓶控件
CDP_LabDeviceSub UPDATE Status, 默认/最大速度（按 Fluid ItemDefID）, 审计字段 泵子设备
CDP_Workflow_BatchSupplyConnection UPDATE Status=2, MultiFeedStatus, VesselWeightStatus, HarvestPumpStatus
CDP_Workflow_BatchSupplyConnectionDtl INSERT BatchID, LabDeviceID, LocCombinationID, Volume, Speed, LocationNo, Unit (+PumpNo/ItemDefId) 连接明细

Finish — FinishBatchSupplyConnection

表操作字段说明
CDP_Workflow UPDATE Creation_FinishBy, Creation_FinishTime
CDP_Workflow_BatchSupplyConnection UPDATE Status=3
CDP_Batch UPDATE 若 Status==7 → Status=9 + SupplementaryUser/Time；否则只写 SupplementaryUser/Time
CDP_Item_Serials INSERT 补料桶序列号 Warehouse.InsertSupplementaryConnectionItemSerials

Cancel

表操作字段说明
CDP_Workflow SOFT DEL IsDelete=true
CDP_Workflow_BatchSupplyConnection UPDATE Status=99
中间还有泵启停（start-pumping / abort-pumping），主要走 CoreService / PumpingService，业务表以事件为主。

11. Complete Batch

WorkflowType = 15 页面：completeBatch/ · UI 含消毒 / 冲洗 / 取样子步骤

Start — AddBatchCompleteWorkflow

表操作字段
CDP_Workflow INSERT WorkflowType=15, UserID, LocCombinationID, Created_by, Creation_time
CDP_Workflow_BatchComplete INSERT BatchID, Status=1, ItemID(=反应器序列号)
CDP_Batch UPDATE Status=10 (Harvesting)

Finish — FinishBatchCompleteWorkflow

表操作字段说明
CDP_Batch UPDATE EndTime, Status=11, CompleteTime, CompleteUser, LastPH / LastDO / LastOxygenFlowRate / LastTemp / LastStirrer（来自 EnvRec）
CDP_Workflow UPDATE Creation_FinishBy, Creation_FinishTime
CDP_Workflow_BatchComplete UPDATE Status=3
CDP_Item_Serials UPDATE 批次相关 ItemDefID≠10,12 且 Status≠28 → ItemStatus=30 + 审计 退役库存
CDP_Location_Combinations UPDATE Status=true 仅 LABINDEX=2（二期）
CDP_LabDeviceSub UPDATE Status=true 仅二期
CDP_Location_Controls UPDATE Status=true；ControlType=1 时 ItemDefID=19 仅二期重置控件
Finish 后：EnvRecHelper.StartCultureLabDevice() 刷新列表；Controller 侧清空 _envStartCultureLabDevices，并 SaveIotDataProcessing。 中间消毒/冲洗/取样走 CoreService / Sampling API / 硬件电磁阀。

Cancel — CancelBatchCompleteWorkflow

表操作字段
CDP_Workflow SOFT DEL IsDelete=true
CDP_Workflow_BatchComplete UPDATE Status=99
CDP_Batch UPDATE Status=9 (Producting) 回退
