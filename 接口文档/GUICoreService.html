GUI 与 CoreService 协作说明（留用表字段）

面向网站重做、CoreService 不动的场景。按三块说明：谁调谁、控什么设备、何时动哪些表字段。

一、Workflow 二、手动取样 / 补料 三、自动取测 + LoadSample 四、建议留用表清单
分工总原则
  • 网站：业务落库（批次、工序、ManualOP、TaskQueue、LoadSample）、权限校验、列表展示；部分 Workflow 场景在调 Core 之前就写好库存。
  • Core：驱动生物反应器 / 补料泵 / 取样冲洗消毒动作 / 流体工作站；通过 PumpIn/PumpOut 直接改 CDP_Item_Serials.Quantity；自动取测拾取 Pending 任务并写检测相关状态；结束后 HTTP 回调网站记过程。

一、Workflow（入口 WorkflowController）

入口：api/workflow/*。以下只列会调用 CoreService的步骤；大量接种/连接/物料等纯网站落库步骤不展开。

1.1 调用总览

网站 API Core URL 设备 / 动作 Core 回调网站
GET get-machine-mode mode/query 无硬件，查 Auto/Manual —
POST finish-start-batch workflow/start_batch?action=finish&batchids= 无泵动作；Core 把批次登记进内存 BatchManager —
POST start-pumping（预填充补料） workflow/filling?action=start_pumping&… 生物反应器补料泵 PUMP_LIQUID POST /api/workflow/get-prefeeding-result

1.2 分步骤：网站 vs Core、表字段时机

① 查机器模式

方做什么表 / 字段
网站调 Core，把 Auto→3 / Manual→1 返回前端不写库
Core读 WorkModeManager 当前模式不写库

② 完成开批 finish-start-batch

时机方表.字段 / 动作
调 Core 之前网站 CDP_Workflow：Creation_FinishBy / Creation_FinishTime
CDP_Batch：StartBatchTime / StartBatchUser / Status→开批
CDP_StartQueue：绑定 BatchID、Status
插入培养液填充相关 TaskQueue / Batch_OP
CDP_Item_Serials INSERT：反应器 Quantity = MediumVolume + CellsVolume，ItemStatus=2；取样单元桶 Quantity=容量（废液可为 0）
调 CoreCore读 CDP_Batch（BatchCode、ReactorSerialNo 等），写入内存 BatchManager。不改 Quantity。
Core 失败网站返回错误；前面已提交的库不会回滚

③ 预填充补料 start/abort-pumping（Workflow filling）

时机方内容
发指令前网站INSERT CDP_ManualOP_Rec（OperationType=9，Status=1，ExecParameters 含 speed/volume/location/item）；sourceid=ManualOPRecID
执行Core设备：反应器补料泵。轮询天平/泵状态。
结束回调网站get-prefeeding-result：ManualOP Status 1→3 或 99；EndTime、ErrorCode；写 CDP_OperateUnit_Events。不改 Quantity（weight 传入但当前未加到 Item_Serials）。
失败立即返回网站ManualOP ErrorCode/EndTime + Error Event

④ 消毒 / 冲洗预填充

步骤网站写库（发指令前）Core 设备回调后网站
消毒 start ManualOP OperationType=7 Status=1 INSIDE_STERILIZE get-disinfect-result → ManualOP 完结 + Event
冲洗预填充 start ManualOP OperationType=6 Status=1 CLEAN_OUTSIDE 本应 get-rinse-prefilling-result；Core 现误回调 get-disinfect-result
abort 失败时 ManualOP→99 ABORT_CLEARING —

⑤ 补料单元连接完成（门禁）

  • 可选：Core pumping_getinfo，若 WorkStage=Pumping 则禁止完成。
  • 通过后纯网站：CDP_Workflow 完结、CDP_Workflow_BatchSupplyConnection Status=3、CDP_Batch 状态/补料人字段、INSERT CDP_Item_Serials（Quantity=MapCarriedItemQuantity）。

Core

  • QCFluidCenter 在 Auto 下找 ItemStatus=17 优先，否则 16。
  • 按 ExtraData 分液并登录 BGA / Vicell / OSMO / Cedex 设备服务。
  • 设备子系统写 CDP_Testing_*；管状态最终到 Discard(28)，位置清空。
  • 不创建 TaskQueue 行。
