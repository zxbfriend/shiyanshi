# 泵速策略逻辑指南

## 概述

泵速策略用于控制补料过程中的泵速切换、停泵条件和异常监控。本文面向工艺人员、开发人员、测试人员，说明二段式和三段式策略的配置方式、计算公式、实例演算和监控规则。

核心目标：

- 工艺人员：明确每个阶段的补料量、泵速和停泵点。
- 开发人员：按统一公式实现策略计算和异常判断。
- 测试人员：根据参数推导预期结果，验证阶段切换、停泵和报警逻辑。

> 本文默认泵速百分比表示每分钟补入目标量的百分比。例如目标量为 100 L，泵速为 50%，则理论流量为 50 L/min。

## 策略类型详解

### 二段式策略

二段式策略包含 3 个状态：

```text
高速阶段 → 低速阶段 → 终止
```

| 阶段 | 触发条件 | 运行目标 | 使用字段 |
| --- | --- | --- | --- |
| 高速 | 补料开始 | 快速补入主要物料量 | `HighSpeedPercent`、`HighSpeedVolumePercent` |
| 低速 | 实际补料量达到高速目标量 | 降低泵速，提升停泵精度 | `LowSpeedPercent`、`TerminalVolumePercent` |
| 终止 | 实际补料量达到终止阈值 | 停泵 | `TerminalVolumePercent` |

二段式适合目标量稳定、物料流动性较好、无需前置校准的场景。

### 三段式策略

三段式策略包含 4 个状态：

```text
校准阶段 → 高速阶段 → 低速阶段 → 终止
```

| 阶段 | 触发条件 | 运行目标 | 使用字段 |
| --- | --- | --- | --- |
| 校准 | 补料开始 | 用固定时间建立初始流量 | `CalibrateDuration`、`CalibrateVolumePercent` |
| 高速 | 校准完成 | 快速补入主要物料量 | `HighSpeedPercent`、`HighSpeedVolumePercent` |
| 低速 | 高速阶段完成 | 精细补料 | `LowSpeedPercent`、`LowSpeedVolumePercent` |
| 终止 | 实际补料量达到终止阈值 | 停泵 | `TerminalVolumePercent` |

三段式要求：

```text
CalibrateVolumePercent + HighSpeedVolumePercent + LowSpeedVolumePercent = 100
```

该策略适合需要先观察泵料稳定性、物料易波动或对补料精度要求更高的场景。

## 字段说明与配置建议

### 策略字段

| 字段 | 含义 | 单位 | 配置建议 |
| --- | --- | --- | --- |
| `CalibrateDuration` | 校准阶段运行时间 | s | 三段式必填，建议覆盖泵启动后的不稳定时间 |
| `CalibrateVolumePercent` | 校准阶段计划补料比例 | % | 三段式必填，通常设置为 5% 到 15% |
| `HighSpeedPercent` | 高速阶段泵速 | %/min | 值越大，补料越快，过冲风险越高 |
| `HighSpeedVolumePercent` | 高速阶段计划补料比例 | % | 二段式通常设置为 60% 到 80% |
| `LowSpeedPercent` | 低速阶段泵速 | %/min | 建议明显低于高速泵速 |
| `LowSpeedVolumePercent` | 低速阶段计划补料比例 | % | 三段式必填 |
| `TerminalVolumePercent` | 终止补料比例 | % | 常见值为 98% 到 100%，用于提前停泵或精确停泵 |

### 监控字段

| 字段 | 含义 | 单位 | 配置建议 |
| --- | --- | --- | --- |
| `IntervalTime` | 监控间隔时间 | s | 常见值为 1 s 到 5 s |
| `ExcessPercentage` | 超量报警百分比 | % | 按工艺容忍度设置 |
| `TimeOutSeconds` | 超时报警宽限时间 | s | 应覆盖泵启动、流量波动和称重延迟 |
| `DitherIntervalCoefficient` | 抖动监控间隔系数 | 无 | 用于放大或缩小抖动检查窗口 |
| `DitherCoefficient` | 抖动系数 | 无 | 基于计划变化量判断称重波动 |
| `DitherMonitorTime` | 抖动观察时间系数 | 无 | 控制抖动持续观察时长 |
| `DitherScaleCoefficient` | 抖动地秤系数 | 无 | 基于地秤精度设置最低抖动阈值 |
| `RebateCoefficient` | 返水系数 | 无 | 负数，用于判断实际量回退 |
| `JamIntervalCoefficient` | 堵塞监控间隔系数 | 无 | 控制堵塞检查窗口 |
| `JamCoefficient` | 堵塞系数 | 无 | 实际增量低于计划增量的比例时判定堵塞 |

## 计算公式详解

### 三段式校准速度

**公式描述**

校准阶段按固定时间运行。校准速度表示每分钟理论补入目标量的百分比。

**数学表达式**

```text
calibrationSpeed (%/min) = (CalibrateVolumePercent / CalibrateDuration) * 60
```

**代码实现**

```typescript
function getCalibrationSpeed(
  calibrateVolumePercent: number,
  calibrateDurationSeconds: number
): number {
  return (calibrateVolumePercent / calibrateDurationSeconds) * 60;
}
```

**实例计算演示**

实例 2 中：

```text
CalibrateVolumePercent = 10
CalibrateDuration = 120 s

calibrationSpeed = (10 / 120) * 60 = 5 %/min
```

目标量为 100 L 时，校准阶段理论流量为：

```text
100 L * 5% = 5 L/min
```

### 高速理论时间

**公式描述**

高速理论时间表示高速阶段按设定泵速完成计划补料比例所需的时间。

**数学表达式**

```text
highTime (min) = HighSpeedVolumePercent / HighSpeedPercent
```

**代码实现**

```typescript
function getHighTime(
  highSpeedVolumePercent: number,
  highSpeedPercent: number
): number {
  return highSpeedVolumePercent / highSpeedPercent;
}
```

**实例计算演示**

实例 1 中：

```text
HighSpeedVolumePercent = 70
HighSpeedPercent = 50

highTime = 70 / 50 = 1.4 min = 84 s
```

### 低速理论时间

**公式描述**

低速理论时间表示低速阶段按设定泵速完成计划补料比例所需的时间。

**数学表达式**

```text
lowTime (min) = LowSpeedVolumePercent / LowSpeedPercent
```

**代码实现**

```typescript
function getLowTime(
  lowSpeedVolumePercent: number,
  lowSpeedPercent: number
): number {
  return lowSpeedVolumePercent / lowSpeedPercent;
}
```

**实例计算演示**

实例 2 中：

```text
LowSpeedVolumePercent = 20
LowSpeedPercent = 5

lowTime = 20 / 5 = 4 min = 240 s
```

二段式没有独立的 `LowSpeedVolumePercent` 字段，可按终止比例反推：

```text
lowSpeedVolumePercent = TerminalVolumePercent - HighSpeedVolumePercent
```

实例 1 中：

```text
lowSpeedVolumePercent = 99 - 70 = 29
lowTime = 29 / 10 = 2.9 min = 174 s
```

### 三段式总理论时间

**公式描述**

三段式总理论时间由校准阶段、高速阶段、低速阶段组成。

**数学表达式**

```text
totalTime (min) = CalibrateDuration / 60 + highTime + lowTime
```

**代码实现**

```typescript
function getThreeStageTotalTime(
  calibrateDurationSeconds: number,
  highTimeMinutes: number,
  lowTimeMinutes: number
): number {
  return calibrateDurationSeconds / 60 + highTimeMinutes + lowTimeMinutes;
}
```

**实例计算演示**

实例 2 中：

```text
CalibrateDuration = 120 s = 2 min
highTime = 1.75 min
lowTime = 4 min

totalTime = 2 + 1.75 + 4 = 7.75 min = 465 s
```

### 终止条件

**公式描述**

当实际补料量达到目标量乘以终止补料百分比时，系统停泵。

**数学表达式**

```text
actualVolume >= targetVolume * TerminalVolumePercent / 100
```

**代码实现**

```typescript
function shouldStopPump(
  actualVolume: number,
  targetVolume: number,
  terminalVolumePercent: number
): boolean {
  return actualVolume >= (targetVolume * terminalVolumePercent) / 100;
}
```

**实例计算演示**

实例 1 和实例 2 的目标量均为 100 L，终止补料百分比均为 99%。

```text
stopVolume = 100 * 99 / 100 = 99 L
```

当 `actualVolume >= 99 L` 时停泵。

### 超量报警

**公式描述**

当实际补料量超过目标量允许上限时，触发超量报警。

**数学表达式**

```text
actualVolume > targetVolume * (1 + ExcessPercentage / 100)
```

**代码实现**

```typescript
function isExcessVolume(
  actualVolume: number,
  targetVolume: number,
  excessPercentage: number
): boolean {
  return actualVolume > targetVolume * (1 + excessPercentage / 100);
}
```

**实例计算演示**

实例 1 中：

```text
targetVolume = 100 L
ExcessPercentage = 5

excessLimit = 100 * (1 + 5 / 100) = 105 L
```

当 `actualVolume > 105 L` 时触发超量报警。

### 超时报警

**公式描述**

当实际运行时间超过理论时间加超时宽限时间时，触发超时报警。

**数学表达式**

```text
elapsedSeconds > expectedSeconds + TimeOutSeconds
```

**代码实现**

```typescript
function isTimeout(
  elapsedSeconds: number,
  expectedSeconds: number,
  timeoutSeconds: number
): boolean {
  return elapsedSeconds > expectedSeconds + timeoutSeconds;
}
```

**实例计算演示**

实例 1 中：

```text
expectedSeconds = 258 s
TimeOutSeconds = 60 s

timeoutLimit = 258 + 60 = 318 s
```

当 `elapsedSeconds > 318 s` 时触发超时报警。

### 抖动阈值

**公式描述**

抖动阈值取地秤精度阈值和计划变化量阈值中的较大值，用于过滤称重噪声。

**数学表达式**

```text
ditherThreshold = max(
  DitherScaleCoefficient * scalePrecision,
  DitherCoefficient * plannedVolumeDelta
)
```

**代码实现**

```typescript
function getDitherThreshold(
  ditherScaleCoefficient: number,
  scalePrecision: number,
  ditherCoefficient: number,
  plannedVolumeDelta: number
): number {
  return Math.max(
    ditherScaleCoefficient * scalePrecision,
    ditherCoefficient * plannedVolumeDelta
  );
}
```

**实例计算演示**

假设：

```text
DitherScaleCoefficient = 3
scalePrecision = 0.05 L
DitherCoefficient = 0.2
plannedVolumeDelta = 0.8 L
```

计算：

```text
scaleThreshold = 3 * 0.05 = 0.15 L
plannedThreshold = 0.2 * 0.8 = 0.16 L

ditherThreshold = max(0.15, 0.16) = 0.16 L
```

### 堵塞判定

**公式描述**

当计划补料变化量足够大，但实际补料变化量明显偏小，判定可能堵塞。

**数学表达式**

```text
plannedVolumeDelta > 2 * scalePrecision
AND actualVolumeDelta < JamCoefficient * plannedVolumeDelta
```

**代码实现**

```typescript
function isJam(
  plannedVolumeDelta: number,
  actualVolumeDelta: number,
  scalePrecision: number,
  jamCoefficient: number
): boolean {
  return (
    plannedVolumeDelta > 2 * scalePrecision &&
    actualVolumeDelta < jamCoefficient * plannedVolumeDelta
  );
}
```

**实例计算演示**

假设：

```text
plannedVolumeDelta = 1.0 L
actualVolumeDelta = 0.2 L
scalePrecision = 0.05 L
JamCoefficient = 0.3
```

计算：

```text
2 * scalePrecision = 0.1 L
plannedVolumeDelta > 0.1 L，条件成立

JamCoefficient * plannedVolumeDelta = 0.3 * 1.0 = 0.3 L
actualVolumeDelta < 0.3 L，条件成立
```

结论：判定为堵塞。

### 返水判定

**公式描述**

当实际补料变化量为负，并且回退量超过按地秤精度计算的阈值时，判定返水。

**数学表达式**

```text
actualVolumeDelta < 0
AND actualVolumeDelta <= RebateCoefficient * scalePrecision
```

**代码实现**

```typescript
function isRebate(
  actualVolumeDelta: number,
  rebateCoefficient: number,
  scalePrecision: number
): boolean {
  return (
    actualVolumeDelta < 0 &&
    actualVolumeDelta <= rebateCoefficient * scalePrecision
  );
}
```

**实例计算演示**

假设：

```text
actualVolumeDelta = -0.20 L
RebateCoefficient = -3
scalePrecision = 0.05 L
```

计算：

```text
RebateCoefficient * scalePrecision = -3 * 0.05 = -0.15 L
actualVolumeDelta < 0，条件成立
actualVolumeDelta <= -0.15 L，条件成立
```

结论：判定为返水。

## 完整实例演算

## 实例 1：二段式策略

### 目标与配置

目标：向 Tank 中补料 100 L 物料 A。

| 参数 | 字段 | 值 |
| --- | --- | --- |
| 策略类型 | StrategyType | 二段式 |
| 目标量 | targetVolume | 100 L |
| 高速泵速百分比 | `HighSpeedPercent` | 50% |
| 高速补料百分比 | `HighSpeedVolumePercent` | 70% |
| 低速泵速百分比 | `LowSpeedPercent` | 10% |
| 终止补料百分比 | `TerminalVolumePercent` | 99% |
| 监控间隔 | `IntervalTime` | 2 s |
| 超量报警 | `ExcessPercentage` | 5% |
| 超时报警 | `TimeOutSeconds` | 60 s |

### 阶段 1：高速阶段运行到多少升

```text
highVolume = targetVolume * HighSpeedVolumePercent / 100
highVolume = 100 * 70 / 100 = 70 L
```

高速阶段运行到实际补料量达到 70 L。

高速理论时间：

```text
highTime = HighSpeedVolumePercent / HighSpeedPercent
highTime = 70 / 50 = 1.4 min = 84 s
```

### 阶段 2：低速阶段运行到多少升

低速阶段从 70 L 开始，运行到终止阈值 99 L。

```text
terminalVolume = targetVolume * TerminalVolumePercent / 100
terminalVolume = 100 * 99 / 100 = 99 L
```

低速阶段计划补料量：

```text
lowVolume = terminalVolume - highVolume
lowVolume = 99 - 70 = 29 L
```

低速阶段对应比例：

```text
lowSpeedVolumePercent = 99 - 70 = 29%
```

低速理论时间：

```text
lowTime = lowSpeedVolumePercent / LowSpeedPercent
lowTime = 29 / 10 = 2.9 min = 174 s
```

### 阶段 3：何时停泵

终止条件：

```text
actualVolume >= 100 * 99 / 100
actualVolume >= 99 L
```

当实际补料量达到或超过 99 L 时停泵。

### 阶段 4：理论补料时间

```text
totalTime = highTime + lowTime
totalTime = 1.4 + 2.9 = 4.3 min = 258 s
```

### 阶段 5：超时报警阈值

```text
timeoutLimit = expectedSeconds + TimeOutSeconds
timeoutLimit = 258 + 60 = 318 s
```

当补料运行时间超过 318 s 时触发超时报警。

### 阶段 6：超量报警阈值

```text
excessLimit = targetVolume * (1 + ExcessPercentage / 100)
excessLimit = 100 * (1 + 5 / 100) = 105 L
```

当实际补料量大于 105 L 时触发超量报警。

### 时间轴

```text
0 s                 84 s                         258 s
|-------------------|-----------------------------|
开始                切换低速                      停泵
高速 50%            低速 10%                      actualVolume >= 99 L
0 L 到 70 L         70 L 到 99 L
```

### 结果汇总

| 项目 | 结果 |
| --- | --- |
| 高速阶段终点 | 70 L |
| 低速阶段终点 | 99 L |
| 停泵条件 | `actualVolume >= 99 L` |
| 高速理论时间 | 84 s |
| 低速理论时间 | 174 s |
| 总理论时间 | 258 s |
| 超时报警阈值 | 318 s |
| 超量报警阈值 | `actualVolume > 105 L` |

### 约束验证

| 约束 | 验证结果 |
| --- | --- |
| 高速补料百分比小于终止补料百分比 | 70% < 99%，通过 |
| 低速阶段补料比例为正 | 99% - 70% = 29%，通过 |
| 高速泵速大于低速泵速 | 50% > 10%，通过 |
| 终止补料百分比不超过目标量 | 99% <= 100%，通过 |

目标：向 Tank 中补料 100 L 物料 B。

```text
CalibrateVolumePercent + HighSpeedVolumePercent + LowSpeedVolumePercent
= 10 + 70 + 20
= 100
```

结论：三段式阶段补料比例约束通过。

### 2. 校准速度是多少

```text
calibrationSpeed = (CalibrateVolumePercent / CalibrateDuration) * 60
calibrationSpeed = (10 / 120) * 60 = 5 %/min
```

目标量为 100 L：

```text
calibrationFlow = 100 * 5 / 100 = 5 L/min
```


```text

lowTime = LowSpeedVolumePercent / LowSpeedPercent
```

```text
lowActualVolume = 99 - 80 = 19 L

```

按完整阶段计划量计算：

```text
totalTime = CalibrateDuration / 60 + highTime + lowTime
totalTime = 120 / 60 + 1.75 + 4

```

```text

```

## 异常监控机制

### 监控节拍

系统按 `IntervalTime` 周期采集实际补料量、运行时间和阶段状态。每次采样可执行以下检查：

1. 判断是否达到终止条件。
2. 判断是否超量。
3. 判断是否超时。
4. 基于采样窗口判断抖动、堵塞和返水。

示例：

```text
IntervalTime = 2 s
系统每 2 s 读取一次实际补料量，并更新异常状态。
```

### 超量监控

适用场景：泵关闭滞后、阀门泄漏、称重异常导致实际量超过上限。

判断公式：

```text
actualVolume > targetVolume * (1 + ExcessPercentage / 100)
```

建议：

- `ExcessPercentage` 应按物料风险和工艺容忍度设置。
- 对高价值或危险物料，建议设置更小的超量比例。

### 超时监控

适用场景：泵流量不足、管路堵塞、阀门未打开、称重反馈异常。

判断公式：

```text
elapsedSeconds > expectedSeconds + TimeOutSeconds
```

建议：

- `expectedSeconds` 应由策略参数计算得到。
- `TimeOutSeconds` 不宜过小，否则容易因启动延迟误报。
- 对低速阶段较长的策略，应结合实际工艺节拍设置宽限时间。

### 抖动监控

适用场景：称重数据短周期波动，可能影响停泵判断和阶段切换。

判断基础：

```text
ditherThreshold = max(
  DitherScaleCoefficient * scalePrecision,
  DitherCoefficient * plannedVolumeDelta
)
```

建议：

- 地秤精度较低时，提高 `DitherScaleCoefficient`。
- 物料流量波动较大时，提高 `DitherCoefficient`。
- 抖动监控应结合观察窗口，不建议只凭单次采样判定。

### 堵塞监控

适用场景：泵运行但实际补料量增长明显不足。

判断公式：

```text
plannedVolumeDelta > 2 * scalePrecision
AND actualVolumeDelta < JamCoefficient * plannedVolumeDelta
```

建议：

- `JamCoefficient` 越小，堵塞判定越严格。
- 应避免在计划变化量过小时判断堵塞，因为称重精度会放大误差。
- 堵塞报警应优先检查管路、阀门、泵运行状态和称重反馈。

### 返水监控

适用场景：实际补料量出现负增长，可能由管路回流、称重波动或物料回吸导致。

判断公式：

```text
actualVolumeDelta < 0
AND actualVolumeDelta <= RebateCoefficient * scalePrecision
```

建议：

- `RebateCoefficient` 为负数。
- 回退量超过地秤精度允许范围时再报警。
- 返水报警后应检查止回阀、管路压力和泵停止后的回流情况。

## 常见问题与注意事项

### 1. 二段式为什么没有 `LowSpeedVolumePercent`

二段式低速阶段由高速终点和终止点共同决定：

```text
lowSpeedVolumePercent = TerminalVolumePercent - HighSpeedVolumePercent
```

例如高速补料 70%，终止补料 99%，则低速阶段实际承担 29%。

### 2. 三段式阶段比例为 100%，为什么 99% 就停泵

三段式的 100% 是阶段计划量，用于计算理论时间和阶段分配。`TerminalVolumePercent` 是实际停泵条件。本例中终止补料百分比为 99%，因此低速阶段计划可到 100%，但实际达到 99 L 时停泵。

### 3. `TerminalVolumePercent` 应该设置为 100% 吗

不一定。若泵停止后存在惯性补料或管路残余流量，可设置为 98% 到 99%，降低超量风险。若系统停泵响应快、流量稳定，也可设置为 100%。

### 4. 高速补料比例越高越好吗

不是。高速比例越高，总时间越短，但切入低速越晚，过冲风险越高。建议根据物料流动性、泵响应时间和称重延迟配置。

### 5. 超时报警时间如何设置

建议先计算理论时间，再加上合理宽限时间：

```text
timeoutLimit = expectedSeconds + TimeOutSeconds
```

宽限时间应覆盖泵启动延迟、称重刷新周期、管路压力建立时间和低流量波动。

### 6. 测试时应重点验证哪些点

建议覆盖以下测试点：

- 阶段切换点是否正确。
- 停泵点是否按 `TerminalVolumePercent` 判断。
- 超量报警阈值是否正确。
- 超时报警阈值是否正确。
- 三段式比例和不等于 100% 时是否拒绝配置或报警。
- 抖动、堵塞、返水是否按采样窗口和阈值判断。
- 边界值，例如 99.99 L、100 L、105 L。

### 7. 配置校验建议

上线前建议校验：

| 校验项 | 建议规则 |
| --- | --- |
| 泵速百分比 | 必须大于 0 |
| 补料百分比 | 必须大于等于 0 |
| 二段式高速补料百分比 | 应小于 `TerminalVolumePercent` |
| 三段式比例和 | 必须等于 100% |
| 终止补料百分比 | 建议大于 0 且小于等于 100% |
| 超量报警百分比 | 必须大于等于 0 |
| 超时报警时间 | 必须大于等于 0 |
| 返水系数 | 必须为负数 |

## 附录：核心伪代码

```typescript
type TwoStageConfig = {
  highSpeedPercent: number;
  highSpeedVolumePercent: number;
  lowSpeedPercent: number;
  terminalVolumePercent: number;
};

type ThreeStageConfig = {
  calibrateDurationSeconds: number;
  calibrateVolumePercent: number;
  highSpeedPercent: number;
  highSpeedVolumePercent: number;
  lowSpeedPercent: number;
  lowSpeedVolumePercent: number;
  terminalVolumePercent: number;
};

function getStopVolume(targetVolume: number, terminalVolumePercent: number): number {
  return (targetVolume * terminalVolumePercent) / 100;
}

function getTwoStageExpectedSeconds(config: TwoStageConfig): number {
  const highTimeMinutes =
    config.highSpeedVolumePercent / config.highSpeedPercent;

  const lowSpeedVolumePercent =
    config.terminalVolumePercent - config.highSpeedVolumePercent;

  const lowTimeMinutes =
    lowSpeedVolumePercent / config.lowSpeedPercent;

  return (highTimeMinutes + lowTimeMinutes) * 60;
}

function getThreeStageExpectedSeconds(config: ThreeStageConfig): number {
  const highTimeMinutes =
    config.highSpeedVolumePercent / config.highSpeedPercent;

  const lowTimeMinutes =
    config.lowSpeedVolumePercent / config.lowSpeedPercent;

  return config.calibrateDurationSeconds + (highTimeMinutes + lowTimeMinutes) * 60;
}
```
