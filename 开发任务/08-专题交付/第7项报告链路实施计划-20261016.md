# 第7项报告链路实施计划

> 执行方式：按 test-driven-development 逐项先写失败测试，由主协调运行 Maven；不提交、不执行数据库、不调用外部网络。

**目标：** 落实 M05-031/032/033/034 当前冻结契约，将当前有效结果版本冻结为耐久作业，在事务外生成真实 PDF/XLSX，按全部冻结对象当前权限下载。

**依据：** `docs/02-详细设计.md`、`docs/详细设计/05-检测与数据签批/签批记录与报告导出设计.md`、`结果操作报告与版本发布数据库设计.md`、`受控更正与审计保留设计.md`。本文件是实施计划，不创建平行业务权威。

**结构：** Controller → M05 应用服务 → 模板/范围/不可变清单 → M01 管理守卫内 root/child 与回执同提交 → 数据库租约 worker → 真实渲染器 → 私有受控文件 → 下载前逐对象重新授权。复用 `det_print_export_log`，不新增业务表。

## 固定合同

- 模板清单：`{schemaVersion:1,releaseId,profiles:[{versionKey,profile:{profileId,version,sourceSha256,rendererVersion,cellMappings:[{templateKey,detectClass,itemCode,displayLabel,unitPolicy}],fontSha256},status,approval}],approvalEvidence}`。
- 核准记录：`{schemaVersion:1,releaseId,manifestHash,submittedByUserId,approvedByUserId,approvedAt,profileHashes:[{versionKey,sourceSha256,profileHash}],evidenceRef,authorizationEvidence:{permissionCode,actorUserId,authzVersion,evaluatedAt,requestId},keyId,signature}`。Ed25519 对去 signature 的规范化 JSON 签名；permissionCode 必须 `detect:report:template:approve`。
- 配置固定前缀 `futurefab.m05.report`：`template-root`、`template-manifest-sha256`、`template-approval-public-key`、`max-results`、`max-bytes`、`timeout-seconds`。已有确认密钥 `futurefab.m05.confirmation-hmac-key`。阈值无默认值。
- 发布目录 `<template-root>/releases/<manifestHash>/manifest.json`；核准记录为同版相对引用。资源按内容寻址的实现约定存为同版 `resources/<sha256>`，不增加客户端可传路径；模板与字体均按原字节摘要校验，拒绝路径越界/软链接/未知字段与重复身份。
- 新任务 manifest schemaVersion=2；根 manifestHash、发布 manifestHash、profileHash、sourceSha256 分别计算，template_hash 只存 sourceSha256 原始32字节。已有 v1 只读，不补造核准证据。
- root=min(resultId) 对应日志；一结果一索引行，root/child 同事务，唯一 actor+request+result。manifest/selection 提交后不可更新。
- M01 守卫→实验室→设备→样品→结果升序；锁内复核当前授权/版本/模板核准，回执优先于令牌过期。渲染与文件 I/O 不在管理事务中。
- 整批全日期选样品，任一类型当前 uploaded/signed/reviewed 命中则展开全部有权类型，不沿用人员/日期/页码/勾选；按不可变采样身份分组，不按可改样品号拼接。
- 当前有效 schema1/schema2 同一路径；精确版本缺失不回退最新。无当前版本快照时只可在锁内创建当前 BASELINE，不伪造过去版本。
- PDF 每页最多16样品列，嵌入核准字体，日志及更正另页；Excel 保留模板 A:AC 布局、文本ID、防公式、来源注释及更正说明 sheet。单位不可核准则 FAILED/MAPPING_UNVERIFIED，不生成貌似合格文件。
- 下载前要求原发起者或用途审计权、相应用途功能码、冻结集合每一对象当前阅读范围、root/child/manifest 一致及文件摘要一致。UNKNOWN 只描述物理打印不确定；已有文件可依合同独立下载。

## 验证重点

- 签名/清单/字体/模板任一篡改零令牌；无核准记录、重复版本键、软链接逃逸拒绝。
- 批次跨日期、重测无法配对及更正有效值不遗漏，所有样品/版本来源可追溯。
- 事务内任何写失败 root/child/审计/回执全回滚；回执到期不重新执行领域效果。
- 旧 worker 租约不能置 READY；渲染器输出真实可解析文件并遵守字节/时间限制。
- 中文/长文本/多签名不截断，公式样品号为文本，旧报告内容不覆盖且有后续更正提示。

## 外部输入及独立提供方

真实核准模板、字体文件及使用权、逐项单位映射、受控发布工件、公钥/keyId登记、部署目录访问控制、多实例整版切换、阈值/HMAC配置属于部署输入，不伪造默认值。

M01 TrustedAdminToolAuthenticationAdapter、共享 token.secret 安全配置与受信核准签名/发布工具是独立尚缺的生产代码，不把它们称作仅缺配置。业务实例只验证发布工件，不持审批私钥、不生成虚构授权证据。M02 已有 `ILabPrinterService.checkPrinterUsableInLab` 当前会话下的同实验室可用性事实；物理 PRINT 仍缺锁内/后台取事实及真实打印提交/查询合同，不能把候选可用性冒称为物理执行；PDF/XLSX 不依赖打印机。

本计划及本批单元/契约测试不能证明数据库、HTTP、浏览器、正式核准发布或现场打印通过，运行层均须单独验收。
