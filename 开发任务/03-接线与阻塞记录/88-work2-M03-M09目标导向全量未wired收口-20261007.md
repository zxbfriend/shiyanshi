## 2. 为什么本批 0 项接线（判定依据，不是态度）

Provider 清点（`src/main/java` 全量 `implements` 扫描，本批取证结果）：

| 端口族 | 有提供方的端口 | 零提供方 |
| --- | --- | --- |
| `port/m01` | ActorContextPort、FunctionPermissionPort、RoleCandidateFactsPort | ManagementRevisionPort（守卫走 `SysManagementRevisionMapper` 直读，另有 `ManagementRevisionSource` 适配器） |
| `port/m02` | LabAuthorizationPort | DeviceConfiguration / DeviceCapability / DeviceCommand / ConsumptionResolution / EngineeringResolution / CommunicationConfiguration / DeviceReadings / MaterialObservation / ObservationIntake（共 9 口） |
| `port/m06` | **ApprovalPolicyPort、ApprovalSubmissionPort（各 1 个真实提供方）** | ApprovalDecisionPort 不在 m06 包 |
| `port/m07` | PlanReplacementPort | CultureExecutionBarrier / CultureInputBarrier / CultureRuntime / DetectionReservation / DetectionResultChange / ExecutionSample / PlanGeneration / RunDeadlineFacts / RunEventPublisher / m07.ApprovalDecisionPort（共 10 口） |
| `port/m03` | CultureBindingPort、CultureReadEligibilityPort、MemberIdentityFactsPort、ResourceUsageGuardPort | m03.ApprovalDecisionPort、CultureChangePort、CultureRuntimeReceiptPort、ResourceDeadlineFactsPort、WorkflowReferencePort |
| `port/m09` | DeliveryReconciliationPort、EventIngestionPort、MonitorAcknowledgementPort | AlarmConfigDecisionPort、m09.ApprovalDecisionPort |

判据链：

1. **所有写口**（M03-004/005/011/013/027/032/033 **以及 M09-011/013**，即 U1 覆盖的 M03 七项 + M09-011/013 两项，
   共 9 个操作码）都要 `@ManagementGuardedWrite` + W0 幂等回执 + 审计策略，
   而这两张注册表是**共享串行窗口**（原则 5/7 禁止本批修改）。没有登记，写口接出来就是"无守卫的无条件覆盖"，
   违反 AGENTS.md §8"状态变更必须校验版本/幂等键和权限，不允许无条件覆盖"。
   实测 `ManagementOperation` 当前确实没有 `M09_011 / M09_013`（同族对照项 `M03_007` 已登记于该枚举第 424 行），
   所以 M09 两个配置写口同样进不了 U4 的落地前提。
2. **所有依赖外部事实的写口**还叠加②类阻塞：M02 设备/占用 9 口零提供方、M07 运行屏障与生效 10 口零提供方、
   M09 决定交付 INT02 零提供方。原则 4 明确"provider 未就绪则跳过实现"。
3. **候选读口**（M03-003/025/026/030）缺的是**事实源本身**：M01 侧只有身份/判权/管理版本/角色目录四口，
   没有部门/人员/字典候选端口。若改用 legacy `ISysDeptService`/`ISysDictDataService`/选择器出口把
   `wired=true` 刷出来，等于绕过 Port 契约直读他模块主数据（AGENTS.md §8 明令禁止）并制造平行机制，
   因此本批采严格口径：不接，登记为 D-1 决策问句。
4. **M03-039—044 是 DISABLE 设计终态**，"未 wired"正是它们的验收结果；翻 `wired` 反而是回归。
