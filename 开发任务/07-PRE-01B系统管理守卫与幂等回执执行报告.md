## 2. 幂等唯一性最终定义

- 四元组：`actorUserId`（ActorContextPort 服务端可信推导）+ `requestId`（WriteMeta，UUID36）+ `operationCode`（ManagementOperation 白名单常量）+ `payloadHash`。
- `payloadHash = HMAC-SHA256( canonicalJson({"operationCode":<编码>,"payload":<白名单JsonNode>}) )` 的 64 位小写十六进制；规范化=对象键 Unicode 升序、数组保序、无多余空白、UTF-8。
- 回执查询（同 actor+requestId、未过期）：operationCode 与 payloadHash 均一致 → 返回原 `result_json`（`replayed=true`），不执行 callback、不递增版本、不重复审计、回填原回执 managementRevision；任一不一致 → `REQUEST_CONFLICT(409)`，callback 零执行、零数据库修改。

## 3. 过期回执行为

`selectReceipt` 命中且 `expiresAt == null || !expiresAt.isAfter(now)` → 视为过期（`now >= expiresAt`），抛 `REQUEST_CONFLICT(409)`："同操作者同 requestId 的回执已过期，禁止自动重放创建；请刷新当前 managementRevision 并使用新的 requestId 重新提交"。本执行路径不删除该行、不复用其 requestId 执行业务、不覆盖其内容；过期回执的物理清理为后续独立调度任务事项。

## 5. ActorContextPort 接入方式

- Port 物理签名沿用 PKG-00 冻结：`resolveActorContext(ActorContextQuery) -> ActorContext`。
- 请求侧：`ActorContextQuery.requestId = writeMeta.getRequestId()`；`sessionKey` 取服务端链路会话上下文（`SecurityUtils.getUserKey()`，由 HeaderInterceptor 从网关写入，非浏览器 Body 字段）。
- 响应侧：`ActorContext.actorUserId` 必须为正的十进制字符串，执行器解析为 Long 后作为幂等键与回执 `actor_user_id`；null 上下文、非法/非正 actorUserId、Port 抛异常一律失败关闭，不降级匿名。
- 现状（PRE-01B-R1 时点）：SEC-I01 生产适配器尚未落地（属后续逐模块接入步骤），`ManagementGuardExecutor` 因 `actorContextPort == null` 显式拒绝执行——不退回 `SecurityUtils.getUserId()`、不建第二套身份。
  **【PRE-01C 实现已撤回】** PRE-01C 曾落地 SEC-I01 真实身份适配器并改为构造器必需依赖，经审阅越过"只做接口骨架"边界，已于 2026-09-19 全部撤回删除（撤回明细见 `09-PRE-01C越界实现撤回与骨架边界恢复报告.md`）。ActorContextPort 仍为**未实现、fail-closed 扩展点**；本报告 PRE-01B-R1 仍是当前有效基线。

## 6. 审计 fail-closed 方式

任务书 §四 提供 A/B 两案，本次采用 **A（推荐）：审计为必需能力**。实现为"守卫不得执行"变体：`ManagementAuditHook` 仍为可空注入（避免 58 接口接入前阻塞整个服务启动），但 `execute()` 在任何校验/身份解析/数据库访问之前检测到无审计实现即抛 IllegalStateException——无审计能力的管理写在语义上不可能发生；报告不再存在"审计钩子以后补且允许无审计提交"的口径。审计调用位于同一 `TransactionTemplate` 事务内、业务回调之后、CAS 与回执之前，审计异常触发整体回滚（测试断言业务写/CAS/回执全部回退）。

**【PRE-01C 实现已撤回】** 上述"可空注入 + 执行入口拒绝"变体曾被 PRE-01C 收紧替代（真实审计适配器落地、构造器必需依赖、钩子契约扩为 7 参），经审阅越过"只做接口骨架"边界，已于 2026-09-19 全部撤回：真实审计实现与审计明细模型已删除，`ManagementAuditHook` 恢复为本报告的 5 参基础契约（onManagementApplied 仅 actorUserId/requestId/operationCode/outcome/committedAt），当前无生产实现、执行入口 fail-closed。本报告 PRE-01B-R1 仍是当前有效基线。

## 7. HMAC 启动校验

`NormalizedPayloadHasher` 实现 `InitializingBean`：`@Value("${futurefab.management.receipt-hmac-key:}")` 注入值为 null/空白时 `afterPropertiesSet` 抛 `IllegalStateException("BLOCKED_INPUT：部署配置缺失 futurefab.management.receipt-hmac-key…")` → Spring 容器启动失败。仓库源码无默认密钥值；异常/日志/回执/测试输出仅含配置键名不含密钥。测试环境经 `MapPropertySource` 显式提供测试密钥。直接构造路径（绕过容器）在 `hash()` 内同样拒绝空密钥（纵深防御）。

## 8. 时区与边界语义

- 守卫 Clock：`ManagementGuardConfig.BUSINESS_ZONE = ZoneId.of("Asia/Shanghai")`，`Clock.system(BUSINESS_ZONE)`，不随 JVM/OS 默认时区漂移。
- 事务内一次取时：回执 `create_time`、`expires_at = create_time + 24h`、CAS `update_time` 共用同一 `LocalDateTime.now(clock)`。
- 边界：`now < expiresAt` 可重放；`now >= expiresAt`（恰好等于即过期）走 §3 过期拒绝路径。
