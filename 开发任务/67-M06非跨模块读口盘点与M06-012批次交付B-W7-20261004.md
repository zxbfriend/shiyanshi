关键实现口径：

- 只读切片独立建 `M06ApprovalLogQueryMapper`，沿 `M01ManagementQueryMapper/M02ManagementQueryMapper/
  M03ResourceQueryMapper/M07TaskQueryMapper` 先例，避免与写路径表 Mapper（`AprRequestMapper#updateDecisionState`、
  `AprActionMapper#insertAction` 等 M06-014/内部 API10 冻结写方法）争抢同一文件；不触碰
  `M06PolicyMapperXmlContractTest`（work6 为 TP-M06-03 建的门禁）与其 `EXPECTED` 词表。
- 失败分层：`approvalId` 非法 / 单据不存在 / 无该实验室 VIEW 三者统一 `NOT_FOUND` 404，可信身份缺失 503；
  范围闸门未过时不产生任何 `apr_action` 读取（用例以 `verifyNoInteractions` 与 `never()` 取证）。
- 执行者姓名只取 `action_snapshot.actor`（接口 `Person` 快照）；快照无 `userName/displayName` 即置 null，
  不回查 `sys_user` 现名。`kind/userId` 以 `actor_kind/actor_user_id`（受 `ck_apr_action_actor` 成对约束）为权威，
  SYSTEM 恒 `userId=null`，不以 `"0"` 或空账号代替。
- `action_snapshot` 是 `NOT NULL + CHECK(JSON_TYPE='OBJECT')` 列：解析失败、非对象、空值一律上抛
  `IllegalStateException`，不降级成"动作存在但无身份/结果码"。
- 动作码越出 `ApprovalActionCode` 词表时由 `valueOf` 抛出不合并语义，不静默产出 null 行。
- `occurred_at` 按 UTC `DATETIME(3)` 读为 `LocalDateTime`，输出补 UTC 偏移，不做服务器本地时区换算。

## 3. 待裁决与偏差登记（本批不自行统一）

1. **单对象 Path ID 非法值的错误码口径不一致。**
   `接口与审批生效契约.md` §2 写"单对象非法ID、不存在、无对象范围统一404"，`错误码全集.md` 第 12 行同径；
   而已合并的 M06-007/008（`ApprovalPolicyQueryApplicationServiceImpl.requirePositiveLabId`）对非十进制/0/负数
   返回 `INPUT_INVALID` 400。本批 M06-012 按契约文本取 404，未修改 007/008，也未发明第三种口径。
   需总控裁决：是把 007/008 收敛到 404，还是把 §2 澄清为"格式非法 400、语义不存在/无范围 404"。
2. **`ApprovalRow.labName` 等"当时名称"缺快照来源**（阻塞 M06-010/011 与 M06-005 的 Person 姓名）。
   可选方向：提交期把名称写入 `initiator_snapshot`/`change_snapshot`；或由拥有方 Port 提供带标识的当前名并按 §1 标注；
   或契约删字段。本批不选任一路。
3. **`apr_request/apr_action` 目前没有生产者。** 内部 `submitApproval`（API10 系）与 M06-014 决策动作仍是 501 骨架，
   真实库内不会出现审批单与动作行。因此 M06-012 的 HTTP 与浏览器验收在联调环境属 `BLOCKED_DATA`。
4. **`resultCode` 的落库形状未单独登记。** 契约 §1 Action 把 `resultCode:string` 列为必填，
   `action_snapshot` schema 有 `resultCode` 键但无值域；本批按"有则回显、无则 null"处理，不造值。
5. 沿用已登记的展示缺口：API02 冻结视图不含 `activationState`（属 M06-008 批偏差，本批未改动）。
