## 2. 落码判断：不可安全落码（八层精确前置）

派发希望"若可安全落码则实现校验输入→计算冻结集合→签发 REPORT_JOB 令牌→返回预览的最小真实链路"。经第一性复核，该链路在允许面内无法在不伪造业务快照的前提下完成，逐层可机械核验，均非"设计未定"泛称：

1. **核准 TemplateProfile 载体不存在（决定性）**。§3 定义 `TemplateProfile={profileId,version,sourceSha256,rendererVersion,cellMappings,fontSha256}`，且 031 命令注释与 §3 一致要求"完整 TemplateProfile 为服务端冻结对象，客户端不提交全量"——服务端必须凭客户端提交的键**解析**出完整对象。核对基线：`docs/开发基线/01-完整建表.sql`＋`02-基础数据初始化.sql` 中 `font_sha256`/`cell_mapping`/`renderer_version`/`source_sha256` 命中 **0**；唯一模板登记表 `prc_template` 的 `template_kind` 只含 M04 工艺模板种类（`CONFIG/PERFUSION/SAMPLING/AUTO_CONTROL/FEEDING/PUMP_SPEED`，无报告/打印用途）；`det_print_export_log.template_profile VARCHAR(32)`＋`template_hash BINARY(32)` 是 root 行的**存储列**，不是核准来源。⇒ 无任何 lawful 来源可解析模板身份，任何填充即伪造（红线：不得伪造）。`BLOCKED_INPUT`。
2. **TemplateProfile 归属未登记**。现行设计树（排除 `history/`）内 `TemplateProfile` 只出现在本模块 `签批记录与报告导出设计.md` 与 `错误码全集.md`，没有 M02/M04 侧登记表或接口认领该载体。`BLOCKED_DESIGN`（载体归属需总控裁决）。
3. **预览阶段阈值配置键无载体**。§2 明文"数据量超部署配置阈值在预览阶段提示缩小到合法培养范围，不能悄悄截断""异步任务最大结果数/字节数/超时为技术部署参数，缺配置拒绝超大任务"——该义务属于 031 自身。核对：`nacos-config/*.yml`、`futurefab-system` 的 `bootstrap.yml` 与模块资源中 `max-results/maxResults/max-bytes/maxBytes/futurefab.report` 命中 **0**，键名语义亦未登记。依 AGENTS.md §10 不得编造默认值。`BLOCKED_INPUT`（需需求方/运维给三个部署数值并登记键语义）。
4. **必响应字段 `scopeSummary.versions` 语义未注册**。§2 只写"实际结果数/版本"未拆叶子；`M05完整目标字段字典.md` 与 `审阅收尾完整字段字典.md` 均无 `scopeSummary` 条目；契约类型 `ReportScopeSummary` 自身留痕"设计文档未定义，待补充"。响应必填项无法在不猜语义的前提下填充。`BLOCKED_DESIGN`（单点字段）。
5. **BATCH 业务样品分组规则无文本**。§2 入选谓词按业务样品分组并要求"业务样品分组沿主设计UI03身份键"，`详细设计.md` §12.3 把编码规范化委托给"已经核准的样品ID规则，不新增长度规则"；核对判据为：现行设计树（排除 `history/`）内"样品ID规则"的每处命中都是该委托式引用，**无一处定义规则本身**，两份字段字典与骨架清单里该词零命中（与 M05-047 已登记签名同源）。`BLOCKED_DESIGN`，**范围仅限 BATCH**：§2 已明文 SINGLE_RESULT"此结果详情与其操作记录；不能凭sampleNo扩至别人结果"，工作台单份不受本条影响。
6. **`REPORT_JOB` 令牌 payload 字段清单无权威定义**。绑定基建已冻结（见 §1 表），缺的是 payload 业务快照内容；唯一候选来源 `content_manifest` 的模板段依赖第 1 项。031 与 032 必须共享同一 payload 形状，单方面定形即制造新的平行契约（AGENTS.md §12 禁止）。`BLOCKED_DESIGN`。
7. **台账登记的预览读投影尚未建立**。骨架清单为 031 登记 `DetReportJobMapper#selectReportJobPreview`（关联表 `det_result`，Mapper 适用性 REQUIRED），当前 Mapper 接口与 XML 均无该语句（INT-24 只交付 033/034 两条窄读，且 `M05ReportJobReadMapperContractTest` 禁读侧 `FOR UPDATE`）。本项**在允许面内可补**，但投影应输出哪些列正取决于第 1、4、6 项裁决，无法单独定形。
8. **跨模块读口未暴露**。台账把"M05→M02：资源、能力、工程和设备配置读取端口（打印机可用性与实验室范围匹配）"登记为 031 的跨模块依赖，§2 有原文"打印机还需M02当前可用及实验室范围匹配"；而 `service/port/m02` 目录内**无任何打印机读出口**（`Printer` 命中 0），M05 依约不得直读 `lab_printer`。本批禁改 Port 签名／PKG-00 ⇒ 跨模块批次＋总控裁决项。附带待裁决口径：预览体不接收 `printerId`，预览阶段究竟是否需要可用性检查尚无定义。

**运行层另列一项（不阻断落码，阻断高层验收）**：`futurefab.m05.confirmation-hmac-key` 在 `nacos-config/*.yml` 与模块配置源命中 0，仅有实现侧 `@Value` 占位默认空串；密钥不足 32 字节时签发失败关闭为 `DEPENDENCY_UNAVAILABLE`(503)。因此 031 日后即便接线，状态上限仍是 `IMPLEMENTED＋CONTRACT_TESTED`，运行须标 `BLOCKED_DEPLOY`。

**已排除的伪阻塞（正向收窄）**：031 的阻塞面**不含"读不到冻结候选结果"**。M05 自有窄口已具备单结果/版本事实（`M05DetectionResultFactsMapper.selectCurrentRevisionFacts/selectEligibleRevisions`）与项目/批次结果列表（`DetSignConsoleMapper.selectProjectOptions/selectBatchOptions/selectSignConsoleRows`）。后续批次不应把力气花在新增结果读取基建上。

**曾评估并否决的最小方案**：只实现"入参形状校验＋权限复算"而在令牌步骤仍留 501。否决理由：响应契约必填 `confirmationToken/expiresAt`，缺令牌的响应不合契约；台账 `wired` 不得为半链路口翻真（AGENTS.md §13.2）；且该做法不产生任何 032 可消费事实，只增加平行实现面。
