### 2.2 HTTP 验收脚本级步骤

#### M02-006 GET /lab/observation-mappings

```http
GET /lab/observation-mappings?deviceKind=DETECTOR&deviceId=9001&channelCode=TEMP-01&rawMetricCode=temperature
Authorization: Bearer <token>
X-Management-Revision: 60
```

**成功响应应核对**：
- HTTP 200，AjaxResult.code=200
- data.rows 为数组，每行含 mappingId/mappingVersion/deviceKind/deviceId/channelCode/rawMetricCode/itemId/rawUnit/unit/profile/effectiveFrom/effectiveTo/approvedBy/approvedAt
- profile 为 MappingProfile v1 JSON（schemaVersion=1, dimension, conversion.kind, measurementScope 等）
- 排序：mapping_version 降序（最新在前）

**关键失败路径**：

| 场景 | 触发方式 | 预期码/HTTP | 说明 |
|------|----------|-------------|------|
| 设备种类不在白名单 | deviceKind=LEGACY_BOX | VALIDATION_ERROR / 400 | 名单外一律拒收 |
| 设备种类缺失 | deviceKind 为空或 null | VALIDATION_ERROR / 400 | 必填 |
| 设备ID 非十进制 | deviceId=abc | VALIDATION_ERROR / 400 | 形态校验 |
| 设备ID 超出 long 范围 | deviceId=99999999999999999999 | VALIDATION_ERROR / 400 | 越界 |
| 通道空白 | channelCode="   " | VALIDATION_ERROR / 400 | trim 后为空 |
| 通道超长（>64） | channelCode="C".repeat(65) | VALIDATION_ERROR / 400 | 长度校验 |
| 原指标码缺失 | rawMetricCode=null | VALIDATION_ERROR / 400 | 必填 |
| 原指标码超长（>100） | rawMetricCode="M".repeat(101) | VALIDATION_ERROR / 400 | 长度校验 |
| 设备不存在或软删 | deviceId 指向不存在的设备 | NOT_FOUND / 404 | 不泄露存在性 |
| 不在设备管理范围 | 非管理员且 userId 无该 lab OPERATE 资格 | NOT_FOUND / 404 | 同"无权"语义 |
| profile 列损坏 | 数据库中某行 profile 列为空或非合法 JSON | IllegalStateException → 500 | 失败关闭，非输入错误 |

**数据清理**：只读接口，无需清理。

- data.mappingId 为十进制字符串 ID
- data.mappingVersion 为十进制字符串版本号（expectedMappingVersion+1）

**关键失败路径**：

| 场景 | 触发方式 | 预期码/HTTP | 说明 |
|------|----------|-------------|------|
| 所有 M02-006 输入校验失败 | 同上四要素不合格 | VALIDATION_ERROR / 400 | 先于守卫，不得触库 |
| 期望版本非负 | expectedMappingVersion=-1 | VALIDATION_ERROR / 400 | 形态校验 |
| 生效起点缺失 | effectiveFrom=null | VALIDATION_ERROR / 400 | 必填 |
| 生效终点早于/等于起点 | effectiveTo ≤ effectiveFrom | VALIDATION_ERROR / 400 | 半开区间方向 |
| profile 缺失/null | profile=null | VALIDATION_ERROR / 400 | 必填 |
| schemaVersion 非 1 | schemaVersion=2 | VALIDATION_ERROR / 400 | 模式校验 |
| 测量范围缺失 | measurementScope=null | VALIDATION_ERROR / 400 | 必填枚举 |
| 设备级测量通道非 DEVICE | measurementScope=DEVICE 但 channelCode≠"DEVICE" | VALIDATION_ERROR / 400 | 一致性校验 |
| 转换类型缺失 | conversion.kind=null | VALIDATION_ERROR / 400 | 必填 |
| IDENTITY 系数不符 | kind=IDENTITY 但 scale≠1 或 offset≠0 | VALIDATION_ERROR / 400 | 合取分支 |
| AFFINE 倍率为零或缺失 | kind=AFFINE 但 scale=0 或 null | VALIDATION_ERROR / 400 | 非零要求 |
| 设备不存在 | deviceId 指向不存在的设备 | NOT_FOUND / 404 | 事务内重解析 |
| 检测项不存在 | itemId 指向不存在的 dev_detector_item | NOT_FOUND / 404 | 存在性核验 |
| 权限不足 | actor 无该 lab MANAGE 资格（或 OPERATE，见待裁） | PERMISSION_DENIED / 403 | 事务内重判 |
| 无可信操作者身份 | ActorContext.actorUserId 解析失败 | PERMISSION_DENIED / 403 | 批次十五 §6⑤ 待裁归类 |
| 版本冲突 | expectedMappingVersion ≠ 当前最新版本 | VERSION_CONFLICT / 409 | CAS 不符 |
| 区间重叠 | 新 [from, to) 与既有核准版本重叠 | MAPPING_OVERLAP / 409 | 仅允许关闭同键最新开放区间 |
| requestId 体头不一致 | Body requestId ≠ X-Request-Id | REQUEST_ID_CONFLICT / 409 | 控制器归一前拒绝 |
| 同 requestId 异 payload | 首次落库后，相同 requestId 不同 hash 再次提交 | REQUEST_CONFLICT / 409 | 守卫层 request 表判定（批次十五 §6① 待裁：未在集合内） |
| 管理版本变更 | X-Management-Revision 过期 | MANAGEMENT_CONFLICT / 409 | 守卫层判定（批次十五 §6① 待裁：未在集合内） |
| 守卫锁等待超时 | 并发高时锁竞争 | MANAGEMENT_BUSY / 503 | 整次回滚 |
| HMAC 密钥缺失 | Nacos 未配置 futurefab.management.guard.hmac-key | IllegalStateException → 500 | 启动期应拦截，构造路径兜底 |

**数据清理**：
- 成功落库的行可通过 `DELETE FROM lab_observation_mapping WHERE mapping_id=<id>` 手动清理
- 幂等重放不会二次落库，只需删除首次回执对应的 sys_management_request 行

### 2.3 批次十五 §6 待裁项在验收中的处理

| 待裁项 | 验收影响 | 处理方式 |
|--------|----------|----------|
| ① REQUEST_CONFLICT/MANAGEMENT_CONFLICT 不在登记集合 | 测试已断言它们，HTTP 验收可验证；不改变代码 | 标记为"已验但集合待补" |
| ② 请求头元数据 INPUT_INVALID | 框架层 400，非 OBS 业务字段；验收时需携带合法 UUID/修订 | 按现状验收，不放宽 |
| ③ DEPENDENCY_UNAVAILABLE 类内 0 抛出点 | profile 列损坏走 500；验收时用合法 JSON 避免触发 | 标记为"依赖故障未覆盖"，待裁决后再补 503 分支 |
| ④ 设备管理范围 OPERATE vs MANAGE | 影响谁能通过 403/404 分界；验收时用已知有 OPERATE 资格的账号 | 标记为"权限等级待裁"，若裁决收紧需重新验收 |
| ⑤ 无可信操作者身份取 403 | 正常验收路径不会触发；异常路径可用无效 token 测试 | 保持原语义，不擅改 |

#### M02-234 GET /lab/lab/{labId}/check-disable

```http
GET /lab/lab/1001/check-disable

```

**成功响应应核对**：
- HTTP 200，AjaxResult.code=200

| 场景 | 触发方式 | 预期码/HTTP | 说明 |
|------|----------|-------------|------|
| labId 非十进制 | labId=abc | INPUT_INVALID / 400 | 形态校验 |

| 维度 | RESOURCE_FACTS_UNAVAILABLE | DEPENDENCY_UNAVAILABLE |
|------|---------------------------|------------------------|
