## 1. 验证层级口径（AGENTS.md §13.2，禁止笼统"已完成"）

| 层级 | 含义 |
|---|---|
| IMPLEMENTED | 源码已接真实 Controller→ApplicationService→Mapper/Port 链路 |
| CONTRACT_TESTED | 单元/契约测试通过（本处指骨架 501 信封契约测试通过） |
| HTTP_VERIFIED | 真实 HTTP（网关/后端直连）通过，非 Mock |
| BROWSER_VERIFIED | 真实浏览器登录态操作页面抓包通过 |
| NOT_VERIFIED | 尚未在对应层级验证（含仅有骨架/契约证据） |
| BLOCKED_DATA / BLOCKED_MENU / BLOCKED_DEPLOY / BLOCKED_EXTERNAL | 分别因缺主数据 / 菜单 / 运行发布 / 外部参数环境而阻塞 |
