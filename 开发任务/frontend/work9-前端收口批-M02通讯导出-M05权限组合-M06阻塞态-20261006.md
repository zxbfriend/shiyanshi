## 2. 逐任务说明

### 2.1 任务 1：M02-193 通讯导出前端收口

**现状核实**：前端不存在通讯配置列表页（通讯配置仅作为设备编辑器内的 per-device 字段，`/lab/communication/list` 无任何前端调用）。按任务规则「只在现有页面风格下补最小导出入口」，宿主选择**检测器设备管理页**（devdetector-management，其列表已展示 communicationTypes 列，是通讯信息最贴近的既有页面）。

**后端契约对齐**（读 `LabCommunicationApplicationServiceImpl` 确认）：
- 导出实际生效筛选：`deviceId`、`communicationType` + 服务端 VIEW 实验室范围（`currentViewLabIds()`）。
- **`labId`/`deviceKind` 虽在 DTO 中但被静默丢弃**——前端封装的参数类型刻意不含这两个字段，页面调用传空载荷 `{}`，交付口径为「导出按服务端 VIEW 范围收窄；页面筛选不宣称对导出生效」。
- 导出列不含凭据（后端契约原文）。

**测试步骤**（测试 work 执行）：
1. 页面路径：系统设置 → 检测器设备管理；工具栏「导出通讯配置」。
2. HTTP：`POST /lab/communication/export`，头 `Authorization` + `Accept-Language`，Content-Type `application/json`，payload `{}`。
3. 期望：响应为 xlsx 流，浏览器下载「通讯配置_时间戳.xlsx」；提示「通讯配置导出已开始下载」。
4. 无权限账号（无 `lab:communication:export`）：按钮不渲染。
5. 后端未部署/失败：提示后端错误明细（如「未返回可下载文件」/403「没有此操作权限」），**不触发浏览器保存、不提示成功**。
6. 重复点击：进行中按钮 loading，只发一次请求。

### 2.2 任务 2：M05 受控更正权限组合

组合判断在上一批已按 AND 实现，本批补 403 出口并加测试锁定：
- 发起预览/提交：`canPreview = has("detect:correction:submit") && has("detect:sign:sign")`；缺任一权限整个发起区禁用并显示权限警示。
- 决策预览/决策：`canReview = has("detect:correction:review") && has("detect:sign:audit")`；缺任一权限决策区禁用并显示权限警示；提交人本人额外禁用（双人制）。
- 403 处理：六个操作出口统一走 `showCorrectionError()`——403 提示「权限或菜单种子未配置（detect:correction:* / detect:sign:*），请联系管理员开通后再操作」，其余透出后端明细；**不修改后端错误码，不冒充成功**。

### 2.3 任务 3：M06 阻塞态展示

**现状核实**：`/process/approval/*`（请求/动作/审计聚合）与交付对账（reconciliation）在**前端零调用**，无页面可挂；M06 现有页面为审批记录查询（`/detect/approval-record/*`，权限 `detect:approvalRecord:query`）。

本批落地：
1. 审批记录页三个读口（列表/详情/日志）原来**完全没有错误处理**（无 catch，失败时 loading 永久卡死、未处理 rejection）。现统一 async+try/catch，失败经 `m06BlockedMessage()` 映射后 toast，恢复 loading，不打开弹窗。
2. 映射口径（模块内同目录小文件 `m06-blocked.ts`）：
   - 403 → 「审批菜单或权限未配置，请联系管理员开通审批权限」
   - 501 → 「该审计聚合能力暂未接通」
   - 503 → 「外部拥有方回执未接入」（M06-015 BLOCKED_EXTERNAL 的用户可理解表述）
   - 其余 → 后端明细透传
3. 详情/日志入口按 `session.has("detect:approvalRecord:query")` 门控：种子 0 行导致缺权限时按钮不渲染。
4. **escalation_level**：后端未对外投影，页面与 helper 均不含该字段，测试断言其不出现。
5. `/process/approval/*` 与对账入口仍为前端候选入口（未接线），登记 BLOCKED_MENU / BLOCKED_DESIGN，待菜单种子与后端部署后另行接线——本批不做假入口。
