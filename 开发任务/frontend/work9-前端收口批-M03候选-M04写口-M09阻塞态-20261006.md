## 3. 逐任务说明

### 3.1 任务 1：M03 参数候选入口

**不做功能性入口是本批的结论，不是遗漏**：后端 P01 候选固化是内部 Port，无任何 HTTP 端点；P02 APPLY 显式 ACTION_NOT_SUPPORTED。任何"生成候选/应用参数"按钮都会指向不存在的接口。已入库的实现把 P01—P04 渲染为只读提示块（内部已接线/未接线/无回执口径），页面零写请求、零伪造 revision，错误码映射覆盖 VERSION_CONFLICT/STATE_CONFLICT/MANAGEMENT_CONFLICT/APPROVAL_CONTEXT_UNAVAILABLE 等全部关注码。本批独立复核后端论断成立，未改动。

### 3.2 任务 2：M04 模板写口提示与版本身份

- 版本身份：编辑器以 `versionIdentityRows(versionMeta)` 渲染 templateId/versionId/objectVersion/currentVersion 与内容哈希域，操作使用 `form.objectVersion`/`form.currentVersionId` 现值，无硬编码（测试断言 `expectedSourceObjectVersion` 不含字面量版本）。
- 复制（M04-008）：`processTemplateApi.copy` 失败经 `templateErrorMessage` 映射（STATE_CONFLICT/VERSION_CONFLICT/RESOURCE_FACTS_UNAVAILABLE/ACTION_NOT_SUPPORTED 等独立文案）；成功提示位于 try 内 catch 之前，失败路径不可能走到"已保存"提示——**不存在"复制一定成功"的表现**（后端当前无可达成功路径时用户只会看到映射后的失败文案）。
- MANAGEMENT_CONFLICT：按"登记≠可达"口径补入映射与中英文案（M04 写口未守卫化，实际 CAS 口径是 STATE_CONFLICT；若后端后续守卫化，前端无需再改）。

### 3.3 任务 3：M09 阻塞态与重发资格

- 三个告警页（邮件投递列表、短信投递详情、告警记录详情）读口失败统一按 403/501/503 分流：稳定文案 + 其余透传后端明细，页面不崩、loading 恢复、不冒充成功。
- **M09-021 重发**：前端不存在任何重发入口（与 BLOCKED_DESIGN 一致），本批以负向测试锁死三页不得出现 重发/resend/redeliver；后端若未来提供重发接口，须先完成资格裁决再开口。
- M09-011/013/016（501/BLOCKED_EXTERNAL）：501/503 文案明说"后端未接线/外部通道未接通、通知未真实送达"，页面无看似可成功的操作按钮。

### 3.4 哪些只是前端展示

以上全部为**前端提示与调用层收口**：M03 候选不可用、M04-008 复制不可达、M09-011/013/016 未接线、M09-021 BLOCKED_DESIGN、外部通道 NOT_VERIFIED 等**后端事实不因本批改变**。
