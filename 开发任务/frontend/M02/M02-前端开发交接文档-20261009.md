## 4 公共开发契约（FE00）

### 4.1 类型、外壳与请求白名单

- API 相对配置的 `apiBaseUrl`；不要再次拼接未经验证的 `/system`。`/device`、`/lab`、`/detect`、`/resource` 必须在部署代理中可达。工程资料正式路径本身含 `/system/lab/...`。
- 分页通常是顶层 `rows/total/pageNum/pageSize`，详情/候选/写结果通常在 `data`。保留顶层 `managementRevision/requestId/errorCode/fieldErrors/retryAfterSeconds`。不要全部解包成 `data.rows`。
- ID、管理版本及响应中的字符串版本保持字符串，禁止 Number 化 bigint。观测写的 `expectedMappingVersion/expectedProcessVersion` 当前请求 DTO 为 Long，是单独适配项：仅经安全整数校验后按该契约发送；超出 JavaScript 安全整数范围时停止提交并要求后端明确无损传输契约，不静默舍入。Decimal 输入按十进制字符串处理；不把空值转 0、不用浮点运算做业务换算，不静默截断超精度输入。
- 普通日期使用 `YYYY-MM-DD`；查询起日含、结束日次日不含，按 Asia/Shanghai。时刻使用明确时区；不把时间字符串当本地无时区时间重新解释。
- 型号/实验室分页选 10/20/50/100；其他接口遵守自身 DTO。游标观测接口独立处理，不能套 pageNum。
- UI 模型、读取模型、提交模型分离。审计、状态派生、字典 label、`allowedActions`、候选缓存、UI 临时 ID 不回传。
- 路径有 ID 时通常不在 Body 重复；M02-051 差异单独处理。附录 C 中 DTO 的 `requestId/managementRevision` 多为后端注入字段，不是允许提交整个 DTO 的依据。
- 字段省略、null、空串、false、0 分别处理。部分更新仅在正式接口允许时使用；整组覆盖保存必须提交完整集合。

### 4.2 管理写与恢复

普通管理写显式携带 `X-Request-Id: UUID`、`X-Management-Revision: 当前版本`。工程资料 M02-226 是例外，元数据在 Body：`requestId/expectedManagementRevision/expectedProfileVersion`，不能只加 Header。

| 场景 | 前端处理 |
| --- | --- |
| 打开编辑 | 加载当前详情、候选和该业务读出口的版本；未成功加载不可保存 |
| 提交 | 固定载荷、版本、requestId；防重复点击；不同逻辑操作使用不同 requestId |
| 成功 | 读取实际回执及新版本，回读核对，才提示保存成功 |
| MANAGEMENT_CONFLICT / VERSION_CONFLICT | 保留非敏感草稿，刷新详情与候选供比较；用户确认后作为新操作提交 |
| REQUEST_CONFLICT / REQUEST_ID_CONFLICT | 提示请求标识冲突，停止自动重试；不自行换键绕过未知结果 |
| 超时、网络中断 | 显示结果未确认；对明确支持幂等重放的管理写可用原键、原版本、原载荷核对；不得更换请求键重发 |
| 物理命令结果未知 | 按 M07 命令身份查单；绝不套管理写重试策略再次发送设备指令 |
| 400 | 显示字段错误，定位对应表单/数组行；不清空草稿 |
| 403/404 | 清理失权对象和旧候选；404 不区分不存在/无对象范围 |
| 409 RESOURCE_IN_USE / REFERENCE_EXISTS | 展示可公开的阻断原因；不提供“强制删除/释放”绕过按钮 |
| 501、503、依赖状态 UNKNOWN | 显示暂不可用/待联调；不转成空数据、空闲或成功 |

管理页可能共用 SYSTEM 管理版本，无关页面修改也可能使当前草稿过期。禁止借其他页面的新版本提交旧草稿。

| 业务 | 应读取的版本上下文 |
| --- | --- |
| 实验室 | 本页 M02-228/231；负责人编辑同时读取当前负责人 |
| 型号与实例 | 对应当前列表/详情/编辑候选实际发布的 managementRevision；SDK 透传，拿不到版本停止提交并登记后端问题 |
| 默认连接、打印排版 | M02-109、111 当前聚合读响应 |
| 控制器能力 | M02-254 当前能力视图 |
| 通讯 | M02-206/207 当前配置读响应；无配置时用该读上下文 |
| 检测运行配置 | M02-170 的管理版本，加 data.profileRevision 作为 expectedProfileRevision |
| 实例检项、检测规则 | M02-212、215 当前配置视图 |
| 消耗配置、液瓶 | M02-241、251 当前配置/布局上下文 |
| 观测映射 | M02-006 管理版本及目标映射版本，不能互相替代 |
| 工程资料 | M02-225 顶层/行管理版本与 objectVersion；不能用 versionNo 或 versionId 代替 objectVersion |

### 4.3 权限、状态与候选

- 功能权限决定动作；实验室范围决定对象。可见等级 0、操作等级 1、管理等级 2。液瓶写和实例工程资料需要管理等级 2；型号全局维护权限不能代替实例实验室权限。
- `allowedActions` 用于界面显示，不替代后端校验。切换实验室、型号、设备后取消旧请求，拒收旧上下文回包。
- 实例编辑优先使用本类 `edit-options`，不拉完整用户或设备列表冒充候选。保留当前失效引用以只读形式显示原因；禁止自动选列表第一项替换。
- `Option={id,label,disabled,disabledReason,children}`；`ReferenceOption={id,label,kind,role,available,unavailableReason}`。同一数字 ID 在不同类型表可重复，引用键必须含 kind。
- `maintenance`、`occupancy`、`connectivity` 分列：维护、IDLE/RESERVED/IN_USE/UNKNOWN、ONLINE/OFFLINE/UNKNOWN。`configurationReady` 是配置完整性；均不能相互推导。
- 删除预检只辅助确认；提交仍可能失败。批量全成全败，刷新后保留仍有效选择，不静默跳过失败项。
- 页面必须有加载、无数据、无实验室权限、加载失败、配置缺失、只读、提交中和结果未知状态。图标需有文字/tooltip，键盘可操作；状态除颜色外还显示文字。

### 4.4 提交示例与适配要求

以下只演示 JSON 形状，数字 ID 为隔离测试夹具；运行时用实际详情/候选和当前版本替换，requestId 每个逻辑操作生成一次。

**实例项目开关（差异保存）：**

```http
POST /lab/detectorconfig/4005/batch-save
X-Request-Id: <本次操作UUID>
X-Management-Revision: <本设备当前配置读版本>
Content-Type: application/json

{"items":[{"itemId":"7001","enabled":false}]}
```

成功从 `data.items` 读取完整当前集合及新管理版本；不得仅将提交的一个项目替换整张表。

**控制器能力（省略其他能力即保留）：**

```json
{"mfcCount":2,"thresholdWeightG":"10"}
```

发送到 `PUT /lab/pumpconnection/{connectionId}/capabilities`，携带管理写头；不在Body填connectionId或用null清空其余布尔能力。

**工程资料撤销（版本在Body）：**

```json
{
  "requestId":"<本次操作UUID>",
  "expectedManagementRevision":"<225读取的管理版本>",
  "expectedProfileVersion":"<225读取的objectVersion>",
  "scope":{
    "kind":"MODEL",
    "modelKind":"INTEGRATED_MODEL",
    "modelId":"2002",
    "deviceKind":null,
    "deviceId":null
  },
  "action":"REVOKE",
  "reason":"<实际撤销原因>",
  "profile":null,
  "evidence":null
}
```

该形状仅说明226契约，不代表测试环境已部署，也不能用占位值调用。保存草稿/核准需要完整对应载荷，不能复用撤销的null正文；已有资料回填受BE06限制。

### B.2 响应使用要点

| 视图 | 前端消费方式 |
| --- | --- |
| 型号列表/详情 | 各类独立主键+业务字段+只读兼容字段；不要套通用id，更不要把整个响应作为保存Body |
| 实例列表/详情 | 字段平铺，含labName、负责人显示名、审计和三维状态。集成实例列表省略pumpConfigs/externalPumps，编辑必须读取详情 |
| 编辑候选 | models/owners/venues/references及版本；区分disabled与available，显示对应原因 |
| 删除预检 | allowed/reasonCodes/referenceCount/managementRevision；allowed=false即阻断，不将HTTP200视为可删除 |
| 唯一预检 | data.unique；仅辅助提示，正式提交再校验 |
| 工程资料 | 当前读为顶层rows，正文未回填；写为data结果。按BE06处理差异 |
| 通讯 | desiredRevision/appliedRevision/applyState与配置问题分开；has*状态代替秘密明文 |
| 液瓶 | 布局与观测分别呈现，readingQuality/observedAt不能丢；editable为服务端结果 |
| 消耗 | quantity=null为NA；resolvedQuantity与configurationIssue是只读结果 |
| 观测 | 历史为游标快照语义；当前值、详情、维护收件不能混成普通分页接口 |
