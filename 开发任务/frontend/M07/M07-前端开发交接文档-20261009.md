- 编写日期：2026-10-09；代码基准：本地 `cloud@a1a54bcb`。
- 依据：当前需求/详细设计、M07 专题契约、实际 Controller → ApplicationService → Mapper/Port，以及前端源码。
- 本次仅静态核对与文档检查；未运行构建、单元测试、数据库、HTTP、浏览器或真实设备。旧交付记录的测试结果不作为本次执行证据。
- 本文是开发交接，不修改业务裁决。功能目标和当前实现分开登记；接口已接线不等于完整可用，模拟数据也不构成设备验收。

## 1 阅读顺序与交付方式

1. 前端负责人先读第2—4节，确定路由、共用 SDK 和可先开发的页面。
2. 开发按第5节逐项实现；第6节的 BE 编号是后端交付依赖，不能靠页面补默认值绕过。
3. 附录A逐项映射35项设计接口；附录B/C列出当前 Java 请求/响应模型及嵌套字段；附录D列枚举。
4. 测试按第7节验证。页面/接口/设备分别验收，保留原请求与命令身份。

本文中的001等短编号均指 M07-xxx。目录 API32.1/32.2 对应032/033，API33.1/33.2对应034/035，不能把目录小节号当成接口编号。

## 4 公共协议、状态与权限

### 4.1 请求与版本

复用client/会话/网关前缀，不硬加`/system`。路径ID来自已鉴权对象，Controller将`{id}`写入DTO的id，服务优先使用id；页面不重复提交矛盾的taskId/cultureId/confirmationId。工作流步骤路径同时绑定id和stepId，不能把定义步骤ID当运行步骤实例ID。

| 操作组 | 当前协议 | 所需版本与限制 |
| --- | --- | --- |
| 018/019/020 | 已有ManagementGuardedWrite；X-Request-Id、X-Management-Revision头权威回填 | 018/019管理版本读017；020读021；Body不复制头元数据 |
| 019 | Body expectedRuntimeVersion | 必须是M07 runtime版本；M03培养版本/managementRevision/sourceVersion均不能代替，目前出口缺失BE05 |
| 020 | Body expectedVersion | 必须是确认对象objectVersion；当前021未填充，不能写死1或客户端自增 |
| 004 | 目标为只读预检POST | 不创建任务/占资源，不提供未来资格保证 |
| 005—010、023、025—028、033—035 | 当前只有骨架，未接守卫写与对应读管理版本 | 目标按WriteMeta/对象CAS；待后端同时补齐，不能把DTO的requestId存在当Header已生效 |
| 003/016 | 无当前入口 | 先补后端契约与实现，不绕到旧增量接口 |

管理版本是017/021成功响应的**顶层**字段。缺失时关闭提交；与业务对象版本分别存储。不要从M01/M03无关页面借revision。一次明确意图一个requestId，超时核实保留原ID/载荷；内容改变需重新读状态、明确确认后发新意图。当前缺少覆盖所有M07写的按requestId恢复读口（BE05/11），不能承诺刷新后自动恢复所有请求。

### 4.2 类型、单位和时间

- ID、业务Version、fence、epoch保留字符串，禁止转JS Number。当前公共Jackson还将Long（含total/remainingSeconds/时长/序号）序列化为字符串：小范围计数经格式和范围检查后才转换用于分页/计时。
- 设计要求Decimal用字符串；当前M07多数VO用BigDecimal且未见统一BigDecimal字符串序列化。表单保留十进制文本、单位和精度；联调需BE13固定无损传输，不承诺把JSON Number转回字符串能恢复已丢精度。
- 重量/累计g，浓度g/L，公式净体积L=g/1000；Speed1—10是设备代码，不换算rpm/g/min。初始量g/kg展示随M03规则，累计量始终g。
- 设计时间是ISO8601带offset、日期Asia/Shanghai；当前Jackson对OffsetDateTime输出`yyyy-MM-dd HH:mm:ss`且不转换其偏移，M07服务多处以UTC构造OffsetDateTime。**无偏移时间不能直接按浏览器本地时区解析**。BE13要求与公共协议负责人统一传输时区并提供真实响应；不能无依据追加+08:00。
- 查询LocalDate仍传`YYYY-MM-DD`。确认业务日以服务器上海日为准，不按浏览器所在地日期判定。倒计时只使用服务端remainingSeconds；0只显示待服务端处理，不改CONFIRMED。
- null/缺字段显示“未取得/待核验”，真实0正常显示；糖耗可为负，不取绝对值。量、来源时刻、质量和单位同屏展示，旧/缺样本留断点。

### 4.3 状态必须分栏

| 维度 | 值/解释 |
| --- | --- |
| businessState | PENDING_REVIEW待审核、PENDING_APPROVAL待批准、READY待执行、REPAIR_PENDING_REVIEW执行出错待审核、EXECUTING执行中、ERROR执行出错、ERROR_HANDLED处理已登记、EXECUTED已执行、CANCELLED已取消、DAY_CANCELLED跨天取消、PAUSED暂停中 |
| baseState | 原任务底层状态；有候选时不由浏览器覆盖原参数 |
| physicalPhase | NOT_STARTED/STARTING/CALIBRATING/HIGH/LOW/PAUSE_REQUESTED/PAUSED/STOPPING/STOPPED/UNKNOWN |

### 4.4 权限与异常

目标写资格=功能码∩实验室OPERATE∩M03当前有效MEMBER∩对象状态/版本；SHARE和VIEW不授予写权。读取合并实验室VIEW与M03可读培养范围。013/014/031权限由服务端按执行来源推导task:query或workflow:query，不能让客户端任选一个。

源码差异：018/019的requireCultureInRange目前用VIEW/visibleCultureIds；020把resolveScope“存在可读范围”的boolean当成allAccess，可能不下推范围，且未补齐OPERATE/MEMBER。必须BE07修复并做失权用例，前端隐藏按钮不能弥补后端授权。

| 错误/状态 | 页面行为 |
| --- | --- |
| INPUT_INVALID/400 | 字段定位，保留非敏感草稿；不吞错误当空列表 |
| PERMISSION_DENIED/403、NOT_FOUND/404 | 清该对象敏感缓存；上下文失权关闭整页，历史权限不提升当前操作资格 |
| MANAGEMENT_CONFLICT、VERSION_CONFLICT | 重新读取同一对象/管理版本，展示差异后明确提交；不自动覆盖 |
| REQUEST_CONFLICT | 原键异载荷冲突，核查原意图；不能换UUID绕过 |
| STATE_CONFLICT、RESOURCE_IN_USE | 刷新任务/确认/资源事实，解释状态或占号冲突；不自动释放资源 |
| CONFIGURATION_INCOMPLETE | 缺runtime/方案/能力等，定位未就绪原因；不在前端补默认运行行 |
| CALCULATION_PRECONDITION_FAILED/422 | 已核准数据不满足公式，展示缺项/定义域；不补0计算 |
| DEPENDENCY_UNAVAILABLE/503 | 组件显示依赖不可用，保留其他有效区域；不等于无候选或未执行 |
| THRESHOLD_UNVERIFIED | 动态补糖阈值待核准，不能设0放行 |
| 501 | 功能尚未接入；不能显示成功或“暂无数据” |
| 超时/UNKNOWN | 原请求/原命令结果待核对，不自动重发物理动作，不因关页面释放资源 |

034/035权限run:handover:submit/review，当前Controller也待补正式鉴权。提交冻结cultureId、expectedRuntimeVersion、baselineSnapshot；显示cutoverAt、currentWeightG、累计补/取、各袋session/实例/初始/剩余/皮重/单位、sourceWatermarks、真实dayStart证据。未知不可填0；旧BatchID不能直接当新batchId。

## 附录B 当前请求DTO逐字段

这里只列当前33个入口实际使用的请求类型。id/stepId/resourceKey等路径字段由Controller绑定；不当作额外可编辑业务字段。GET其余字段在Query；POST其余业务字段在JSON。018—020的requestId/managementRevision由Header权威回填，前端Body省略；其余骨架字段只是后续目标，并非已实现守卫协议。

字段Java类型是源码类型，不直接等于HTTP JSON类型；String字段的“必填”以正文业务规则/最终服务校验为准。未标NotNull不等于业务可省；有DTO也不等于方法已实现。说明列摘录源码字段注释，其中ISO格式等目标描述仍须结合第4.2节的当前序列化差异阅读，不能覆盖BE13。
