# M01—M09 前端页面任务清单与开发顺序

核对日期：2026-10-15（Asia/Shanghai）。项目：`yaoming_shengwu`。

**结论：当前项目已具备较多基础管理页和部分运行业务页，前端工作重点是补齐正式契约、完善关键业务页面、完成真实联调。后端正在从接口和受管写入实现推进到业务闭环，仍有明确拒绝的分支，不能据接口数量或 `wired` 状态给出整体完成率。**

项目主线是：实验室/设备/人员基础 → 项目、批次、培养 → 工艺模板与工作流配置 → 检测及结果签批 → 业务审批/来源应用 → 补液运行与任务执行 → 告警通知。你这次要做的是把这些能力落实到可操作、可追溯的前端页面，而不是重新建设底层服务。

本文给出 **144 个页面或独立交互面核对项**，包括共用组件、范围确认和延期项。它们不是144个独立URL；M02-P38/M04-P09等明确共用的条目不重复计工作量。文末按开发批次给出执行顺序与验收清单。
