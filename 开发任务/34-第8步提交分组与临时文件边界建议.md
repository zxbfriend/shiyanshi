## 4. 环境/脚本风险登记：git 中文路径输出编码（31 审计 P2-5）

- 现象：`git status`/`git diff --name-only` 将 `docs/开发任务/…` 中文路径输出为 GBK 乱码八进制/转义序列（core.quotepath 与 Windows 控制台代码页叠加）。
- 定性：**非文件损坏**（UTF-8 路径可正常读写，31 审计已验证）；列为环境/脚本风险，**不阻断第9步**。
- 建议：后续脚本化处理 git 输出时不得依赖终端显示文本解析路径（可用 `git -c core.quotepath=false`、`--porcelain -z` 或改从清单 JSON 取路径）；如需可全局确认 `i18n.logOutputEncoding`/`core.quotepath` 配置。本文档生成过程未修改任何 git 配置。
