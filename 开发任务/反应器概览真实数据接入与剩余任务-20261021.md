## 2. 权限与完整性约束

- 在线观测要求 `lab:observation:query`，读取培养绑定还要求 `resource:culture:query`；没有后者时不发起绑定请求并说明缺少依赖权限。
- 在线名称/单位配置读取要求 `alarm:onlineConfig:query`；缺少权限时沿用观测读取器的检项 ID 标识与提示，不猜名称或单位。
- VCD 要求 `detect:workbench:query`，培养记录和批次对比要求 `resource:culture:list`，任务查询要求 `run:task:list`。保留后端数据范围过滤和前端实验室/培养匹配。
- 培养和检测列表沿用每页 100 条、最多 20 页的完整读取保护。分页不完整、请求失败或超过 2000 条报错，不能显示部分结果为完整记录。此保护不等同于后端提供跨页一致性快照。
- 不修改角色授权、历史数据、培养配置、流程配置；不新增接口或表，不发送设备操作。

## 3. 待安排的后端任务与业务确认

下面字段是建议补齐的能力，不是已经生效的接口契约。需要先确认口径，再落契约与实现。

### ROV-01：台式反应器在线测点与培养的可靠关联（M02 / M03，优先）

- **已有实现**：观测查询、培养绑定、在线检项配置读口均存在，本次已接线。现行普通关联自动发布只明确支持集成反应器的 floor_scale_id 与同实验室已核准地秤通道。见[培养关联契约](../详细设计/03-项目与培养管理/观测时培养关联与历史修订契约.md)“2026-10-14 普通关联自动发布”；其他缺少明确测点连接的种类保留 UNKNOWN。
- **缺什么**：台式控制器 pH、温度、氧气等测点的明确设备/通道/检项/培养关系及可靠发布链；有效起止时间、当前关联状态、测量时间、单位、质量与过期事实。不得从设备名称或全部控制器通道推测关系。
- **影响**：前端读口已接通，仍可能无有效当前值，概览显示 `—` 和缺少绑定提示。
- **需确认**：由谁核准设备测点与检项映射；台式控制器哪些通道属于该培养；缺映射时维持 UNKNOWN。有既存正确映射的先按现有管理流程配置，无需重复开发查询口。
- **验收**：同控制器多个培养不会串值；更换培养、关联冲突、隔离、过期数据不显示为当前有效值。

### ROV-02：真实培养体积及液位投影（M02 / M07）

- **已有接口**：设备读口返回规格/最大容量，M07 计量余额已返回 `currentNetGrams` 和 `currentVolumeLiters`；本次保留远端新增的体积读取，要求培养匹配且无 netWeightIssue。净重仍按克显示。
- **缺什么**：无需重复新增当前体积字段；需确认现有体积来源、观测时刻、质量/过期状态能否满足验收，以及容量和体积的适用口径。若由质量换算，需核实后端已核准密度、适用条件和算法版本。
- **影响**：沿用接口有效体积；缺值时保留未知状态，不将 1 g 直接当作 1 mL。
- **需确认**：显示实测体积还是核准换算体积；容量依据罐体规格还是培养工作体积；无数据时保留示意图。
- **验收**：已知值、真实 0、未知和过期可区分；容量与体积单位一致；来源和时间可追溯。

### ROV-03：当前培养天数 Dn（M03 / M07）

- **已有接口**：培养列表/详情有计划开始日期和计划周期；生产过程接口可提供培养实际开始证据。运行候选 DTO 声明过 dayCount，但本次未找到可直接用于所有概览培养的稳定赋值投影。
- **缺什么**：服务端统一的当前培养天数及计算依据（实际开始时刻、业务日期/时区、D0/D1 规则、结束后是否冻结），并覆盖概览所有可见培养。
- **影响**：概览不把计划周期当当前天数，也不按浏览器时钟自行计算 Dn。
- **需确认**：实际开始当天为 D0 还是 D1，跨日边界，延期/暂停/已结束时的展示规则。
- **验收**：计划与实际开始不同时以确认口径计算；跨时区访问显示一致；未开始不冒充 D0。

### ROV-04：工作流角标数量口径（M03 / M04 / M07，先业务确认）

- **已有接口**：`GET /run/workflows/candidates` 提供运行候选，`GET /run/workflows/{id}` 提供实例详情；`GET /run/cultures/{id}/production-process` 提供带权限的生产过程历史，其中包含 WORKFLOW 节点。实验室与培养流程配置也已有读口。
- **缺什么**：角标究竟表示“已配置入口数”“当前可执行入口数”还是“已有实例数”的确认。生产过程是历史分页查询，不提供全局一致快照，不能直接视为当前可执行流程数量。若需稳定、多培养计数，建议补按可见培养聚合的计数投影，明确状态范围、隐藏流程排除规则、时刻与部分失败状态。
- **影响**：入口可使用，数量保留 `—`，不填固定 12 或把任务数冒充流程数。
- **需确认**：选择计数口径；若是历史实例，是否包含已结束/取消；W04、废液清理及已暂停入口继续不展示。
- **验收**：计数与点击后的同口径列表一致；未授权对象、跨实验室对象不计入；读取失败不显示 0。

### ROV-05：跨批次检测趋势/统计比较（M05 / M08，范围待确认）

- **已有接口**：培养列表支持基础配置/状态对照；M05 有检测结果，M02 有单通道观测历史。
- **缺什么**：跨批次比较的指标集合、单位归一、按培养日或实际时刻对齐、有效检测/修订/作废规则、缺失数据规则，以及带权限的聚合/分页能力。
- **影响**：当前仅展示真实基础信息，不绘制假趋势或统计值。
- **需确认**：先保留基础对比，还是将高级统计纳入后续排期。仓库当前 M08 延后，不在本轮自行扩大范围。
- **验收**：相同指标才比较，单位和对齐基准明确；无权限培养不进入任何汇总。

### ROV-06：历史设备归属（M03，按业务需要确认）

- **已有接口**：培养列表有当前可返回的 device.ref，当前按 device kind + id 精确筛选。
- **缺什么**：若“某反应器培养记录”要求包含培养曾经使用过该设备、后来又更换设备的情况，需要设备绑定历史的有效期投影/查询。现有列表字段不足以证明所有过去归属。
- **影响**：实验室级可见培养记录已可查看；不承诺当前 device.ref 能覆盖所有历史更换关系。
- **需确认**：按当前/保存的设备归属查看是否足够，还是需要完整使用历史。

### ROV-07：概览批量查询和快照能力（M02 / M03 / M05，优化项）

- **已有接口**：上述逐培养绑定/当前观测/检测列表/明细读口，本次已限并发并使基础卡片优先呈现。
- **缺什么**：大量培养时可选的批量最新指标投影；返回 cultureId、itemId、有效值/单位/时间/质量、来源 ID、不可用原因及读取范围/快照标识。列表分页如要求一致性保证，需服务端稳定排序/快照或明确重试语义。
- **影响**：现有接口可用，但培养较多时补充指标仍有请求数量和等待时间；超过完整读取保护上限会报错。
- **需确认**：是否按实际容量安排优化，不将其列为小规模概览使用的前置接口。
