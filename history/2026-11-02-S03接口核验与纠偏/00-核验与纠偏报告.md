### 5.1 前端消费者核对方法（本轮新建，修正了前版误配）

前版 `consumer_v2.mjs` 存在**跨对象误配**：路径段数相同时用 `*` 互配，导致 `GET /run/confirmations/{id}` 匹配到 `runMeasurementApi.cancelConfirmation`/`detail`，把大量无关页面文件计入「页面在用」，输出膨胀到 375KB。本轮重写为 `consumer_v4.mjs` ＋ `sdkurl.mjs` ＋ `gateway.mjs`，修正四点：

1. **对象式 API 按 `objName.fname` 精确匹配**，不再因同名方法跨对象互配；
2. **路径段匹配只在「两边同为模板变量段」或「字面全等」时成立**，不再用 `*` 双向互配；
3. **SDK URL 提取支持四种形态**：字面量、字符串拼接（`"/x/" + encodeURIComponent(id) + "/y"`）、模板串（`` `${base}/x` ``）、**基址常量替换**（`const base = "/system/data/statistics"`）；`request({url:…, method:…})` 对象形态用**括号配平**取 `url` 值，避免被后续 `method` 截断；
