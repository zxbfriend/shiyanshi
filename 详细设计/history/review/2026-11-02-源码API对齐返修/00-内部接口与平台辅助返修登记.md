## 1. 接口性质统一口径（与主分类 A—F 正交）

主分类（A 已登记一致 / B 专题在册缺入口链接 / C 源码真实存在设计未登记 / D 设计与源码实质差异 / E 设计要求存在但实现缺失 / F 停用·替代·延期·范围外）**只回答"设计与实现的关系"**；本轮另立独立的**接口性质**轴，六选一：

| 性质 | 判定条件（源码事实） | 计数落处 |
|---|---|---|
| 公开 HTTP | 类级 `@RequestMapping` 或方法级 `@GetMapping/@PostMapping/@PutMapping/@DeleteMapping/@PatchMapping` 存在，且无 `@InnerAuth`、不属 `/internal/**` 内部段 | 计入源码唯一路由 1045 |
| 受控内部 HTTP | 同上带映射注解，但由 `@InnerAuth`（from-source=inner）或设备验签（`X-Adapter-*` HMAC）界定访问方；`/internal/**` 9 条 + `@InnerAuth` 非 internal 段 5 条 | 计入 1045 |
| Java Port | `service/port/**` 下的 `public interface`，无任何 Spring 映射注解 | 独立另册 155 |
| Feign 声明 | `futurefab-api` 中 `@FeignClient` 接口及其方法 | 独立另册 4 接口/12 方法 |
| 后台消费者 | `@Scheduled`/`@EventListener`/Quartz 反射任务/命名管道监听线程等非请求入口处理器 | 独立另册 41 类/43 方法（另册 2） |
| 非接口辅助 | DTO/VO/实体/Mapper/Service/advice/handler/标记注解/出站客户端/legacy wrapper/测试类/常量枚举 | 独立另册（枚举 21 项 + 余量估算） |

三条硬规则：

1. **有 Spring 映射注解就是 HTTP 接口**。`@InnerAuth`、`@RequiresPermissions`、网关 `BlackListUrlFilter`、"只被内部服务调用"、"不自动开放浏览器 HTTP"等都是**访问边界或部署属性**，单独记录，不改变"它是 HTTP"的性质，也不得据此把它算进"非 HTTP 入口"。
2. Java Port / Feign 声明 / 后台消费者 / 非接口辅助 **不重复计为公开 HTTP，也不计入 HTTP 核查漏**（既不加进 1045，也不因它们存在就声称公开接口更多）。
3. **平台辅助、停用/被替代/延期条目不得留在 E**：E 仅表示"现行有效设计要求存在且实现链缺失"。范围外一律 F 并写明业务范围（平台辅助 / AAD 延期 / ~~M08 延期~~ / DISABLE 身份 / 旧实现层待治理）。**（返修合并批更正：用户 2026-11-02 明确 M08 不再延期，"M08 延期"自此不再是合法的 F 业务范围取值；M08 条目须按 V5.1 原文与有效澄清逐条判本期范围，见《01-返修总修正与跨模块合并》§4.1.1 与 `08-M08范围改判返修记录.md`。）**

## 4. 跨模块通用 E 排查规则与其他候选清单

### 4.1 规则（五项全查完才允许留在 E）

对每一条拟判 E 的设计接口，按顺序核验并把结论写进对应模块登记：

- **(a) 专属方法是否存在**：在承载该前缀的 Controller 内检索方法级映射；同时检索全仓路由底账，避免"类找错→以为没有"。
- **(b) 设计 URL 能否被源码通用路由匹配**：把设计路径的 `{var}` 实例化为一个具体值，逐条用源码路由做段级匹配；**字面段必须相等**（`/run/workflows/{id}` 不匹配 `/run/task-candidates/resources`）；变量段可匹配任意单段（`/resource/{type}/{id}/exit` 匹配 `/resource/project/123/exit`）。同时按《90》§2.3 N3 处理字面 `/system` 双形态。
- **(c) 设计身份是否已停用/被替代/属延期**：`DISABLE`/`DEPRECATED`/AAD 另案一律不得判 E，改 F 并写接管身份或业务范围。~~M08 延期~~（2026-11-02 更正：M08 已纳入本期，不得再以"延期"排除；见 §3 规则 3 与《01》§4.1.1）。
- **(d) 通用入口是否实际支持该类型或子资源**：类型开关必须核到枚举/常量与分支（如 `TYPE_PROJECT="project"`），不能只看路径模板。
- **(e) 请求体、权限、响应语义是否对应**：核验幂等键/版本头、错误码与 CAS/事务语义是否与契约同形；同名不同义按 D 并列，不同名同义按别名归并到同一身份。

判定后落处：(a)—(e) 全为"否"→ 可留 E；任一为"是"→ 按别名/D/F 改判，并在模块登记写明依据行号。
