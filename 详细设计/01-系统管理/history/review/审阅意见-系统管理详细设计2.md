## 2. P1 项（签署编码前必须闭环）

### P1-A 场地/部门编码唯一性口径不一致（本轮新发现）

| 来源 | 口径 |

| 澄清决策记录 | "场地编码全局唯一 vs 部门同级唯一…已开发完成，按已实现口径处理" |
| 基线库实况（已核实 ymsw.sql） | `sys_dept`/`sys_venue` **没有任何编码唯一约束**（仅主键）；只有 `sys_group` 有 `uk_sys_group_name_del/code_del`（ymsw 3258/3259 行） |

影响：若目标库现存数据有跨层级重复编码（基线不阻止，很可能存在），04 preflight 直接阻断迁移。需要评审拍板：

- 若确认全局唯一 → 迁移说明必须补"现存重复编码的显式处置方法"（preflight 只报错不清洗，符合规范，但缺处置指引）；
- 若按需求同级口径 → 两个全局唯一键要改成 `(parent_id, active_*_code)`，04 的 preflight 与 API 错误文案同步改。

### P1-B `sys_user_password_history` 新行 id 生成规则未钉死（复核第一轮 P1-2，属实）

字典 3.19 只写 `id varchar(20) 主键`；DD01 的 BASELINE 行用 `LEFT(SHA2(...),20)`，但 SELF/ADMIN_RESET/INITIAL_CREATE 新行的 id 谁生成、什么格式，设计和字典都没写。建议明确：雪花 ID 字符串（确认 ≤20 位）或独立规则，写进字典 3.19 / 设计第 9 节。

### P1-C M02 `LabAuthorization` 契约未实现但已被 USR 依赖（复核第一轮 P1-3，属实）

用户新建/编辑的 `authorizedLabIds` 闭环依赖 `prepareUserEdit/replaceUserLabs/removeUserLabs`（详细设计 967–969 行），M02 详细设计尚未完成。建议 §25 验收矩阵将 USR 授权相关用例标注"待 M02 联调"，并写明联调前的降级策略（仅持久化不校验，或字段暂不开放）。

### P1-D 单 SYSTEM 管理版本行全局串行所有管理写（复核第一轮 P1-1，属实）

详细设计 811 行已自认"需压测后再决定是否拆分守卫"。评审应明确压测时点和拆分触发条件（如按对象类型分 `scope_key`），避免"需压测"成为长期开放项。

## 4. 复核确认正确的关键点

1. **锁定阈值完全对齐**：需求 01-941"15 分钟错误超过 6 次锁定"→ 设计"第 7 次锁定"；需求 19-62 旧密码"超过 5 次"→ 设计"第 6 次锁定"；与 Q41"5 次/6 次有意设计，两处按原文分别执行"逐字吻合。
2. **密码长度 10–18**：需求正文 10-16 与截图 10-18 冲突，澄清决策明确"定为 10-18，正文需修订"——设计取 10-18 正确；"连续"≥3（含递增/递减、case-folded）与决策一致。
3. **单终端**：需求 942"又登录另一台设备，之前的登录会被退出"→ 设计 last-login-wins + `SESSION_REPLACED`，方向一致。
4. **初始密码闭环**：123456 初始（01-755）+ 首次/重置后强制改密（01-970）+ 重置回初始密码（01-809）→ `is_initial_password` + `ADMIN_RESET` + 强制改密，对齐。
5. **有效期**：需求 90 天/提醒 1–15 天（01-913/926-927）→ 全局 `sys_config` 1–100/1–15、旧 0 经评审转 90；per-user `password_valid_days` 明确只读兼容、全局优先（字典 304、设计 75 行），处理得当。
6. **MAC 预留**：决策"保留字段允许为空"→ `mac_address` 可空，一致。
7. **基线事实核对**（均已在 ymsw.sql 实证）：
   - `sys_menu.menu_i18n_key/api_path` 基线已存在（ymsw 3655/3675 行），迁移不加属正确而非遗漏；
   - `sys_group` 索引名与 04 的 `DROP INDEX uk_sys_group_name_del/code_del` 一致（ymsw 3258/3259 行）；
   - `sys_user_password_history.id/user_id` 基线为 varchar(20)，与迁移改型一致（ymsw 5695-5702 行）;
   - `sys_config` 四键基线状态（`passwordValidateDays='0'`、`initPasswordModify='1'`、其余两键不存在）与 DD01 处理一致（ymsw 2823-2825 行）。
8. **22 表 242 列**：对 07 DDL 逐表独立计数，与设计 §25 自述一致。
9. **迁移工程**：preflight 遇错即停、`@reviewed=0` 防误跑开关、LIKE 原样备份、回退保留失败版本不 DROP、核验只读且不输出口令摘要、bcrypt 不在事务内比较——均符合编写规范 §3，且与 02 总体设计"迁移带版本号、前置检查、备份和回退说明"一致。
10. **安全底线**：口令/令牌/挑战/密钥不进日志；`authProof` 仅服务端持有；敏感 Body 用 HMAC 指纹；登录短时回执不可凭 requestId 取他人会话（设计 555 行）。
