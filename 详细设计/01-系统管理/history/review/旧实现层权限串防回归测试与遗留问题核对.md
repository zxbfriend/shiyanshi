- 依据提交 `0961487b`：修复 `SysUserLabController`、`SysUserPasswordHistoryController` 中 `@RequiresPermissions` 值尾部残留的 `')`（例如 `system:userlab:list')`），该脏串导致权限串无法与菜单权限匹配，非超管恒被拒绝。

- 本轮范围：补防回归测试 + 最小链路核查。不含重构、不含表结构、不含前端。

## 4.1 LEGACY-PERM-03 处置记录（2026-09-29 后续轮，状态 IMPLEMENTED + CONTRACT_TESTED）

修复方式（最小改动，只动实体的注解与 `toString()` 输出一行，未引入 VO/DTO 白名单）：

- 文件：`futurefab-modules/futurefab-system/src/main/java/com/futurefab/system/domain/SysUserPasswordHistory.java`
- `password` 字段改为 `@JsonProperty(access = JsonProperty.Access.WRITE_ONLY)`，并移除 `@Excel(name = "加密后的密码")`（该实体无导入入口，`ExcelUtil.getFields()` 只收集带 `@Excel` 的字段，去掉注解即从表头与数据列消失）。
- `toString()` 移除 `.append("password", getPassword())`，日志打印实体不再带出摘要；`getPassword()/setPassword()` 保留。
- 未采用 `@JsonIgnore` 的原因：`@JsonIgnore` 会同时屏蔽入站反序列化，导致 `POST/PUT /system/pwdhistory` 无法写入 `password`，破坏持久化写路径；`WRITE_ONLY` 只屏蔽出参。
- 出参结果：`list`/`getInfo` 的 JSON 不再输出 bcrypt 摘要，`export` 不再输出「加密后的密码」列，`toString()` 不再 `append("password", ...)`（日志面）；入站绑定与 MyBatis 映射（`resultMap column/property="password"`、查询列清单、`#{password}`）保持不变，Controller → Service → Mapper/XML 链路未改动。

## 4.2 LEGACY-PERM-04 处置记录（2026-09-29 后续轮，状态 IMPLEMENTED + CONTRACT_TESTED）

修复范围只限 `saveSysUserLabs` 返回值语义；未处理菜单权限种子（LEGACY-PERM-01，仍 **BLOCKED_MENU**）、未处理 `DELETE /smp/userlab/{userIds}` 删除粒度（LEGACY-PERM-05，仍 **NEEDS_DESIGN_CONFIRMATION**）；未改前端、未改数据库结构。

修复方式（最小改动，3 个源文件）：

- `service/impl/SysUserLabServiceImpl.java`：删除恒定 `return 1`，改为返回真实影响行数 = `deleteSysUserLabByUserId` 删除行数 + `batchInsertSysUserLab` 插入行数；空集合不触发插入时只计删除数。空集合覆盖已为空的授权是合法幂等清空，返回 0 表示「无变化」，不代表失败。
- `controller/SysUserLabController.java#saveLabs`：不再 `toAjax(saveSysUserLabs(...))`，改为调用 Service 完成后返回 `success()`。依据：`BaseController.toAjax(rows)` 口径为 `rows > 0` 才成功（`BaseController.java:147`），幂等清空真实 0 行若走 `toAjax` 会误报失败；旧实现层覆盖保存以「命令完成」为成功口径，mapper 失败沿 `@Transactional(rollbackFor = Exception.class)` 上抛，由 `GlobalExceptionHandler` 统一映射，不存在静默成功。
- `service/ISysUserLabService.java`：javadoc 同步为「真实影响行数（删除 + 新增）；0 表示无变化的幂等清空，不代表失败」。

```

M01LegacyPermissionStringContractTest   Tests run: 6, Failures: 0, Errors: 0, Skipped: 0
```

- 新增 `futurefab-modules/futurefab-system/src/test/java/com/futurefab/system/contract/M01UserLabSaveContractTest.java`（Mockito 内存替身，7 用例）：有旧+新授权返回删 2+插 2=4（含 labId 去重取证）；有旧+空集合返回删除数且不触 insert；无旧+空/null 幂等返回 0 且 Controller 仍报成功；delete/insert 抛异常均上抛不静默；Controller 对 0/4 行返回均 success、异常传播、`checkUserDataScope` 先行。
- 判据可检出性：测试内显式断言 `toAjax(0)` 为失败口径（反例自检，证明「Controller 不走 toAjax(rows)」可被检出）；恒 1 旧实现会被「返回 4/返回 3」用例报红。
