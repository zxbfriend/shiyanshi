## 内部只读事实端口（非 HTTP canonical 接口，不计入 76 项）

本节登记 M01 作为提供方对外服务其他业务模块的跨模块内部端口，不是浏览器可达的 HTTP 入口，不扩充 76 个 canonical HTTP 接口数量。落实 AGENTS.md §8「跨模块调用经 Port，不直读他模块 Mapper」。

### 内部端口 · RoleCandidateFactsPort（M01 提供方 / M09 消费方）

- 精确契约：`com.futurefab.system.service.port.m01.RoleCandidateFactsPort#loadRoleCandidateFacts(RoleCandidateFactsQuery) -> RoleCandidateFacts`。物理签名冻结、只能实现一次；单 Request 入参 `RoleCandidateFactsQuery` 只携带调用关联用 `requestId`，不含业务过滤，也不承载任何客户端自报的用户身份、部门或数据范围。
- 提供方能力：复用 M01 自有 `SysRoleMapper.selectRoleList`（`where del_flag='0'`）读取非删除角色目录，逐条输出 `roleId`（十进制字符串）/`roleName`/`enabled`（`status='0'` 启用、`'1'` 停用），稳定按 `roleId` 升序；停用角色照常返回、不预过滤。
- 语义边界：候选事实 ≠ 允许保存。`enabled=false` 只表达"当前停用"这一事实；停用角色能否作为通知规则接收人来源等业务终态，由消费方 M09 自行判定，M01 不代答，也不与身份端口 `ActorContextPort`、功能判权端口 `FunctionPermissionPort` 混用或扩充。
- 失败关闭（整份目录 all-or-nothing）：入参为 null、取数异常或返回 null、或结果集内任一行出现 null 元素 / 缺失或非法（≤0）主键 / 重复主键 / 状态不在 {0,1} / 名称违反 `SysRole` 约束（空白或 >30）/ 带删除标志 → `status=UNAVAILABLE`（`reasonCode=FACTS_UNAVAILABLE`，HTTP 503，见[错误码全集](错误码全集.md)）。绝不静默跳过、任意去重、把未知状态默认成停用，或以 `AVAILABLE`+空集合冒充"无角色"；仅"确无角色"的空结果才是 `AVAILABLE`+空列表。
- 字段约束来源：`SysRole`（`role_name` `@NotBlank`/`@Size(max=30)`、`status` `0正常/1停用`、`del_flag` `0存在/2删除`），对齐[数据库表结构与字段字典](数据库表结构与字段字典.md)。消费方字段语义对齐 09-告警与通知管理/页面与接口契约.md API04 的 `roleOptions:[{roleId,roleName,enabled}]`。
- 待收口：角色删除与消费方引用写入之间的并发保证属跨模块一致性专题，本端口不承诺任何跨模块事务/锁，另列待收口项。
