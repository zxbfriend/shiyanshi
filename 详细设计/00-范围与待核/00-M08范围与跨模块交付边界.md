## 4. 业务数据独立与统计单向消费

业务模块是其数据的唯一写入权威，业务页面直接调用所属模块的查询与增删改接口。M08 只消费授权投影/可靠事件建设统计读模型；不成为原始业务数据的唯一保存处，不持有业务状态推进、通用CRUD或操作准入。业务接口、事务、调度、告警和本期验收不得读取 M08 统计表或等待其响应。统计口径可以延期，业务必需的查询、计量累计、报告和执行曲线按原领域契约交付。

| 数据与事实 | 本期拥有方 | M08 恢复后的关系 |
| --- | --- | --- |
| 设备身份/通讯版本、原始业务观测与质量/时刻 | M02 负责设备接入契约和非运行观测接收、留存及授权查询；执行专属高频采样由 M07 保存，避免双重权威 | 只读消费来源观测，按需要形成统计副本 |
| 培养身份、占用、设备关联及其有效时段 | M03；源观测固定发生时的关联依据，未知保留未核验，不按当前绑定回填旧记录 | 消费稳定ID/版本及历史关系 |
| 检测样品、结果、签批、更正、报告 | M05 | 消费精确版本，不改源结果 |
| 确认、工作流、任务、命令、控制采样及计量账 | M07 | 消费实际事实，不重算业务结算 |
| 审批单、动作及决定交付 | M06 | 消费审批事实，不代替应用方生效 |
| 告警规则、事实、处理、消息、投递及历史 | M09 | 消费告警/通知投影，不参与触发或发送 |

原 M08《在线归档与培养关联契约》中业务必需的接收去重、乱序、质量、时间与培养关联约束由 M02 设备接入/M03 关联提供方及 M07 执行采样承接；统计查询/抽样部分继续留 M08。实施时复用并核验现有接入存储，字段/迁移与业务查询契约列入拥有模块的交付包，不能仅因旧稿位于 M08 目录而延期，也不能宣称本次范围修订已经完成实际迁移。全量非 M08 需求矩阵必须跟踪这项数据承接到所属模块的详细落点。

M03/M05/M07/M09 继续保存可信业务事实、不可变版本、原单位、时间、来源身份和可靠投递证据。M08 消费者未启用不阻塞本期事务、物理结算、资源释放或 M09 已就绪消费者。投递状态按已有 outbox/代理回执定义，不伪造 M08 消费成功；保留后续按原 eventId 补取和去重能力。消费订阅、积压容量、保留与恢复沿原领域契约，不能以暂停为由删除唯一证据或无限重试同步 HTTP 调用。

M09 在线告警直接接收 M02/M07 的业务观测或判定事实，不经 M08 统计/归档服务。旧稿中“因 M08 暂停而在线告警无法接入”的依赖取消，源接入纳入 M02/M07/M09 本期开发和联调。真实设备协议、逻辑 profile、单位/时效或恢复证据尚未核准的路径仍按原规则保持 BLOCKED/SAVE_ONLY，这是外部能力准入而非统计依赖。配置保存、审批通过和监控策略 ACK 不等于在线判定链可用；模拟事实不计为真实闭环。

M07 物理控制采样、停止证据、执行曲线与计量历史继续保留，不能切换为依赖 M08 原始在线库。M05/M07/M09 受控归档不设置未经确认的删除期限，历史读取、解密、关联、幂等和恢复要求保持。
