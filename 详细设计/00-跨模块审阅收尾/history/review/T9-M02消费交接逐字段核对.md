# T9 M02 跨模块消费交接逐字段核对

版本DD-20260913-T9-R1。范围是T8期间明确转交T9的五组M02生产/消费边界。本文冻结设计交接，不代表生产方或消费方代码已经适配。

## 1. M05检测事实 → M02检测设备摘要

| 项 | 固定契约 |
| --- | --- |
| 生产方 | M05按detectorId及稳定attemptId，对“首次进入检测中”的事实去重汇总 |
| 消费方字段 | M02 LabDetector Row/Detail的detectionCount:string|null，非负十进制整数；列表、详情、导出同源 |
| 明确区分 | M05 DetSample.detectCount/队列detectCount是样品“当日检测次数”Long，不是设备累计尝试数，禁止复制或重命名后充当detectionCount |
| 完整性 | M05事件基线不完整或查询失败时null并给configurationIssues，不返回0；0只表示完整基线确认无尝试 |
| 版本 | 返回事实水位resultFactWatermark:string及asOf:ISO8601；M02 managementRevision不冒充事实水位 |
| 重试/错误 | 查询失败503 DEPENDENCY_UNAVAILABLE；展示可降级为null＋问题，导出须标空值，不能缓存为0 |

目标内部读：`summarizeDetectorAttempts(context, detectorIds:string[], asOf?:ISO8601) -> [{detectorId,detectionCount,resultFactWatermark,asOf,complete,issues}]`。context为可信调用目的，最多100个ID；无权对象不返回。该方法是T9交接定义，源码当前未发现实现。

## 2. M02集成反应器 → M04/M03/M07

| 字段 | 类型/单位 | 消费规则 |
| --- | --- | --- |
| floorScaleId | string | 非补料地秤角色，kind=FLOOR_SCALE；不得与feedScaleId相同 |
| feedScaleId | string | 补料地秤角色，kind=FLOOR_SCALE；字段名决定角色，不能按ID或候选顺序推断 |
| pumpConfigs[].pumpNo | integer 1..N | 固定泵稳定身份；rangeValue单位g/min、最多2位；strategy≤50 |
| externalPumps[].pumpId | string | 外置PERISTALTIC_PUMP实例；与pumpNo命名空间分离 |
| externalPumps[].rangeValue | decimal-string|null | 历史读可保留4位，正式保存≤2位；现场单位未核准不得进入执行计算 |
| externalPumps[].strategy | string|null≤200 | 不复用固定泵50字符限制；历史pumpUsage只读 |
| needExternalPump | "0"/"1" | 保留既有字符串；不得由消费方转换成缺省boolean后回写 |

M04只用能力/候选设计模板，M03固化选定实例及配置版本，M07只执行M03固化且准入通过的配置。ReferenceOption.role固定为`floorScaleId`、`feedScaleId`、`airPumpId`、`relayId`、`alarmId`、`externalPumps[].pumpId`；生产与消费JSON均用这些表单路径。版本同时携managementRevision和业务快照版本，不能只存当前对象ID。

## 3. M02通讯配置 → 设备适配器/M07

HTTP写入只接受interfacePasswordChange/deviceSecretChange:SecretChange，action=KEEP/REPLACE/CLEAR；这两个对象是变更指令，禁止进入适配器加载DTO。内部loadEffectiveCommunication输出interfacePassword/deviceSecret:string|null明文，仅走受信内部通道，使用后清除且不日志化。适配器不得把明文回传HTTP，也不得把星号作为REPLACE值。

加载身份键固定deviceKind+deviceId+desiredRevision；返回配置字段按communicationType白名单。reportAppliedConfiguration输入result=APPLIED/FAILED/UNKNOWN；APPLIED只表示配置加载，设备在线与命令执行另判。M07准入要求desiredRevision==appliedRevision且applyState=APPLIED，同时重查连接/业务条件；managementRevision、desiredRevision和M07 configurationRevision是三个不同版本，M07证据中的configurationRevision固定取本次appliedRevision。

失败/重试：旧修订回报accepted=false/VERSION_CONFLICT；同修订FAILED后APPLIED是新证据；完全同证据duplicate=true。同修订已接受APPLIED后迟到失败不得降级。读取或解密失败503 DEPENDENCY_UNAVAILABLE，不返回空密钥伪装CLEAR。

## 4. M02资源与消耗配置 → M04/M05

资源写iconPath三态：键省略=保留，null=清除，字符串=替换；读统一iconUrl:string|null，消费方不回传临时URL或把空串当清除。耗材身份固定consumableId，itemCode/description只显示；单位measureUnit:string|null，null时依赖数量解析的流程阻断。

消费Row固定ruleId、seqNumber、itemType、consumableId、sharedRuleId、quantity、resolvedQuantity、configurationIssue。itemType='1'直接量，quantity必填且resolvedQuantity=quantity；itemType='2'共享量，sharedRuleId必填、quantity=null，resolvedQuantity取稳定源。configurationIssue仅SOURCE_UNAVAILABLE/CONSUMABLE_UNAVAILABLE/null；NA展示不等于数值0。M04/M05只能消费resolvedQuantity及其单位/问题，不能自行追sharedRuleId形成第二套解析器。

卡片身份固定labId+tabType+detectClass+dilutionType，rowName/cardName只显示。旧字段detectType由兼容层映射detectClass；生产方输出新字段后消费方不得继续混读两键。配置管理版本用于编辑CAS，业务快照另存解析结果和来源ID/版本。

## 5. M02液瓶布局 → M03/M07

部署身份为labId+unitType+unitCode+slotNo；bottleId是槽记录ID，不能替代unitCode。Slot的currentCapacityG/maxCapacityG单位g、bottleCapacityMl单位mL、percentage为decimal-string，禁止按固定密度互换。readingQuality=GOOD/STALE/BAD/UNKNOWN和observedAt共同消费；非GOOD不能作为精确执行输入，UNKNOWN不得当0。

M03/M07占用守卫输入必须含bottleId、配置managementRevision、观测版本/observedAt及业务上下文，返回allowed/reasonCodes/usageRevision。M02配置写在SYSTEM守卫内重查占用，但不创建运行占用；M07命令事务外执行。workflowConnected:null或依赖故障均失败关闭；只有明确false且其他准入通过才允许换绑。配置变更使旧观测失效，未变槽保留原观测。

## 6. 兼容、错误与验收

生产方先提供新字段/转换层，消费方随后切换，最后移除旧旁路。任何双读期都以新契约为权威并记录差异，禁止“有哪个取哪个”。跨模块错误保留生产方原码和上下文：M02 RESOURCE_FACTS_UNAVAILABLE/CONFIGURATION_INCOMPLETE、通用DEPENDENCY_UNAVAILABLE、M05事实问题及M07命令状态不得互相改名。

验收夹具至少覆盖：detectCount与detectionCount同时存在；事实基线不完整；两秤角色交换；固定/外置泵同序号；SecretChange不泄漏；FAILED后APPLIED；iconPath三态；共享源失效；NA与0；bottleId/unitCode错绑；STALE/UNKNOWN读数。T9-R1关闭这五组设计命名和消费规则，实际源码适配与契约测试另行记录。
