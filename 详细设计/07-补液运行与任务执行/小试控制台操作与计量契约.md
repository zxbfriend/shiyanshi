# 小试控制台操作与计量契约

2026-11-07，S04第2组；依据V5.1[补料控制台](../../需求说明书V5.1-1030_md/20-补料控制台（5.0）.md)md3—109、[取样控制台](../../需求说明书V5.1-1030_md/21-取样控制台（5.0）.md)md3—57，S02-312/313，B8526—8636；原生121、138、144及145最新补充。M02拥有资源/合法模式/耗材来源，M07操作与原控制方衔接；本专题不是培养工作流的新步骤。

## 1. 读模型、范围与模式

按当前有权小试实验室实际布局读取各补料/取样单元，稳定单元ID与泵号/通道映射；不以画面第几张卡片寻址。原图四泵为适用原设备布局，其他型号按实际已配置通道，不创建虚拟泵。培养/反应器图标、当前理论量、最新VCD及其真实样品号、秤读数来自拥有方只读Port；缺值显示原因，不补0/假在线。

补料单元详情Unknown表示当前培养未完成连接流程，Doing/Done沿真实连接与补料事实显示，不能作为命令成功依据。物料详情读取原液瓶名称/序列号/序号/料液及当前使用量/标准容量，不改型号容量。

模式对整个实验室生效；切自动前耗材计算包含所有适用取测任务，等于足够可通过，真实切换成功再按原模式限制页面。自动时不操作工作流、不从检测分析人工发送，任务在手动继续等待。使用[LoadSample§3](LoadSample运行交付契约.md)同一模式控制方，不新增全局未决动作门槛。

## 2. 补料操作

| 操作/输入 | 约束及结果 |
| --- | --- |
| 固定三泵 | 料液只读取当前培养补液方案的真实单元/泵/料液，补量0.1—150g；速度沿本入口适用Speed1—10代码，必须在当前型号真实支持内 |
| 自定义第四泵 | 必选原有效补液培养基、净重正整数g及原泵速，补量0.1—150g/补料速度按原字段；不把固定泵物料改成可编辑 |
| 使用/保存默认值 | 按**同一具体泵**共用补量及速度，非用户隔离；后保存者成为该泵默认，更新需该对象版本，参数及审计同事务（138） |
| 开始/结束预填充 | 仅原该泵/通路合法状态，预填不计入培养补液量；沿实际命令回执/开始结束记录展示 |
| 开始/结束补料 | 当前实际培养/泵/料液及可执行状态重验，真实开始和结束/停止后认可实际量；不能用计划量当已补 |
| 系统状态/初始化 | 固定机械臂子系统名称/IP/实际网络状态；原单个/统一初始化逐设备真实结果，不宣称整批物理原子 |

每次操作记录真实人/时刻/对象/输入、原命令或执行身份及实际结果；趋势图读取该操作真实秤时间序列，不编图表采样频率。实际小试供料瓶减重=前读−后读（79），不得反向相减或取绝对值掩盖异常。取消部分已补仍保留真实认可量且仅累计一次，未补余量不自动新增任务（101）。

## 3. 取样、清洗和消毒

清洗量1—100mL、真正取样量1—30mL、消毒量1—100mL，单位及原精度沿原字段，不迁用任务样品µL；开始/停止保留真实动作起止，消毒默认值来自最近一次真实开始操作，不取未保存输入或他人页面内存。

三项速度均按**当前设备型号**实际支持二选一种：档位型下发该型号有效速度代码；数值型下发合法数值及原单位。第145最新补充覆盖此前清洗无速度解释；Speed1—10只是一型号示例，不固定清洗速度、不扩第三种方式。能力/单位缺失只跳该设备速度下发并登记原接口适配，不猜值。

外部水/75%酒精清洗和消毒排至废液，不从培养罐抽液、不扣培养理论重量（121）。首次开始培养初始基准后，正常完成且真实从培养罐取出的实际培养液，沿M03既有追加/累计取测量原通路自动计入一次并扣理论量；用户不重复手工追加。D-1已计入首次基准的不重扣。仅点击开始/计划量不是实际取出，异常/部分停止实际认可口径局部Q-2-04。

物料详情只有waste显示清除，复用原W08废液清理更换液瓶、容量归0的拥有方能力与审计；不直接跨表置0、不能清除普通料液或代替设备真实安全动作。该入口沿原权限和状态校验，不新增清空审批。

## 4. 接口编排与事务

目标复用现有工作流026原操作/原控制方语义，但控制台不伪造workflowId。现行独立控制台源HTTP尚未定位，采用以下M07目标登记，与M07-038—043 LoadSample区分；不宣称现有Controller可原样处理。

| 编号/路径 | 合同 |
| --- | --- |
| M07-044 GET /run/consoles | labId及原补料/取样单元选择→上述布局/物料/实时值/真实状态/能力和managementRevision |
| M07-045 POST /run/consoles/defaults | 具体补料单元/泵、当前对象版本、原补量及速度→保存后的泵共用默认；仅保存不启动 |
| M07-046 POST /run/consoles/operations | 具体单元/泵或机械臂、原操作种类/参数、对象版本及原操作ID→原ActionResult/逐项真实结果；不得接任意命令字符串 |

044使用目标`run:console:query`，045/046使用目标`run:console:operate`，与[M01逐口登记](../01-系统管理/S04新入口权限与读取配套.md)一致，不借旧任务/工作流权限默认授予控制台操作。目标未编码、部署或实际授权不得开放。所有写双头、从044同模块取revision，完整显式集合校验，操作时重验实验室/培养/资源范围和版本。结果按允许动作返回，不由前端复制业务状态机。

应用服务先短事务记录原合法操作及审计，再事务外经M02/原控制方调用，另短事务核本次对象/版本记录结果；设备结果仅成功、失败、结果未确认，调用前不显示成功。缺真实原操作回执、状态查询/恢复协议继续关联Q-1-07；行锁只能解决本地并发，不能承诺物理未知结果已去重。

每泵当前状态及实际资源占用应从原执行事实取得，“已下发不重复”必须查已有原操作/执行审计，不依赖页面Doing/Done。接口参数映射、型号速度单位/回读和真实记录载体尚待原控制方接线，Q-2-04局部保留；不新增默认表/监控频率或任务状态来补资料。
