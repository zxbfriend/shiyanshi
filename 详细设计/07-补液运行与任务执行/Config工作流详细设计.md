# Config 工作流详细设计

## 2026-11-07 现行澄清适用口径

依据正式决策记录末尾S04客户答复及后续补充。本节与下文正文同步；仅为设计，不证明代码或设备已验证。

- **Q-1-08**：四类检测设备（BGA、Vi-CELL、OSMO、Cedex）除外，设备命令先下发再查询检查结果；下发失败重试下发、查询失败重试查询，不因查询失败就盲目重发已成功下发的命令。失败重试间隔统一10秒；最多重试3次，不包含首次，故下发/查询各阶段最多4次尝试。重试仍失败后提示用户，并提供原手工处理按钮；不在首次失败即直接结束自动尝试，不把受理或查询失败当设备已成功。设备真实方法、回读与原请求身份沿已有契约，未接线不伪装成功。此为本次设备命令调用内重试，不新触发一次工艺规则，不取消原pH每日处理或通气连续调整次数等业务限制，不套用于四类检测设备送检、通知投递或数据库审批交付。
- **Q-1-02**：仅由人点击范围正常按钮记录确认，不获取、不记录三项实测MPa数值，不新增压力数值输入/采集。
- **Q-1-04**：保压时长过程中异常即失败；自动保压从精充重做，保压从0计时；首轮操作记录保留。手动保压表示员工线下完成，按原方案进入下一步，不继续或重置线上保压计时。
- **Q-1-05**：仅小试可多控制器操作。仅下发当前值与设定值不一致参数；有未成功项提示并允许重试，重试仍只下发差异项。全部控制器成功才正常推进；通信失败可通过原“跳过并完成”明确跳过未成功设备，保留真实失败与人工跳过记录，不伪装设备成功。结果未知未因此获准盲目重发。

本专题承接[原入口](十二月新增工作流与任务规则.md)第2节 Config 已确认边界，适用于中试 4 步与小试 3 步。需求依据：V5.1 需求 18 章「工作流」下「Config关联设置（4.1）」，原文 B5499—5808（md 见[18-反应器](../../需求说明书V5.1-1030_md/18-反应器.md)第 2872—3333 行）；澄清依据为[需求澄清决策记录](../../需求说明书V4.0-0904_md/需求澄清决策记录.md)的 Q-S02-S5-Config、第 32 项 Q-W05-StablePressureRange、第 33 项 Q-W05-DropThreshold、Q-T02、Q-T03-NothingRow，以及[十二月上线范围与澄清规则](../00-十二月上线范围与澄清规则.md)第 3、4 节。中试下游（设备校准、控制台、操作记录）不在本节范围。

### 公共规则

- 拥有方：M04 持有 Config 方案字段树与版本（[M04 模板内容存储契约](../04-工艺与方案管理/模板内容存储契约.md)第 7、8 节）；M03 持有本培养已生效方案包（[M03 快照契约](../03-项目与培养管理/培养参数快照与审批生效收尾契约.md) M03-P04 readEffectivePackage）；M02 持有设备当前值、远程服务状态与重启、OPC 写入；M07 持有工作流实例、步骤推进、执行记录与曲线；M05 不参与 Config。
- 入口与权限：从当前实验室工作台的工作流选择进入，固定真实 labId（页面与独立入口见[培养运行操作页与独立入口](培养运行操作页与独立入口.md)第 3 节）；候选按各步「入口与前置」逐项过滤。权限为 M01 当前功能权限加 M03 培养成员与培养操作范围，服务端每次重验，页面可见不等于授权。工作流实例与步骤由 M07 承接，不新建第二套页面或执行器。入口分两类：工作台候选列表按原文第 2879 行「对于不可重复的工作流，已完成该步骤操作的反应器／控制器不显示」；已完成工作流从该反应器／控制器详情只读入口进入时展示完成界面（原文第 3215、3313 行）。已完成者不在候选列表展示，详情入口只读展示完成结果，不另设“已完成候选再启动”路径。候选与启动分别复用 M07-022、M07-023，详情、推进、设备动作、取消及重启分别复用 M07-024—028；接口字段与版本沿现有目录，不因客户原文未写HTTP编号增加接口。
- 方案口径：只读取本培养已合法生效并固定的 Config 版本；模板已保存不等于本培养方案已生效。字段、单位、精度与量程以 M04 为准，M07 不重复计算一份规则。DO 三槽及pH两槽的Nothing行均不填写左右映射范围、不绑定实际输出、不下发该行输出参数；DO允许三路均Nothing，pH不新增至少一路限制；固定初始化OUT和控制模式保留。依据原生第152问，仅Config适用。
- 设备写入的页面结果保留成功、失败、结果未确认；按Q-1-08先下发、再查询检查：下发失败重试下发，查询失败重试查询；各阶段间隔10秒、首次之外最多重试3次（最多4次尝试），耗尽后提示并开放原手工处理。四类检测设备除外；查询失败不等于可盲目重发已成功写入的指令。受理或未知均不记为设备成功；Q-1-07尚无执行事实的并发窗口仍属技术待核。
- 事务边界：步骤状态变更与操作审计在同一本地事务内提交；设备 I/O、HTTP 调用不进入数据库事务；调用前只核验事实，调用后另开短事务记录真实结果并推进步骤和审计，不把参数检查成功写成步骤成功。审计写操作人、步骤开始与结束时间、结束原因、动作前后值；设备动作另记下发时间、通道与返回结果，不与数据库提交混同。
- 并发：同一培养的工作流实例行用 `SELECT … FOR UPDATE` 锁定后推进；后到者重新读取当前步骤再决定，不覆盖他人已完成的步骤。重复点击同一下发动作在同一锁定内重读后再决定是否发送，不引入步骤级版本或请求键去重协议，不展开为额外协议。
- 流程记录：二级流程记录开启步骤 1 到全部步骤结束的操作时间、操作人及相关信息（原文 B2849）；每步开始与结束时间分别留痕，已发生的设备动作不因取消抹除。
- 边界：不新增表、枚举、类、状态；不新增审批、重试次数、阈值、默认值、采样周期、允差或跨模块联动。原文未写的事项列入本节末待确认项表，不补默认值；培训示例数值不作默认参数。

### 中试 Config（4 步；原文第 2890 行照抄「Config关联设置无前置环节」；第 2892 行「Config关联设置在每个培养只能执行一次，不允许重复操作」）

#### 步骤 1 开始（B5522—5547）

1. 需求依据：18 章 Config关联设置-中试步骤 1，B5522—5547，通用候选 B5506—5517；澄清 Q-S02-S5-Config。
2. 入口与前置：当前中试实验室工作台，仅本实验室反应器，且已有包含计划起止日期与所用反应器的确定培养方案（原生第114问，允许计划接种日前准备，无新增确认按钮；原文第 2877 行）；前置按本培养实际已选流程关系判断：Config本身不增加未选前置；按原生第2—3问补充、第5问和第114问，不以是否已选“开始细胞培养”统一拦截。其余候选条件按原文第 2879—2885 行：不可重复流程已完成者不显示、完全空闲者不显示、未选择当前Config或灌注环节者不显示；未选开始细胞培养本身不再拦截、无培养权限者不显示、中试仅反应器培养模式可选，且须完成 Config 方案填写并审核通过（置灰卡片点击提示「未进行方案预设，不可进行操作」）。候选范围为上述条件交集，卡片仅支持单选。原文此处混用“开始培养工作流”已按第5问明确纠正，不再列T11问题。
3. 输入：房间（同实验室多个房间或「所有」，来源 M02 集成反应器场地字段）；其他条件「所有」（默认）或「方案已设置」二选一（标识来源 M04）。卡片展示培养 ID、当前阶段（第几天；按已确认 D0 规则，日序号为业务自然日期差、从 D0 起算，时间按 Asia/Shanghai，见[04 章详细设计](../04-工艺与方案管理/详细设计.md)第 563 行）、反应器编号、图标、规格（L，原文图示 50L）、进入页面时最新的在线与离线指标名称及数值（来源 M02，单位随各指标原单位；卡片读取进入页面时最新有效值，不套用M08统计图表抽样档位）、负责人（培养成员→批次成员→项目成员回退，来源 M03）、是否设置 Config 方案标识（来源 M04）。本步无手填数值、无单位换算。
4. 动作：M07 候选查询读取 M02 场地与观测、M03 培养成员、M04 方案标识；选中后创建工作流实例并写步骤开始时间，用 M03-P04 读取本培养已生效 Config 包仅用于核验方案已设置。无设备 I/O。
5. 结果：选中单台已设置方案的反应器并确认后「下一步」可用，进入步骤 2；卡片未设置方案或权限不足时不可选并提示，按钮保持禁用。写记录：操作人、步骤开始与结束时间、结束原因；前后值无（本步不改业务值）。
6. 取消／续做／跳过：取消无、续做无、跳过无（原文未给步骤 1 这些路径）；再次进入：工作台候选列表按原文第 2879 行不显示已完成本流程的培养，已完成工作流从该反应器详情只读入口进入展示完成界面（原文第 3215 行），两条路径不混用；已完成者不在候选列表，详情入口保持只读。
7. 并发与幂等：两人同时开启同一培养时，以工作流实例行 `SELECT … FOR UPDATE` 仲裁，后到者读到已存在实例后不再新建；重复点击「下一步」在同一锁定内重读当前步骤，已推进则不再重复创建，不生成第二个实例。

#### 步骤 2 设备状态确认（B5548—5570）

1. 需求依据：18 章 Config关联设置-中试步骤 2，B5548—5570；第 120 项开始培养最终设备确认的异常勾选二次确认规则不跨用到本步。
2. 入口与前置：由步骤 1 单选后进入且步骤 1 已成功；候选范围固定为选中的这一台反应器；权限同公共规则并每次重验。
3. 输入：培养/反应器基本信息与M02所配远程服务名称、连接状态及原重启按钮；气体压力仅由用户逐项点击Air、O₂、CO₂的“范围正常”按钮确认。按Q-1-02不获取、不记录三项实测MPa数值，不新增数值输入、读点或数值范围校验。
4. 动作：M07读取M02服务状态；异常重启沿M02既有入口并在事务外执行。压力只记录逐项人工“范围正常”的确认事实，不采集或存储三项压力数值（Q-1-02）。
5. 结果：全部服务连接正常且三项压力范围全部确认后「下一步」可用，进入步骤 3；任一服务异常或任一项未确认时「下一步」禁用并标出异常项；点击重启后重新读取状态，不因点击即显示正常。本步无参数下发，三类设备写入结果不适用。写记录：操作人、步骤开始与结束时间、结束原因、服务状态前后值、确认前后值。
6. 取消／续做／跳过：取消＝二次确认后不保存当前任何数据，下次从步骤 1 重新开始；续做无；跳过无。
7. 并发与幂等：两人同时对同一培养点击重启时，以工作流实例行 `SELECT … FOR UPDATE` 串行，后到者重读服务状态；重复点击同一次重启时在同一锁定内重读服务状态，服务已正常则不再重复下发，不展开为额外协议。

#### 步骤 3 参数下发（B5571—5619）

1. 需求依据：18 章 Config关联设置-中试步骤 3，B5571—5619；澄清 Q-T02、Q-T03-NothingRow（第 44 项）；K01 的 gain／reset／rate 与回路绑定格式缺口。
2. 入口与前置：步骤 2 全部服务正常且压力范围确认完成；候选范围为步骤 1 选定的单台反应器及其本培养已生效 Config 包；权限同公共规则。
3. 输入：基本信息反应器编号、培养 ID（M03／M02）。按 M04 第 8 节字段树自动带出：MFC（序号、MFC 编号、气体、允许通路、初始化 OUT、控制模式）、泵（仅筛选已填写功能名称的泵：序号、泵编号、功能名称、转速或流量、关联控制模式、初始化 OUT、控制模式）、控制回路（控制回路、关联、控制器输出、输出上下限、初始化 OUT、控制模式）、PID 设置（DO Control、PH Control、Vessel Temp Control，各含 gain、reset、rate）。每项同时读取设备当下数值，与方案预设值显示一致或不一致两态；当前值来源 M02 OPC 回读，方案值来源 M03-P04 读取的 M04 固定包，单位、精度、量程按 M04 第 7、8 节，不在 M07 另定。
4. 动作：用户确认信息后二次弹窗确认，再点「下发参数」；M07 经 M02 设备写入口（原 OPC 服务）只下发「当前数值与方案预设数值不一致」的项，Nothing 行不映射、不下发；设备 I/O 与 HTTP 调用在事务之外；下发期间页面进入等待状态、不允许继续操作。具体写点、方法与回读映射属本节末接口缺口，缺的不写默认值、不写假成功。
5. 结果：经查询检查确认各参数成功后进入步骤4；失败/结果未确认按公共Q-1-08过程处理，耗尽后提示并提供原手工处理按钮，不在首次失败直接放开人工处理。记录逐项前后值、下发/查询时间及真实返回结果，不记整批假成功。
6. 取消／续做／跳过：取消＝二次确认后不保存当前任何数据，下次从步骤 1 重新开始；续做无；跳过并完成＝表示本步骤已线下手动完成，二次确认后进入步骤 4 并留痕，不伪装设备下发成功。
7. 并发与幂等：两人同时下发同一培养时，以工作流实例行 `SELECT … FOR UPDATE` 串行，后到者重读设备当前值再比较；重复点击同一下发动作时在同一锁定内重读设备当前值再比较，已有同项真实成功执行记录才不再发送，尚无记录的调用窗口关联Q-1-07，不盲目重发已完成的其他项。

#### 步骤 4 充气／保压／换气（B5621—5734）

1. 需求依据：18 章 Config关联设置-中试步骤 4，B5621—5734；澄清第 32 项（稳定结束 25≤P≤35 mbar 才从 0 开始保压、范围外判失败）、第 33 项（以本次保压开始实际压力为基准，降幅大于配置阈值立即失败并停止计时告警，小于等于阈值继续至规定时长，5% 不作默认）、Q-T02（精充严格小于同通道粗充目标）；10／60 分钟等培训数值不作默认。
2. 入口与前置：步骤 3 真实下发成功，或步骤 3 合法「跳过并完成」后进入；候选范围为该单台反应器及 M03-P04 读取的已生效 Config 包 process 字段；权限同公共规则。
3. 输入：按 M04 第 8.2 节自动带出并逐项照其单位与精度：初始压力设置 0—50 mbar（整数）、充气目标 10—100 mbar（整数）、粗充行（通道、通路、间隔 1—59 s、流量 0.5—100 L/min 一位小数）、精充行（流量 0.1—20 L/min 一位小数，严格小于同通道粗充流量）、稳定时长 1—100 min、保压时长 10—300 min、降压合格阈值 0—100% 最多两位小数（比较符为小于等于）、换气倍数 2—20 一位小数与独立 Air 通道行、是否跳过换气。实时读数：当前压力 mbar、当前流速 L/min、换气体积、罐体积（来源 M02；采集频率原文未写，见本节待确认项 T6）。
4. 动作：「归零」按钮下发压力归零指令，成功后初始压力显示 0（压力归零不是秤清零，接口见本节末）；「确认并开始执行」后按充气→保压→换气顺序推进，换气子步骤仅在方案未跳过换气时展示；各子步骤的 MFC 流量下发、0 速度暂停、服务重启、设备重连均经 M02 设备写入口、在事务之外（这些动作与实时压力／流速读取点的具体调用见本节接口缺口表）；执行记录与曲线由 M07 写入（[原 API13 及采样交接](业务观测采样与告警交接.md)）。

### 可验收场景

1. 正常：中试已设置并生效 Config 方案的单台反应器、服务全部正常 → 依次完成步骤 1 至 4（充气达标、稳定结束 25≤P≤35 mbar、降幅未超配置阈值、换气体积达标）→ 工作流完成，从该反应器详情只读入口再次进入展示完成界面，不从步骤 1 重跑；工作台候选列表不再显示该培养。
2. 失败重试：分别核验下发/查询间隔10秒、最多4次尝试；查询失败不盲发指令；耗尽才出现原手工处理。差异项成功、各台全部成功或明确人工跳过后才能相应推进。此为待执行验收场景。
3. 取消与续做分开：中试步骤 3 取消 → 不保存本次数据、下次从步骤 1 开始；中试步骤 4 取消 → 保存历史信息、再次进入直接从步骤 4 继续；小试步骤 3 取消 → 不保存、下次从步骤 1 开始，三条路径互不套用。
4. 两人并发：两人同时对同一培养点「下一步」或同一次下发 → 后到者重读当前步骤及已登记执行事实；已有完成事实不重发，调用中窗口仍按Q-1-07未定。
5. 权限不足：非培养成员或无培养操作权限者进入 → 候选卡片不展示或不可选并提示，服务端重验拒绝，不因链接直达获得操作权。
6. 读不到数据：步骤 3 OPC 读取当前值异常 → 页面提示读取异常、不显示一致状态，读取异常后当前值如何取原文没写，见本节待确认项 T10；保压过程压力读取异常按Q-1-04立即判本次失败，自动保压从精充重做并从0计时。
