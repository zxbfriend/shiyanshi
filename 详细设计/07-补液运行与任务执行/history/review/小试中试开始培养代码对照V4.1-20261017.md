# 小试中试开始培养代码对照

审阅日期：2026-10-17。需求基线：客户《需求说明书V4.1-1013.docx》“开始培养（4.1）”及“页面原型10.15”中的小试、中试开始培养页面。代码基线：D:/project/yaoming/SMP/yaoming_shengwu 当前工作树，HEAD 为 3786db4cc15021729b0a3b7967bfa8d318261706，审阅开始和收尾一致。工作区已有其他未提交修改；本次未改业务代码、配置、数据库或客户资料，仅新增此审阅记录。

结论：两类开始培养均尚未形成可用的四步业务链。当前已有培养准备、通用工作流实例、重量变更、告警配置读取、ViCell细胞类型带出等基础能力，但真实工作流主要接通小试补液相关流程。W03 是“连接补料单元”，不是“开始培养”。不能把接口已接线、已有预填充按钮或培养状态进入 RUNNING 作为开始培养实现完成的证明。

本文是过程性对照记录，不是修改现行契约的裁决，也不是运行验收报告。检查了前端调用、SDK、Controller、应用服务、相关 Mapper/事件链和现有测试源码；未运行编译、测试、数据库、HTTP、浏览器或设备联调。不计算完成百分比，避免将可复用基础能力计为业务步骤完成。

## 3 已发现的具体差异与责任边界

1. 页面节点与真实能力不一致：界面有“开始培养”的文字，但只读占位。不是“页面已做、只缺设备参数”。
2. 通用工作流接口并不通用：GET /run/workflows/candidates 只接 W03，POST /run/workflows 只分派 W03/W06/W07/W08。即使向流程目录补入开始培养，也不会自动获得运行能力。
3. 现有重量修改与首次接种确认不一致：仅允许运行态、正整数克值、要求原因并判审批政策；中试原型明确首次确认不审核。需要新增清楚的首次登记语义或扩展现有拥有方接口，不能直接绕开审批、放宽既有运行变更口。
4. 告警读写能力不对称：培养配置回退设备模板的读取已有实现；设备默认保存直接失败，RUNNING/DELAYED 培养保存因审批候选链缺失失败。中试第3步需要补齐提供方和跨模块提交边界。
5. 重启尚无真实执行：M07-028 校验后明确失败；现有测试也断言返回缺依赖，而不是重启成功。客户端按钮或假数据不能替代该能力。
6. 启动状态与开始完成缺口：已有首次工作流事件，不等于开始细胞培养完成。只补页面会留下开始完成时刻、延期判定、后续流程前置的断点。
7. 泵角色必须保留：开始培养的小试填充操作属于取样泵；当前可执行预填充属于补液工作流。可复用命令、幂等、安全停止等设施，但不能复用补料通道身份或把补料成功写成取样填充成功。

业务拥有方建议沿现有边界：M04 提供定义；M07 编排开始培养步骤、设备命令与可信完成事实；M03 拥有培养信息、初始重量和生命周期；M02 提供设备身份、状态与协议能力；M09 拥有告警配置；M05 消费细胞类型并处理检测比对。这是补齐职责建议，不表示相关新 Port 已冻结。

## 4 不能直接认定为代码缺陷的口径差异

- 独立接种重量：仓库当前合并需求第110行明确“初始培养体积和接种体积加总后录入一个字段”。因此上一轮仅按客户文档发现的字段疑问，不能直接转为新增独立接种列的开发项。须明确 V4.1 是否改变既有确认；当前审阅未替用户变更该口径。
- 公共工作流入口：现行 M07 页面设计允许公共 RunWorkflows 入口，实验室工作台不是唯一入口。这个导航决定不等于允许省略实验室范围，也不解释开始培养业务尚未接通。
- 现行 M07 W01—W08 设计主要覆盖补液相关流程，并明确提到“没有真实开始培养实现时使用隔离模拟事件验证”。本次以用户指定 V4.1 识别目标差距；不把旧设计范围与新需求差距全部称为回归缺陷。
- 当天过期时刻、跨天续做、MFC/转速为0是否通过、状态数据时效，以及中试新在线监控互通，仍需需求或设备合同明确。本次不猜默认值。

## 5 建议补齐顺序与验证要求

1. 冻结两类开始培养的流程编码、四步定义、候选准入、首次登记与取消保存点；确认初始重量既有合并口径是否保留。
2. 补 M03 首次信息登记与 START_COMPLETED 事实应用，补 M09 工作流完成时告警配置生效及设备默认策略。
3. 补 M07 两类执行分支及前端向导：小试批量/单台续做，中试单台/取消从头，均验证重复完成与并发。
4. 对接取样泵、MFC/加热膜/搅拌读数和 OPC 服务管理；先完成真实协议与身份约束，再做现场联调。
5. 按层验收：单元/契约 → SQL → HTTP → 浏览器 → 设备。重点覆盖跨实验室、非成员、非当天、中试普通培养、缺字段、批量部分未确认、各步骤取消、未知命令、断网重试与不可重复完成。

现有测试源码覆盖 W03 候选、连接完成、预填充命令、取消和首次工作流事件等；本轮未执行这些测试，不能报告其当前通过，也不能把它们算成开始培养验收。
