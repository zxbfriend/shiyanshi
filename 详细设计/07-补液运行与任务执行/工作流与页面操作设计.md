## 2. 预填充、模式与服务操作

真实计量资源排他保持：共用同一真实秤不能同时结算多泵，缺可分辨计量证据时逐泵执行。W01/W02本轮显式SIM不做实测计量，不同泵即使同一模拟秤也可同时START，同泵RUNNING/未决仍互斥。小试每一控制器同一时刻仅一个泵预填充；W07跨控制器并行仍由各资源组能力决定。

复制净重/泵速仅复制到同培养其他选中泵，逐行重验量程、精度与枚举；不能复制命令身份或已执行状态。按钮开始/停止有独立requestId，收到ACCEPTED显示“已提交，等待设备确认”，不是已开启/已结束。实际开始、实际停止、读数证据、操作者及页面参数全部留存。

步骤可跳过预填充，需二次确认；无未停泵/UNKNOWN才可跳过或完成，不能关闭弹窗即释放资源。W02以整页判断：全页无预填充或显式跳过须确认及原因；部分prime整体完成时未做成员按PAGE_PARTIAL_PRIME记录，不造skipConfirm。其他流程维持各自SKIPPED规则。

服务重启只针对核准远程服务身份提供RESTART能力，不能执行浏览器给的URL/命令。其影响设备有运行/暂停/UNKNOWN占用则拒绝普通重启；重新获取服务状态不能清空原命令。具体重启协议未交付时只显示连接状态和未就绪原因，不伪报重启成功。

## 3. 取消、完成与部分成功

开始时保存实例和授权/版本证据，未执行草稿可取消；页面“不保存”不删实例的审计和已发生动作。其他实际执行流程已经确认的物理换袋事实保持，新预填充失败不恢复旧物理袋；实例显示需处理，可重新进入原实例完成剩余步骤。本轮W02仅模拟，步骤2只是暂存，按本文件开头最新确认：任意未最终完成阶段可在二次确认且泵已停止/无未决后取消，放弃本次换袋，下次从第1步开始。W04实际补料开始后禁用普通取消，必须经安全停止/异常路径收口；W05未提交可取消，提交后只能读登记记录。

多对象操作先预检全量选择上限及输入。W02本轮从启动到页面步进、最终保存和取消均以服务端manifest为整页边界：同一次父守卫全量锁定/prepare后apply，失败不留下部分APPLIED；前端逐泵请求不是批事务。单泵启停仍有独立幂等身份及安全状态，不能由此推导成员可独立最终保存。其他真实执行流程按各自对象返回成功/待核对/失败，已发生物理动作不能被本地事务回滚；同次未知结果沿原请求键恢复，不重复生成计划或追加量。

连接最后完成事务同时写完成事实、运行连接标志和计划生成事件；按(cultureId,connectionGeneration)唯一，重启/重复点击不重复生成。实际固定计划创建失败保留待生成事件，连接事实不回滚；UI单列“已连接，任务生成待处理”。工作流完成不等于所有未来补液已执行。

## 4. 量与物料投影

W07 创建实例在原 M07-023 管理守卫事务内追加 `LOCAL / WORKFLOW_STARTED` 审计事件，并返回实例白名单字段快照。事件使用完整事件信封、规范 JSON SHA-256 摘要和每瓶派生请求键；actor 的 managementRevision 记录本次守卫校验的写前版本。事件落账失败不得返回成功；原键幂等回放不重新执行创建回调。本事件只表示流程实例创建，不是设备启动回执，也不生成 `FIRST_WORKFLOW_STARTED`、物料消耗或培养状态变更。无需新增前端交互。

步骤详情补充 `actorUserId`（十进制字符串）、`startedAt`、`endedAt`，直接投影步骤表的已存事实，空值不推算。`actorUserId` 表示最近一次步骤操作人，不代表首次启动人；这些字段不等同于完整操作日志或设备启停回执。仅补后端读取能力，不调整页面交互。

其他实际物料执行流程按各自契约建立装载会话及物理袋实例身份，不因中试规则放宽。一培养可有多个泵的不同袋；新袋累计从0开始，旧袋消耗及培养累计不清空。中试 W02 根据后续确认以型号、补充净重及装载记录区分本次换袋，不要求人工输入实体袋身份；正式业务记录可保存但设备事实需另行核实。公共 materialSession 的现有字段及数据库约束是否需要中试专项调整，须由相关负责人落实，不能据此段声称已改表。

真实预填充消耗进入物料消耗记录，其默认目的为管路，不计培养补入量；只有经过核准的入罐计量事实才可计培养账。W02模拟启停不产生真实消耗或培养补量，也不把请求量当实际测量。W05只有培养补液登记，不凭该登记猜测某物理袋库存减少。W06/W08改变的是实例当前量确认，不实现A2排除的耗材库存自动扣减。

M02当前量写入调用受控applyMaterialObservation事件，以resourceRef、旧版本、新session和核准单位原子校验。PLC原始观测不删除；新确认与后续PLC读数的来源/时间区分，迟到旧session数据不得覆盖新瓶投影。若该设备当前量仍由PLC拥有，适配器需回执后才显示设备已更新；记录完成与设备同步状态分栏。
