## 1. 当前实现与边界

实现三种模式 ONLINE_TIME、ONLINE_CULTURE、OFFLINE_CULTURE；来源读取、Redis 查询快照、连续加载、完整结果选择、多 Y 轴、在线按培养自然/相对时间切换、离线固定D0相对横轴、分图、容器颜色、在线叠加虚线、图例/缩放/图像下载及选中点 CSV 输出。M08 不写任何业务表，不连接旧库，不启动设备采集，不改变结果状态或签批。

来源权限复用 SmpPermissionService.resolveHistoryScope 与 LabAuthorizationService，不新增授权框架。显式培养及设备均预检；发生时实验室逐项检查，快照每次访问重新校验。业务源变化后图表拒绝 SOURCE_VERSION_CONFLICT，消息提示重新统计。queryId 绑定服务端当前用户。

**实现完成不代表可验收。** 分段最早选点及四个实验室已由用户确认；未知实验室继续拒绝。中试反应器阶段仍缺可信历史容器身份。未知样品不猜测容器，列入 PARSE_UNVERIFIED。真实来源、菜单权限、部署、HTTP、浏览器及现场验收分别跟踪。

## 4. HTTP契约

路由为 system 服务内路径，经过网关时沿现有 system 前缀。全部要求 data:statistics:query，服务端再核对象范围。

| 编号 | 方法与路径 | 输入和输出 |
| --- | --- | --- |
| M08-API01 | GET /data/statistics/options | 在线/离线全量已维护未删除指标目录及展示标签，itemId/label/offlineStatName/unit/detectClass |
| M08-API01-C | GET /data/statistics/culture-options | level=PROJECT/BATCH/CULTURE，projectId/batchId、keyword≤100字、limit默认100且≤500；返回统计可读培养的祖先/培养候选，权限data:statistics:query，不附加业务管理列表功能码 |
| M08-API01-L | GET /data/statistics/culture-labs?cultureIds=… | 所选最多9培养当前所属、且经培养/VIEW权限校验的实验室ID集合；前端与既有有权实验室名称候选取交集 |
| M08-API01-D | GET /data/statistics/devices?labId=…&mode=…&cultureIds=… | 有权实验室的小试控制器/中试反应器候选；两类培养模式取所选培养当前及历史绑定设备与实验室当前设备交集，未选培养返回空 |
| M08-API02 | POST /data/statistics/queries | Query，X-Request-Id；返回READY、计数、排除摘要、到期及选择版本 |
| M08-API03 | GET /data/statistics/queries/{queryId} | 当前查询计数/选择版本/全快照培养D0起点origins，表格不从已加载部分猜零点 |
| M08-API04 | GET /data/statistics/queries/{queryId}/rows | cursor；当前源码limit为1—2000，Controller默认200，页面大结果使用2000；返回rows/nextCursor，不混同SET_ROWS≤500 |
| M08-API05 | PUT /data/statistics/queries/{queryId}/selection | expectedSelectionVersion、ALL/NONE/SET_ROWS、rowIds≤500、selected |
| M08-API06 | POST /data/statistics/queries/{queryId}/charts | selectionVersion、axisMode；在线按时间仅NATURAL，在线按培养支持两种，离线仅CULTURE_RELATIVE；完整已选点和各培养origin。chart-pages分块出口同样校验横轴 |
| M08-API06-P | POST /data/statistics/queries/{queryId}/chart-pages | 现行ChartPageRequest、cursor；复用同一快照/选择与来源校验，不触发新统计 |

Query字段：mode、可选labId、cultureIds[]、deviceRefs[{deviceKind,deviceId,channelCode?}]、onlineItemIds[]、offlineItemIds[]、startAt/endAt、pointsPerDay。只接受正整数十进制字符串ID；时间带offset，转换UTC。ONLINE_TIME必须选择lab、device、onlineItem、起止时间，时间成对且结束晚于开始、不超过上海三个日历月，左闭右开。ONLINE_CULTURE及OFFLINE_CULTURE均没有时间条件且拒绝携带startAt/endAt。

采用档位12/24/48/72/144，分别每120/60/30/20/10分钟，严格目标分钟且不限秒，默认12。在线按培养最多9培养、培养数＋指标数≤10；按时间最多9设备、设备数＋指标数≤10。离线按培养以离线统计名归并后的指标组数计数。

原M08 API02中的异步QUEUED/BUILDING在首版采用有容量上限的同步构建：整份结果准备好后才READY，不返回半成品。大范围拒绝缩小范围，不截断并宣称完整。原设计410查询过期在本批复用现有canonical QUERY_EXPIRED（409），不创建平行异常；权限不足和来源不可见继续使用现有403/404，Redis不可用503。

选择接口只写用户临时视图，不是业务管理写，不添加或绕过 @ManagementGuardedWrite。现有业务写接口的X-Management-Revision要求不变。ALL选择整个快照，不是当前浏览器加载的200行；并发修改通过Redis原值CAS拒绝，TTL不因修改延长。创建以用户+X-Request-Id短期幂等，异条件复用请求ID409；快照过期后新查询取得新queryId。
