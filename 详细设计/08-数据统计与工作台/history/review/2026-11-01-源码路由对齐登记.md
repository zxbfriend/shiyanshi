## 4. C 类完整登记：M08-源码-01 · POST /data/statistics/queries/{queryId}/chart-pages

编号说明：冻结台账与现行文档均未给该口编号，为避免与 M01—M09 契约编号混淆，本登记使用临时标识“M08-源码-01”，待 owner 裁决正式编号（是否并入 M08-API06 或新设 API 行）。

- 用途：大图分块传输出口。charts（API06）一次性返回完整图表；本口按游标分批返回同一图表的点集，首末批核验来源、各批核验权限口径由服务实现落实（StatisticsApplicationService.java:208 Javadoc：“大图分块传输；游标绑定查询、选择版本、横轴及已验证来源的票据。最后一页再次核验来源”）。属已恢复的在线/离线统计首版能力范围，不引入新业务写。
- 路径双形态：`POST /system/data/statistics/queries/{queryId}/chart-pages`（system 前缀）与 `POST /data/statistics/queries/{queryId}/chart-pages`（Controller 映射本体）；工作清单 `.local/wl/M08.json` D_missing 行同记两态，`{queryId}` 源码 PathVariable 名为 `{id}`（比对允许变量名差异）。
- 参数（Body `ChartPageRequest`，StatisticsModels.java:20）：`selectionVersion:long`（必填，须等于当前快照选择版本）；`axisMode:String`（必填，仅 NATURAL/CULTURE_RELATIVE，且 ONLINE_TIME 只允许 NATURAL、OFFLINE_CULTURE 只允许 CULTURE_RELATIVE）；`cursor:String`（可空；首页为空由服务端生成票据，续页为 Base64URL `queryId:selectionVersion:axisMode:ticket:offset` 复合游标，前缀与票据指纹校验不符即拒）；`limit:Integer`（默认 2000，范围 1—2000）。Path 变量 `id` 绑定查询快照键。
- 响应（`ChartPage`，StatisticsModels.java:21）：`points:ChartPoint[]`（本批图表点）、`origins:Map<String,String>`（各培养 D0 基准，来自完整快照）、`selectionVersion:long`、`nextCursor:String|null`（end<rowCount 时返回，末页为 null）。顶层响应为现有 AjaxResult 外壳；无顶层 `managementRevision`（本模块不使用管理写守卫，读形态是否补版本字段待 owner 裁决，不虚构）。
- 权限与数据范围：端点级 `data:statistics:query`；对象范围由应用服务再核——`requireOwner` 校验 queryId 绑定当前登录用户（StatisticsApplicationService.java:364，actor 取认证上下文，未登录 `UNAUTHENTICATED`，:391），快照每次访问重验来源与权限（开发说明与接口契约.md §1）。
- 版本/幂等：以 `selectionVersion` 做乐观版本比对（不等即 `VERSION_CONFLICT` 拒绝）；分块连续性由 Redis 票据（`{key}:chart:{ticket}` 存来源 fingerprint，TTL 至快照 `expiresAt`）绑定，不依赖 X-Request-Id/X-Management-Revision 双头；重复拉取同一游标返回同批数据（快照读取，无写副作用；票据键仅在首页生成时写入临时视图命名空间，非业务表）。
- 调用链与事务：StatisticsController#chartPages（:34—35）→ `StatisticsApplicationService#chartPage`（:209—235：load 快照→版本/横轴/选择校验→首页或末页 `validateSources` 来源指纹核验→`store.full/rows` Redis 分块读取→`StatisticsAlgorithms.chart` 纯算法组装）→ M02/M05 只读来源 Port（OnlineStatisticsSourcePort/M02StatisticsSourceAdapter、OfflineStatisticsSourcePort/M05StatisticsSourceAdapter，仅来源核验路径触达）。无数据库业务写、无业务事务；Redis 票据写为临时快照副作用，不受业务管理写守卫（类 Javadoc 口径）。
- 外部投递边界：无邮件/短信/设备/AAD 等外部依赖；来源事实属 M02 采集投影与 M05 不可变结果版本，M08 只读、不反向拥有业务 CRUD（详细设计.md 恢复范围段）。真实观测来源联调仍属 BLOCKED_EXTERNAL 口径（开发说明与接口契约.md 上游缺口段，指正式反应器/控制器映射维护链，非本口直接依赖）。
- 失败路径（均 `ManagementGuardRejectException`，StatisticsApplicationService.java:395—398 工厂）：`VERSION_CONFLICT`“选择版本已变化，请刷新”（:211）；`INPUT_INVALID`“横轴模式非法”“离线统计只支持D0起始的相对天数轴”“至少选择一条记录才能生成图表”“图表批量必须为1—2000行”“图表游标已失效或不属于本次生成”“图表游标超出范围”（:212—214、:215、:226、:228）；`SOURCE_VERSION_CONFLICT`“原查询来源记录已更正、失效或不可见，请重新统计（SOURCE_CHANGED）”（validateSources :359，:219/:230 首末批触发）；`QUERY_EXPIRED`“查询已过期，请重新统计”（expired :397，load 过期分支）；`NOT_FOUND`“查询不存在或不可见”（requireOwner :364，非本人或不存在统一外壳）；`UNAUTHENTICATED`（:391）；`DEPENDENCY_UNAVAILABLE`“图表票据不可用”“统计快照存储不可用”（:221、:387—389，Redis 故障）。错误码名称逐条取自 `FutureFabErrorCode` 源码引用，未新增码。
