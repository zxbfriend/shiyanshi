# 离线数据原型逐项复核（2026-10-17）

依据：用户本轮完整粘贴的离线原型文字和图片，以及本会话最新澄清。属于问题诊断，本轮不修改业务代码、不操作数据库、不提交推送。本记录用于说明差异，不替代当前契约；待确认项不能直接作为开发裁决。

## 1. 结论与复现

当前实现不能声明已符合整张离线原型。实际调用生产`buildStatisticsCharts`，使用隔离输入复现四个场景，无API/数据库访问：

| 场景 | 当前输出 | 原型目标/结论 |
| --- | --- | --- |
| 同培养、同容器、GLC2B与GLC3B分别在两时刻，均映射Glucose | 一个Y轴、两条系列 | 原型本轮明确视为同一个统计指标；应形成同一逻辑指标系列，保留两个点与来源；当前仅改名、共轴，未实现完整归并 |
| 同培养同指标，容器SF01/SF02，切换colorByContainer | true和false均两条系列 | 原型开关同时决定容器拆线，关闭应按培养×指标成一条；当前字段被忽略，页面无开关 |
| 离线PH/OSMO，在线PH/温度，按指标分图 | PH图含在线PH；OSMO图没有在线线；温度独立图，共3张 | 用户已确认后半段：2张离线图，每张叠加全部在线指标；当前不符合 |
| 一个培养、两个离线指标、两个容器，全部拆分 | 四张图 | 原型本轮后半段按培养×指标为两张，容器应控制图内系列，不增加图数；当前按设备/容器×指标分图，沿用了此前用户另一版条款 |

复现入口：`futurefab-frontend/packages/app-smp-data/src/views/statistics/chart-options.ts`；本机隔离观察结果为`.local-runtime/offline-prototype-observations.json`。这证明当前映射函数行为，不是浏览器或真实HTTP验收。

## 3. 已有基础实现，仍需真实环境验收

- 培养必选、项目→批次→培养级联，候选调用现有selectorApi；培养/实验室权限复用现有服务。多账号、分享和全部候选是否可见需真实环境验收，不能靠夹具证明。
- 离线指标弹窗多选，候选同检测类型同离线统计名只列一次，并展开多个底层itemId查询；选择总数按培养＋离线组＋在线项≤10校验。
- 仅读取uploaded/signed/reviewed，使用检测完成时间，样品必须关联所选culture_id；有效结果版本/数值继续校验，不因画图绕过质量状态。
- 在线与离线是结果集合并集，离线列在前、在线列在后，缺项空白，不按最近时刻拼接成假完整行；在线辅助抽样默认12且隐藏密度选项。
- 数量确认弹窗、全快照默认全选、单选/全选/取消、连续滚动、培养分组与组内时间正序、D0随首条已选顺延、空选禁画及固定生成按钮已有实现。
- 生成图后隐藏列表，返回原始数据；重新查询替换旧结果；默认相对时间并支持自然时间切换。
- 在线虚线、离线实线，图例显隐、三套独立配色、深色、缩放/恢复、图像下载、多Y轴及上下限设置已有实现。单图和按培养分图的基础分组存在，但系列数量仍受上述alias/容器缺口影响。

## 4. 原型冲突与确认边界

1. 按指标分图：前半段要求按对应指标归并，完全无对应时单独出在线指标图；后半段要求只按离线指标建图，并在每张图叠加全部在线指标。用户本轮明确选择后半段：PH/OSMO离线＋PH/温度在线生成2图，各含两个在线指标。该确认覆盖前半段示例，但代码尚未修改。
2. 本轮“全部拆分按培养×指标”与此前用户粘贴的“设备×指标”不同，应明确离线采用本轮规则，不能影响在线按设备拆分。
3. 独立颜色的最新要求不取消容器分组开关；关闭分组时减少系列，保留的各系列仍使用不同颜色。
4. 样品命名D0与图表首条已选D0是不同字段语义；本轮仍保留之前已确认的相对D0顺延及自然轴切换，不因截图只画D0…就删除自然时间。
5. 示例120000条不是已确认的容量指标。当前默认来源上限20000点、配置上限100000，超限拒绝而非静默截断；大数据量验收需另明确目标，不把滚动界面等同无限容量。
