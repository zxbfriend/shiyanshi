## 1. 接收身份和数据来源

复用M02的Reading={deviceKind,deviceId,labId,metricCode,rawValue,rawUnit,value,unit,observedAt,receivedAt,sequence,quality,sourceRevision,source}。rawValue/value均为十进制字符串或null，quality=GOOD/STALE/BAD/UNKNOWN。M08接收的Envelope额外携带schemaVersion、sourceInstanceId、sourceBootId、sourceEventId、packetHash、configurationRevision、channelCode、rawPayloadRef；这些字段不进入普通用户可编辑表单。

可信服务凭据必须绑定允许的设备/实验室/协议版本。浏览器不能提交一个labId就为其导入观测。adapter提交的labId仍与真实设备配置核对；服务器receivedAt独立记录，不能接受来源声称已经被服务器接收的时间。

sourceEventId优先使用厂商稳定事件号；设备仅有循环序号时组合sourceInstanceId+sourceBootId+sequence+channelCode+metricCode。没有事件号的适配器必须先将自建接收ID和完整原包持久化到本地收件日志，再用相同ID重投。不能每次网络重试生成新ID，也不能只按时间和值去重：相同数值连续采集是合法事实。

## 2. 指标映射与单位

在线和离线指标均引用M02人工维护的dev_detector_item稳定itemId。在线接入另需核准的映射描述：设备/通道、rawMetricCode、itemId、rawUnit、标准unit、数值转换规则及版本、生效区间、sourceRevision。它是协议映射，不复制一套指标名称/分类主数据。

当前检测项目维护服务要求smp_detect_class和smp_offline_stat_name有效；当前lab_detector_item_config是检测仪项目开关，不能把控制器ID写入detector_id。M02需给在线项目核准有效分类及维护规则，M08负责映射消费；尚未配置的项目标MAPPING_UNVERIFIED并隔离，不冒充BGA/Cedex项目，也不自动新增字典。此工程接入项详见[现状核对](history/review/现状与原系统复用核对.md)。

映射只能进行已核准同维度换算。温度、压力、流量、泵速代码、重量净/毛值不可只凭名称相同合并；空单位不解释为默认g。M07采用的业务密度1约定不能扩展成所有在线设备读数的隐含单位转换。原值、原单位、原时刻、原报文摘要与映射版本同时保存；展示四舍五入不覆盖原精度。

## 3. 归档事务与重复冲突

逻辑记录分为收件证据、规范观测、培养关联版本、当前值投影、查询快照/输出记录。数据库包须逐个给出物理落点与唯一键后才能开始编码，不采用一段任意JSON代替全部事务设计。

| 接收情形 | 目标行为 |
| --- | --- |
| 稳定事件身份和内容hash都相同 | 返回原收件结果；不新建观测，不重复推进当前值 |
| 同一身份但内容hash不同 | 保留冲突证据并标记CONFLICT；不覆盖第一份内容，不按最后到达自动裁决 |
| 设备/指标/单位/时钟未核准 | 原包可进入受限隔离区；不进入正常数值曲线或物理计算 |
| 合法新事件 | 同事务保存收件、规范观测和初始关联依据；提交后才ACK为ARCHIVED |
| 重启/断网重发 | 查询原收件状态，按固定ID继续；不得以ACK丢失判定从未归档 |
| 数据库失败 | 不回成功ACK，适配器保留待发；落盘和恢复能力需接入测试 |

隔离事件有明确reasonCode、原事件身份、来源/接收时刻、人工核准人及处理记录。正常业务页面不展示原报文凭据/网络信息。后续重新映射须新处理版本并保留原错误，不能直接修改旧rawValue伪造首次正确接收。

当前值投影只指向已经归档的合法观测；按真实observedAt排序，相同时用稳定事件身份作确定排序。迟到旧样本进入历史但不倒退当前显示。同序同时时值冲突须显示冲突状态，不以内部ID大小证明物理正确。新一次BAD/UNKNOWN观测应使“当前状态”显示异常；可以另列最后有效值及其旧时刻，但不能继续把旧值标为当前GOOD。

## 4. 按观测时刻关联培养

M03是设备占用和培养关系的唯一写入方。M08通过M03提供的有版本历史区间查询，匹配deviceKind/deviceId/channelCode和observedAt，而不是receivedAt或当前绑定。采用[startAt,endAt)半开区间；设备10:00从培养A切换B，09:59:59观测归A、10:00:00归B，即使A的观测10:05才收到也仍归A。

| 匹配结果 | associationState | 处理 |
| --- | --- | --- |
| 一条可信历史关系 | MATCHED | 固定cultureId/projectId/batchId/labId、关系ID及版本 |
| 可信证明当时空闲且无培养 | UNASSOCIATED | 正常设备历史；按设备与实验室权限读取，不虚构培养 |
| 多条候选/通道不明/区间重叠 | AMBIGUOUS | 保留证据，不选第一条；正常培养统计排除并提示排除量 |
| 来源不可用或历史未核准 | UNKNOWN | 等待补偿；不能当无培养放宽数据权限 |
| 关联依据后来纠正 | REVISED | 新关联版本；原观测和原关联依据保留，当前查询使用已核准版本 |

同一控制器接多个容器时必须有经M02/M03核准的物理通道/逻辑容器身份；控制器公共指标不自动复制到全部培养。共享量若需引用须有明确测量范围及授权规则，未核准时阻断按培养关联。设备改名、培养编号更改、设备删除都不删除或重挂既有历史。

已生成查询快照保存当时associationVersion。新纠正使相关快照标SOURCE_CHANGED；新的图表/输出需重新查询确认，不偷偷改变已勾选数据。已有物理执行计算保持M07原快照，不因M08更正倒推重算泵执行。

## 5. 时间和质量

observedAt保留原始精度与时区依据，receivedAt由服务器记录；数据库统一UTC，查询/日历显示Asia/Shanghai。没有可信时区、明显超前或时钟漂移的读数进入TIME_UNVERIFIED。漂移容差、设备心跳/读数过期阈值必须来自核准的部署能力，不能凭本设计写死30秒/5分钟为设备正常。

STALE是相对于查询asOf及核准时效的状态，不需要反复修改每条历史原始quality。历史曲线“当时GOOD”和当前卡片“现在过期”分别表达。BAD/UNKNOWN及缺测保留来源和断点，不画零点、不线性插值冒充测量。对精确时刻合法0值必须显示0。

收件积压、丢包/序号缺口、冲突和无法归属的事件可发给M09；M08不自己生成安全停泵命令。M07物理计算应读取其核准的及时观测契约，不把统计抽样结果当执行前最新读数。

## 6. 查询、保留和运行交接

原始数据完整保留，12/24/48/96/144只控制统计抽取，不降低采集存储频率。现有材料没有确定归档清理年限，本批不设计自动删除或滚动覆盖；容量、分区/索引、备份与恢复、隔离重处理的管理员接口由数据库及接入专项细化。

接入验收必须覆盖真实设备报文、准确时区/单位、重复重放、冲突、断网落盘、迟到关联、权限撤销、设备迁移及吞吐压测。只验证HTTP成功或数据库有一行不能标记在线采集完成。
