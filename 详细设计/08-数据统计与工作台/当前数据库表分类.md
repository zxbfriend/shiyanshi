# 当前数据库表分类

本清单帮助新开发人员理解表结构。依据新系统完整建表基线与表拥有方清单，只读提取表名和表注释；不是运行数据库验收，也不是新增建库脚本。桌面 ymsw_v2.sql 只做表名存在性比对，不导入其中数据。

## 在线离线统计先读哪些表

- 在线：lab_observation → lab_observation_receipt（设备/通道）→ lab_observation_association（发生时培养）→ lab_observation_mapping（核准指标版本）。历史曲线不使用 current 表代替。
- 离线：det_sample → det_result → det_result_revision.content_snapshot.items。统计值来自当前有效不可变版本，不直接读取可变明细替代版本。det_result_item 是版本的原业务来源。
- 指标：dev_detector_item；offline_stat_name 归并同类离线指标，单位不同仍分别建轴。
- 业务关联：res_project/res_batch/res_culture 及成员/分享表归 M03；统计只能消费授权出口，不直接跨模块联表。
- 旧系统：表整理.xlsx 中的 cdp_ep_*、cdp_testing_* 是旧来源命名，本基线不因为这些名字存在就创建兼容表。一期原库保持原结构。
- 本次 M08 不新增或修改业务数据库表；短期查询、选择版本和期限保存于 Redis，键前缀 smp:statistics:query:，不是原始业务数据。

## 理解字段的顺序

先看稳定主键和逻辑关联，再看 object_version、状态、单位/时间、幂等/审计。display code 与真实 bigint ID 不同；样品字符串不是培养主键。current 是可重建投影，revision/outbox/receipt 是版本或可靠交接证据。配置表不是测量结果，执行台账也不能由统计重新积分计算。
