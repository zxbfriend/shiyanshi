版本 DD-20260917-G01。目标设计，尚未实现或联调。承接需求14空闲反应器业务操作；统计与跨培养图表仍留 M08。

## 路由、来源与上下文

M01 注册目标路由 DeviceOperations，参数 deviceKind、deviceId 必填，section 仅 overview/onlineAlarm/monitor；不接收 labId/cultureId 覆盖设备所属。从 M02 台式/集成反应器列表“业务操作”及有权 M09 设备告警链接进入。deviceKind 沿 M02 现有受控设备种类注册表，不新增客户端可自由映射的表名或 route。首期只接受台式、集成反应器；其他种类拒绝，不以型号 ID 代替实例 ID。

按服务器注册映射调用既有实例详情：台式 GET /lab/labbenchreactor/{reactorId}，集成 GET /lab/labintegratedreactor/{integratedId}，deviceId 映射相应真实主键；必须对应 lab:labbenchreactor:query 或 lab:labintegratedreactor:query 及实验室可见范围。完整 Detail、State、字段与管理版本沿[设备实例契约](设备实例详细设计.md)，不另造“统一设备实体”。详情成功才加载有权子组件；404隐藏整个上下文，403清旧数据，503显示不可用而非空闲。

occupancy、maintenance、connectivity 分开显示；有权培养关联列表不等于完整占用事实。是否空闲由 M03 权威占用和 M07 使用事实判定，不由前端“没有可见培养”推断。没有 cultureId 正常显示设备页，不新建培养、不伪造 ID、不依赖 M08。

## 页面组件与所属 API

| 组件 | 来源及权限 | 交互边界 |
| --- | --- | --- |
| 设备基本信息 | 上述 M02 详情 | 只读；资料编辑继续原 M02 编辑页及原 edit 权限 |
| 台式默认连接 | GET /lab/pumpconnection/reactor/{reactorId} | 沿[默认连接契约](默认连接与打印排版接口契约.md)，无权限不请求；修改走原 PUT，不经本页新增写模型 |
| 关联培养 | M03 CU06，见[运行变更与设备关联查询](../03-项目与培养管理/培养运行变更页面与接口契约.md) | 按有权范围分页；无日期培养正常列出；仅有培养 query 权限时链接 CultureOperations |
| 设备在线告警 | M09 API10/11 /alarm/v2/online-config，scopeKind=DEVICE | 复用 UI06 在线部分；无离线四类页签，离线阈值仍严格属于培养 |
| 非补液监控 | M09 API14/15 /alarm/v2/monitor-policy，设备 scope | 复用 UI07；不关闭 M07 执行安全监控 |
| 声光关闭 | M09 API16 | 使用当前设备真实绑定声光报警器的 ID/kind，不把反应器 ID 填到 sound/{deviceId}；M02 声光权限及命令查单规则保持 |

设备级在线模板只在真实完全空闲或仅无日期培养关联的合法状态下保存，M09 提交时重新检查；页面打开后设备被预约/开始使用，返回409 STATE_CONFLICT并刷新上下文，不把原 DEVICE 草稿自动转成 CULTURE 配置。已占用设备可以按权限只读查看模板，实际培养告警修改必须进入该培养。依赖无法判定返回503，不退化为直接保存。设备模板直接保存，不制造 M06 审批单。

告警界面显示继承模板/培养独立集合差异；DEVICE 保存不覆盖已有培养集合。监控和声光动作以其原 API 动作资格单独校验，不能根据模板可写就授权物理命令。声光无绑定或绑定未知则禁用并说明，不允许输入任意目标 ID。

## 加载、并发与验收

切换设备、退出、失权后取消旧请求并增加页面上下文代号；回包必须与当前 deviceKind/deviceId/代号相同才能显示。子组件独立失败不清除已成功的设备详情，也不把失败显示为空记录。版本冲突保留非敏感草稿供对比，不自动重提；未知写结果按原请求/命令身份查询，不换请求键。

G01-A01：完全无培养、仅无日期培养关联均可进入并按权限保存设备模板；不请求培养详情。
G01-A02：无权关联培养不输出 ID/编号，不用空列表证明空闲；设备权限不授予培养权限。
G01-A03：打开后预约/迁移实验室/解绑声光并发，写端拒绝旧资格，旧响应不覆盖新设备。
G01-A04：M08 路由/API 禁用，M02 详情、CU06、M09 配置/监控仍可工作；设备离线不伪装在线，监控 ACK 未知不显示已生效。
G01-A05：模板配置、非补液监控、声光关闭逐项权限拒绝；执行中的安全监控不受非补液开关影响。
