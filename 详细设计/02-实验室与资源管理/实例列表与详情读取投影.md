# M02 实例列表与详情读取投影

2026-10-18 INS-05-01/02增补：检测设备列表与详情只读返回communicationType=HTTP/NAMED_PIPE/null，精确关联当前未删除的DETECTOR通信配置。型号显示名modelName取model_name，缺失才回落detect_type；型号主键、字典值和协议键不互相替代。communicationType仅描述已配置的通道，不把它投影为ONLINE或APPLIED；通信写仍走独立配置入口，不进入实例写白名单。详见[本次检测联调专题](检测实例规则应用与命名管道接线契约.md)。

版本：DD-20260913-T8-R3。依据[设备实例第3—7节](设备实例详细设计.md#3-字段约定与请求结构)、[集成反应器参数第4节](集成反应器型号与实例参数契约.md#4-当前接口的目标补充)、[型号第16节](设备型号库设计.md#16-完整响应同步和技术兼容定案)和[字段字典](收尾后完整数据库字段字典.md)。这是目标JSON投影的技术收口，不表示现Controller已返回这些字段；前后端实施时按明确白名单同步升级旧序列化。

## 1. 外壳、身份和读取规则

12类list/detail共24个HTTP读取入口，路径/权限原样保留。Authorization必填；GET无Body，无写版本头，不写管理回执、不递增版本、不发送物理命令。功能list/query外叠加当前实例实验室可见范围；列表先范围过滤再count/page，详情不存在和不可见统一404。缺功能403。响应外壳沿M01第17.1节，列表顶层rows/total/pageNum/pageSize，无data；详情data为下述完整投影。

每类型只返回自己的真实主键（reactorId/balanceId/pumpId/airPumpId/detectorId/integratedId/containerId/scaleId/deviceId/alarmId/printerId/relayId），不新增通用id别名。原第3节“＋id”为身份概称，不能当作与第7节不同的字段名。Audit、State表示字段集合平铺到投影，不另套audit/state对象；同名maintenance/enabled仅一份。

公共字段：labId:string、labName:string/null（当前授权显示名）、createBy/updateBy:string/null（历史账号）、createTime/updateTime:ISO8601/null、managementRevision:string、maintenance:boolean/null、enabled:boolean/null、occupancy:IDLE/RESERVED/IN_USE/UNKNOWN、connectivity:ONLINE/OFFLINE/UNKNOWN、configurationReady:boolean、configurationIssues:string[]。有venueId的类型额外venueName:string/null；有ownerUserId的类型额外ownerDisplayName:string/null，只是当前负责人显示，不冒充历史操作人。所有对象/版本ID为十进制字符串；自身主键与labId不可空，历史可写业务字段缺失可返回null并标配置缺项，不以新增必填规则伪造旧值。

State沿原三维分离：维护不代表占用或在线；不适用的布尔项null，未知占用/通信使用UNKNOWN。relayStatus使用既有0关闭/1开启字符串，无可信回读时null，绝不把数据库默认0当作已确认关闭。读取失败不能用0、空数组或IDLE伪装；依赖事实未知而资料可读时返回UNKNOWN和配置问题，不能据此开放写入/执行。

以下投影由三部分组成：公共字段＋对应[可写业务字段](设备实例详细设计.md#4-类型字段及复用映射)（不含WriteMeta）＋第2节列明的只读字段。未列实体列、凭据、任意关联对象均不输出。可写字段的类型/范围以源字段表为准，Decimal读为字符串；不在读取时截断精度。每类型的列表Row与Detail字段相同，唯一例外是集成Row省略pumpConfigs/externalPumps两个聚合数组，详情必须返回两数组；不在列表返回[]冒充“没有泵”。

## 2. 逐类型只读字段

| 类型 | 只读字段、类型/可空及来源 |
| --- | --- |
| 台式 | brand/brandLabel/category/categoryLabel/capacityUnit/description:string/null，iconPaths:string[]；来自当前台式型号，实例maxCapacity不被型号覆盖 |
| 天平 | brand/brandLabel/modelName/spec:string/null，precisionValue:decimal-string/null（g）；来自称重型号，不将量程文本强制转数值 |
| 蠕动泵 | brand/brandLabel/modelName:string/null，maxFlow:decimal-string/null（L/min）；spec仍是实例字段，pumpSpeed为g/min，两者不可直接比较 |
| 空气泵 | brand/brandLabel/modelName:string/null，maxFlow:decimal-string/null（L/min）；workSpeed沿需求g/min，不凭名称换成体积流量 |
| 检测 | modelName/detectType/description:string/null；detectionCount:非负十进制string/null，目标读字段由M05按检测尝试首次进入检测中事实去重聚合，无可靠完整基线返回null；不添加设备主表假计数默认值 |
| 集成 | 保留现DetailVo的modelName/spec/pressureUnit:string/null、capacity:decimal-string/null（g）、floorScaleDisplay/feedScaleDisplay/relayDisplay/alarmDisplay:string/null；modelCapabilities为已定义CapabilityView，不重命名为普通model对象 |
| 容器 | containerNo/containerTypeLabel/spec:string/null；volumeMl:decimal-string/null（mL），由规格解析/核验；不得只截规格数字 |
| 地秤 | brand/brandLabel/modelName/spec:string/null，precisionValue:decimal-string/null（g），alarmHighLimit:decimal-string/null（历史实例上限，g）；不默认从型号填已有上限 |
| 下游 | brand/brandLabel/modelName/spec/description:string/null，precisionValue:decimal-string/null；floor_scale取称重型号，其余取分析仪，源型号不定义的spec/precisionValue返回null |
| 声光 | 无额外型号对象；description为本实例字段；通讯详情单独读取 |
| 打印 | 无额外型号对象；printLimit为本实例字段；排版由专用接口读取 |
| 继电器 | relayStatus:"0"/"1"/null，仅可信回读事实；通讯与操作不通过资料写接口修改 |

modelCapabilities全部键：modelId:string、modelName:string/null、spec:string/null、capacityG:decimal-string/null、pressureUnit:string/null、pumpCount/mfcCount:integer/null、thresholdWeightG:decimal-string/null、temperatureControl/weightControl/pressureControl:boolean/null、managementRevision:string、ready:boolean、issues:string[]，直接采用集成参数契约CapabilityView。capacity与capacityG同质量单位，不把它们当培养工作体积。

集成详情保留既有needExternalPump:"0"/"1"（0否1是）及remark:string/null；pumpConfigs数组的每项pumpNo:integer、rangeValue:decimal-string（g/min）、strategy:string/null，稳定编号按既有固定泵契约。externalPumps沿现有字段名：每项pumpId:string、pumpUsage:string/null、rangeValue:decimal-string/null、strategy:string/null；pumpUsage是关联表历史用途只读，不能由数组顺序推断。历史外置量程允许保留物理decimal(18,4)精度；保存仍按既有DTO≤2位、策略≤200，不能把只读历史值的存在当成放宽写入精度。外置泵量程的现场单位/策略映射未核准时不用于执行计算。

## 4. 错误与读取断言

```json
{
  "code": 404,
  "msg": "对象不存在或不可访问",
  "requestId": "00000000-0000-4000-8000-000000000003",
  "errorCode": "NOT_FOUND",
  "data": null,
  "fieldErrors": [],
  "retryAfterSeconds": null
}
```

GET /lab/balance/list?pageSize=101，HTTP 400：

```json
{
  "code": 400,
  "msg": "分页大小超出允许范围",
  "requestId": "00000000-0000-4000-8000-000000000003",
  "errorCode": "INPUT_INVALID",
  "data": null,
  "fieldErrors": [],
  "retryAfterSeconds": null
}
```

当前身份没有对应类型list/query功能权限，HTTP 403 PERMISSION_DENIED。认证错误沿M01原认证外壳；只读响应不加入配置写的REQUEST_CONFLICT/MANAGEMENT_CONFLICT。有权范围内无匹配数据返回200、rows=[]、total=0。若内部依赖故障导致无法可靠完成本次读取而非可展示的局部未知，返回503 DEPENDENCY_UNAVAILABLE，不生成伪造成功响应。

逐类型断言：真实主键不出现通用id副本；Detail与Row除两聚合数组外一致；所有可空字段存在且用null；无凭据和实体隐藏列；当前显示名不覆盖历史账号；重复GET无写入；多个实验室先授权再分页；UNKNOWN/false/null三者不混淆。检测计数投影来源仍需T9对照M05消费者，不把字段定案当作计数代码已经实现。

本批收口24个实例读取入口的目标输出投影与非空样例。类型专属Query筛选、其他写接口及消费者兼容仍在T8/T9分别核验；旧实体返回适配尚未实现。

## T9-R1 detectionCount来源

detectionCount由M05按detectorId和稳定attemptId对首次进入检测中的事实去重汇总，完整字段交接见[T9 M02消费核对](../00-跨模块审阅收尾/history/review/T9-M02消费交接逐字段核对.md#1-m05检测事实--m02检测设备摘要)。M05样品detectCount是当日检测次数，不能直接作为本字段来源。新增resultFactWatermark/asOf/complete只存在内部汇总结果；M02列表/详情仍只展示detectionCount并在不完整时返回null及问题。
