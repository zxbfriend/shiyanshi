# M02 四类资源逐接口契约

## 公共传输、事务与失败协议

本文为DD-20260913-T8-R5目标契约，复用[检测与资源配置详细设计](检测与资源配置详细设计.md)及M01公共响应；样例均为模拟数据，不证明接口已实现。ID为正十进制字符串，版本为非负十进制字符串；JSON整数只用于有明确int范围的数量/序号，Decimal用十进制字符串。未知与null不得转换为0。

所有配置写请求携带X-Request-Id（UUID）及X-Management-Revision（SYSTEM管理版本），示例初始21、成功22；这些不是Body字段。每个样例独立运行，真实串行提交需新请求ID及最新版本。写入先鉴权、校验白名单，然后在同一管理守卫事务内重检版本、对象和引用，更新配置、审计、版本和幂等回执一起提交。并发占用判定必须与M03/M07占用转换共用锁/守卫或等价原子协议，不能查空闲后无保护落库。T9须验证双方实际锁顺序与消费字段。无锁可靠性/依赖不可用时失败，不猜测空闲。

同请求ID同体且仍有权，回放首次已提交回执；同键异体409 REQUEST_CONFLICT；无回执且旧版本409 MANAGEMENT_CONFLICT。事务前/中任一失败均无部分保存、无成功审计、版本不增加；超时先以原键原体重试核对结果，不能新键覆盖。GET无配置写、无WriteMeta，重复读取按当前授权重新取值。

| 场景 | HTTP/错误码 | 适用 |
| --- | --- | --- |
| 结构、枚举、范围、重复ID、非法引用、缺必填 | 400 INPUT_INVALID | 有参数的读写 |
| 提交只读字段/审计/观测 | 400 READ_ONLY_FIELD | 写 |
| 缺功能权限或实验室操作/管理等级 | 403 PERMISSION_DENIED | 读写 |
| 指定对象不存在或不可见 | 404 NOT_FOUND | 对象接口 |
| 同键异体/旧管理版本 | 409 REQUEST_CONFLICT / MANAGEMENT_CONFLICT | 写 |
| 合法资源已被占用 | 409 RESOURCE_IN_USE | 液瓶写 |
| 唯一值重复 | 409 NAME_CONFLICT / CODE_CONFLICT | 四资源写；耗材编码用CODE_CONFLICT，其余名称用NAME_CONFLICT |
| 依赖不可用/管理锁争用 | 503 DEPENDENCY_UNAVAILABLE / MANAGEMENT_BUSY | 前者读写，后者写 |

认证失效沿M01认证域错误，不新增另一套认证码。下文特有失败补充在对应接口节；统一错误样例：
```json
{
  "code": 409,
  "msg": "管理版本已变化，请重新读取后核对",
  "requestId": "00000000-0000-4000-8000-000000000005",
  "errorCode": "MANAGEMENT_CONFLICT",
  "data": null,
  "fieldErrors": [],
  "retryAfterSeconds": null
}
```

四类均为全局主数据，只要求各功能权限，不虚构labId或全部实验室管理权。有效唯一分别为weightName、description、mediumName、itemCode，修改排除自身；耗材描述可重复。删除为del_flag=2，保留原ID和历史引用；新选择过滤删除项，已有任务使用快照。不能以普通引用存在为由擅改既有软删除策略。

完整覆盖以下20个CRUD入口；四个export复用[已核实的XLSX文件契约](既有导出接口与文件响应契约.md)。另保留的check-unique见末节，不把预检查当提交约束。

公共ListQuery：pageNum整数默认1且≥1，pageSize整数默认10且1—100，keyword可省略字符串trim后空串等于未筛选；本批技术上限100。除培养基外还允许timeField=createTime/updateTime（默认updateTime）、startDate/endDate为YYYY-MM-DD，可单端；区间为上海时区起日00:00到终日次日00:00（不含），起日不得晚于终日。培养基只允许keyword和分页。未知查询字段拒绝，不允许透传实体delFlag或排序表达式。排序createTime DESC、真实主键DESC。

keyword目标映射：校准对象weightName，液袋description，培养基mediumName，耗材itemCode或description联合模糊；作为绑定参数处理，%/_按字面字符搜索。这是现有通用keyword的技术补齐，不声称旧Mapper已支持。

Detail/Row平铺真实ID、业务白名单（iconPath转iconUrl）、createBy/updateBy:string|null、createTime/updateTime:ISO8601|null、managementRevision。业务历史缺值如实null，不伪造默认；iconUrl:string|null，无图由UI显示默认图。编辑无新上传时由服务端保留原路径；为避免把展示URL回写，PUT中iconPath省略=保留、null=清除、有值=替换，POST省略/null=无图。其他可选字段PUT省略按各自默认/null处理，PUT是完整业务表单。文件验证失败400 INPUT_INVALID，文件依赖不可用503；不接受任意远端URL作为路径。
