# M02 编辑候选响应契约

版本：DD-20260913-T8-R2。补充[实例第7节](设备实例详细设计.md#7-接口规格)的12个INS-xx-07读取接口。Option复用[M01第17.2节](../01-系统管理/详细设计.md#172-dto展开无隐含实体字段)，不是新增公共DTO；ReferenceOption仍采用M02原定义。

## 1. 全部叶子及来源

| 字段 | 类型、null与来源 |
| --- | --- |
| models / owners / venues | Option[]，固定返回且无项[]；分别是当前类型可选型号/规格、负责人、场地，不把完整SysUser返回浏览器 |
| Option.id | 正bigint十进制字符串，真实来源主键；models中的容器规格取specId，分析仪取analyzerId，不换成其他型号ID |
| Option.label | 非空string，当前有权候选显示值；不能把label反写为ID或型号协议键 |
| Option.disabled | boolean，当前选择是否禁止作为新引用保存；复用M01规则 |
| Option.disabledReason | string/null；禁用必须给可理解原因，正常为null，不含无权对象资料 |
| Option.children | Option[]；本接口扁平候选每项固定[]，不展开整个用户/部门树 |
| references | ReferenceOption[]，固定返回；类型相关引用候选，未核实的依赖不能当作正常空集合 |
| ReferenceOption.id / label / kind | string，id为真实来源主键，label当前显示值；kind由M02引用解析器按已有设备/资源种类填写，不接受客户端指定表名 |
| ReferenceOption.role | string/null；已有用途角色，未设角色为null，不从数组次序猜角色 |
| ReferenceOption.available | boolean，当前是否可作为新引用；不是未来保存资格或设备在线证明 |
| ReferenceOption.unavailableReason | string/null；available=false须有不泄密原因，true时null |
| managementRevision | 非负十进制字符串，与本次读外壳一致；保存仍重验最新版本 |

四数组是完整data字段，不能只返回其中非空数组。当前已选失效对象在用户仍有权看到其历史身份时保留并标禁用/不可用；已失去读取权限的对象不得为了解释而泄露名称，失败按存在性隐藏策略处理。功能权限为对应add或edit，另查目标labId操作等级；编辑先从当前对象核对原实验室及目标实验室，不能仅信Query labId。

请求Header Authorization，GET无Body且无需写Header；Query labId必填ID，对应实例主键和modelId按编辑/选型需要可选。型号/负责人/场地候选按实际可写字段适用，不为声光、打印、继电器虚构型号或负责人字段。查询只读，不写业务回执、不递增管理版本、不占用资源。

| GET /lab/labdetector/edit-options | lab:labdetector:add / lab:labdetector:edit | 检测；真实主键modelId | owners适用；venues适用 |

容器规格按已确认containerType联动，不能把任意specId当成当前类型；下游类型的精确查询选择字段、复杂references候选种类与角色全集仍须与专用配置契约逐项收口。本表只明确已有12个接口及类型适用性，不擅自添加新的Query键或角色枚举。

## 3. 非空成功与失败样例

独立夹具：有权实验室1001、当前可选负责人101、称重型号2004；无场地要求。用于天平新增候选，不代表全类型references样例覆盖。

GET /lab/balance/edit-options?labId=1001，HTTP 200：

```json
{
  "code": 200,
  "msg": "操作成功",
  "requestId": "00000000-0000-4000-8000-000000000002",
  "managementRevision": "13",
  "data": {
    "models": [
      {
        "id": "2004",
        "label": "模拟称重型号",
        "disabled": false,
        "disabledReason": null,
        "children": []
      }
    ],
    "owners": [
      {
        "id": "101",
        "label": "模拟负责人",
        "disabled": false,
        "disabledReason": null,
        "children": []
      }
    ],
    "venues": [],
    "references": [],
    "managementRevision": "13"
  }
}
```

GET /lab/balance/edit-options?labId=invalid，HTTP 400：

```json
{
  "code": 400,
  "msg": "实验室主键不合法",
  "requestId": "00000000-0000-4000-8000-000000000002",
  "errorCode": "INPUT_INVALID",
  "data": null,
  "fieldErrors": [
    {
      "field": "labId",
      "message": "需要正整数十进制字符串"
    }
  ],
  "retryAfterSeconds": null
}
```

候选依赖读取失败，HTTP 503；不返回HTTP 200与空候选伪装成功：

```json
{
  "code": 503,
  "msg": "候选资源读取失败，请稍后重试",
  "requestId": "00000000-0000-4000-8000-000000000002",
  "errorCode": "DEPENDENCY_UNAVAILABLE",
  "data": null,
  "fieldErrors": [],
  "retryAfterSeconds": null
}
```

其他拒绝：当前功能/操作权限不足403 PERMISSION_DENIED，不存在或无读取范围404 NOT_FOUND。输入错误不写入，重复GET不抢占资源。契约断言包括Option递归键完整、叶子children=[]、禁用候选不能保存、查询后权限/版本变化正式保存重验。

本批关闭Option定义定位与通用响应结构缺口；12类逐项references全集及各类型非空夹具尚未全部通过，不按“公共样例存在”勾选全类型完成。
