方法学校正（本轮据上一轮缺陷固化，M02 后续批次沿用）：

1. **`fe_by_path.txt` 的 `used=0` 不能证明无消费者**：共享组件经 props 接收 api 对象时静态匹配为 0（实测 `member-dialog.vue:57/61` 的 `memberTree`/`memberDetails` 静态 0 命中但真实在用）。故本登记的「无消费者」结论一律回到页面 `import` 来源与解构行号人工核对（下表第 3 列）。
2. **同名函数的 `used=1` 多为 token 碰撞**：`checkCanDelete`/`changeStatus` 在各模块 SDK 各自定义，`used=1` 的页面列表须核对解构来源模块。实测 `lab-balance/index.vue:169` 的 `checkCanDelete` 来自 `labBalanceApi`（`sdk-smp-api/src/modules/lab/balance.ts:58`），与 `benchreactorcontroller.ts:126` 的同名函数无关 →  `/lab/pumpconnection/{id}/check-delete` 仍无消费者。
3. **有 Spring 映射注解即登记为 HTTP 接口**：`@InnerAuth` 只是访问边界，「内部业务用途」不等于非 HTTP；`select-options`/`check-*` 的「辅助」是业务角色标注，接口性质仍为公开 HTTP。
4. **有 canonical 编号不等于 A，无编号不等于 C；停用/被替代不得混入 E，在用不得留在 F。**
