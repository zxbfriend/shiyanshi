## 1. 已有字段的遗漏修正

复用needExternalPump与externalPumps：前者为字符串0否/1是，后者每项至少包含明确pumpNo和pumpId。量程等于型号通道最大量程；实例策略选填。DTO没有pumpUsage可写字段，历史用途只能读取并保留，不得悄悄丢弃。每个型号通道均有泵配置，externalPumps只补充对应外置通道的设备绑定。

无外置型号通道时提交"0"与[]；有外置通道时提交"1"与完整绑定数组。服务端重查通道类型、设备型号、实验室与设备状态，并拒绝重复pumpNo和pumpId；外置通道属于型号pumpCount。修改不能默默丢失历史未映射绑定，仅在SYSTEM守卫、实验室及其他既有业务校验通过后更新；失败整体回滚。删除绑定不是停泵，不能绕过运行释放。

原实例第4节新增维护DTO使用maintenance，当前源码status由实施兼容层转换；本次不把当前DTO中所有字段原样引入目标可写白名单，不借补漏回退既定维护语义。needExternalPump与externalPumps是此前既有业务字段补收。

非空外置配置Body片段（合并到完整集成保存Body，两键共同出现）：

```json
{
  "needExternalPump": "1",
  "externalPumps": [
    {
      "pumpNo": 1,
      "pumpId": "4003",
      "rangeValue": "5.00",
      "strategy": null
    }
  ]

```

该片段不是完整POST；实验室、两秤、型号与固定泵等仍必填。模拟4003为同实验室合法蠕动泵，rangeValue为模拟记录，不构成真实量程/单位核准。查询externalPumps单行投影：

```json

```

## 2. 复杂候选的字段归属

沿用GET /lab/labintegratedreactor/edit-options，现有ReferenceOption结构不另造候选DTO。role为UI表单字段路径的稳定定位值（本批技术定案），kind为固定M02设备种类，不接受客户端任意表名。

| role | kind | 真实引用与过滤 |
| --- | --- | --- |
| floorScaleId | FLOOR_SCALE | lab_floor_scale.scale_id，同实验室、非补料地秤；保存仍重验 |
| feedScaleId | FLOOR_SCALE | 同表补料地秤，与floorScaleId不同；不能仅按ID大小区分角色 |
| airPumpId | AIR_PUMP | lab_air_pump.air_pump_id，同实验室合法空气泵 |
| relayId | RELAY | lab_relay.relay_id，同实验室合法继电器 |
| alarmId | SOUND_ALARM | lab_sound_alarm.alarm_id，同实验室合法声光报警器 |
| externalPumps[].pumpId | PERISTALTIC_PUMP | lab_peristaltic_pump.pump_id，同实验室、型号匹配的蠕动泵；绑定到明确pumpNo |

这些kind是该HTTP候选白名单的明确序列化值，消费者必须按本表映射，不能把M07 deviceKind或其他表名字符串自动强制转换为本表。新增角色值后由T9核对所有前端/内部消费引用。

## 3. 失败与验收

INPUT_INVALID：标志/数组不配对、重复pumpId、负量程或超过现DTO精度、只提交标志试图清关联。READ_ONLY_FIELD：输入pumpUsage或modelCapabilities。REFERENCE_EXISTS/RESOURCE_IN_USE：配置引用或活动/未知使用阻断。MANAGEMENT_CONFLICT/REQUEST_CONFLICT：旧版本或同键异载荷。NOT_FOUND/PERMISSION_DENIED/DEPENDENCY_UNAVAILABLE沿原域定义。所有拒绝保持主记录、固定泵、外置泵、审计和管理版本的一致性，不部分保存。

契约断言：同一FLOOR_SCALE候选不能同时满足相反角色；外置通道必须逐一绑定且属于型号N个通道；型号、实验室或设备状态不符时拒绝；重排数组不更换通道身份；历史pumpUsage及无法确定通道的旧关联不得静默删除；型号量程变更不重写已固化的培养方案。

ReferenceOption.role固定使用表单字段路径；两秤、固定泵和外置泵的跨模块消费、单位与版本见[T9 M02消费核对](../00-跨模块审阅收尾/history/review/T9-M02消费交接逐字段核对.md#2-m02集成反应器--m04m03m07)。消费方不得按候选顺序或相同序号推断角色。
