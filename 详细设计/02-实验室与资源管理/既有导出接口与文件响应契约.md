## 2. 成功、错误和重试

请求仅需Authorization；这是读取型POST，不要求X-Management-Revision，不递增管理版本、不复用“配置写成功”回执。requestId由服务端生成，或校验已有追踪ID；导出审计属于读取操作日志，不引入配置事务。重复请求按当时授权与数据重新生成，内容可能变化，不能承诺相同字节幂等。

成功HTTP 200，Content-Type: application/vnd.openxmlformats-officedocument.spreadsheetml.sheet，Body是可打开的XLSX字节；没有JSON code/data/rows或taskId。目标Content-Disposition: attachment; filename="m02-export.xlsx"; filename*=UTF-8''m02-export.xlsx；这是本批建议的统一响应头，现工具MIME已核对，文件名响应头仍需实施补齐。旧前端本地命名可保留，不将文件名当服务端磁盘路径。无匹配数据仍返回表头工作簿，不能输出零字节冒充有效文件。

先完成授权、过滤、白名单投影及工作簿生成，再提交文件响应；未提交响应前失败返回application/json;charset=UTF-8与M01完整错误外壳。400 INPUT_INVALID（非法筛选/分页或任意列），403 PERMISSION_DENIED（缺功能），404 NOT_FOUND（明确对象上下文不可见），503 DEPENDENCY_UNAVAILABLE（无法可靠读取/生成）。认证失败沿M01。文件发送中连接中断无法再改写HTTP JSON，浏览器提示下载未完成并允许重新发起只读请求，不能保存错误Blob为成功xlsx。

示例POST /lab/labbenchreactor/export?labId=1001&keyword=SIM，不传pageNum/pageSize，不需要写版本头。模拟成功断言Content-Type为XLSX且解压工作簿结构完整；这里不生成假Base64当真实测试通过。缺导出权限HTTP 403完整JSON：

```json
{
  "code": 403,
  "msg": "无权导出此类数据",
  "requestId": "00000000-0000-4000-8000-000000000004",
  "errorCode": "PERMISSION_DENIED",
  "data": null,
  "fieldErrors": [],
  "retryAfterSeconds": null
}
```
