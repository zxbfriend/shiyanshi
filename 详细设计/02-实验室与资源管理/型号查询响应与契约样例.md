# M02 型号查询响应与契约样例

版本：DD-20260913-T8-R2。覆盖8类型号的list与detail，共16个HTTP接口。字段权威：[设备型号库设计第16节](设备型号库设计.md#16-完整响应同步和技术兼容定案)；输入约束见其第9—11节；权限/方法见[逐接口清单](逐接口完整契约清单.md)。本文补齐非空响应与错误样例，不新增型号操作，不扩大分析仪②分期。

## 1. 请求与响应边界

所有请求Header只需Authorization；GET无Body，无X-Management-Revision写前置，不递增管理版本。读请求requestId由服务端生成。成功/失败完整外壳沿[M01第17.1节及第6.1节](../01-系统管理/详细设计.md#171-公共参数响应和并发)。list返回顶层rows/total，不嵌入data；detail返回data。型号列表不擅加实例列表的timeField/pageNum/pageSize响应字段。

list通用Query：keyword可选字符串≤100，缺省空；beginDate/endDate可选YYYY-MM-DD，允许单边，有两边时beginDate≤endDate；pageNum默认1且≥1，pageSize默认10且仅10/20/50/100。时间按原生94取create_time或update_time任一满足同一完整区间，上海时区左闭右开；排序create_time DESC、真实主键DESC。各类字典筛选仍按拥有方第11节，本文样例只使用已明确的公共Query，不代表逐类额外筛选已穷尽验收。detail Path为该类型真实主键，正bigint十进制字符串，无Query。

CommonModelView的所有键均返回；可空值显式null，数组无项为[]。description/审计历史未知允许null，不能以当前姓名伪造历史审计。ID和managementRevision均字符串；Decimal字段字符串，数量整数、开关boolean/null。capacity和thresholdWeightG单位g，precisionValue单位g，maxFlow单位L/min，volumeMl单位mL；不把泵型号L/min当实例泵速g/min。capacityUnit、pressureUnit和字典标签随模型返回，不执行跨量纲换算。

allowedActions采用M01明确动作码且只返回当前权限子集，样例读者仅有list/query，所以为[VIEW]。configurationReady仅表示该型号配置满足其定义，不证明实例在线、未占用、驱动核准或具备执行准入；仍由实例/执行拥有方判断。检测样例未注册旧协议键和runtime-profile，保留null/[]与CONFIGURATION_INCOMPLETE，不能自动填单发、暂存或设备协议。

## 2. 独立模拟夹具

复用[八类保存Body](各类型保存样例.md)的2001—2008逻辑ID和值，但本文件为独立查询夹具：测试库直接装入已验证的型号主数据及字典标签；不声称执行过POST或SQL。管理版本固定13，审计历史未知取null，配置文件引用只在模拟文件域校验。ContainerSpec的volumeMl必须来自规格单位解析，不能截取数字；下文按其保存样例规格计算。除检测运行配置保留未知外，其余“配置完整”仅为本组模拟假设。

每类下面同时给出完整detail和非空list响应。相同型号在两者中的投影键和值必须一致；不能用空rows代替叶子核对。

## 11. 失败响应与逐接口断言

以下完整错误外壳共同适用16个查询入口，触发条件分别限定，不把不存在、无权和空集合混为一谈。错误语义见[错误码全集](错误码全集.md)。

任意list传pageSize=101（例如GET /device/benchreactor/list?pageSize=101），HTTP 400：

```json
{
  "code": 400,
  "msg": "分页大小仅允许10、20、50、100",
  "requestId": "00000000-0000-4000-8000-000000000002",
  "errorCode": "INPUT_INVALID",
  "data": null,
  "fieldErrors": [
    {
      "field": "pageSize",
      "message": "分页大小不合法"
    }
  ],
  "retryAfterSeconds": null
}
```

任意detail请求不存在/不可见对象（例如GET /device/benchreactor/999999），HTTP 404；不得回显对象或其引用：

```json
{
  "code": 404,
  "msg": "对象不存在或不可访问",
  "requestId": "00000000-0000-4000-8000-000000000002",
  "errorCode": "NOT_FOUND",
  "data": null,
  "fieldErrors": [],
  "retryAfterSeconds": null
}
```

当前身份缺少该类型对应list/query功能权限，HTTP 403：

```json
{
  "code": 403,
  "msg": "无权执行此操作",
  "requestId": "00000000-0000-4000-8000-000000000002",
  "errorCode": "PERMISSION_DENIED",
  "data": null,
  "fieldErrors": [],
  "retryAfterSeconds": null
}
```

| 适用接口 | 模拟输入或变化 | 必须断言 |
| --- | --- | --- |
| 8个list | 每类装入本节1个型号，不传筛选 | rows含完整同型投影、total=1、无data；不得返回其他型号的特有字段 |
| 8个detail | 对应真实主键 | data键集合严格为CommonModelView与对应类型字段并集；不返回凭据、delFlag、实例引用明细 |
| 8个list | 合法无匹配keyword | 成功原外壳、rows=[]、total=0，不返回NOT_FOUND |
| 8个list | 非法日期、倒置日期、pageNum=0、pageSize=101 | 400 INPUT_INVALID，配置及管理版本无变化 |
| 8个detail | 不存在或不可见对象 | 同一404错误结构；无功能权限按403，不通过报错泄露引用 |
| 8个list/detail | 重复合法GET，期间无写 | 内容一致；无管理版本增长、无业务写回执或硬件命令 |
