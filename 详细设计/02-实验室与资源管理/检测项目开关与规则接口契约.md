# M02 检测项目开关与规则接口契约

版本：DD-20260913-T8-R4。展开[检测与资源配置第3、4节](检测与资源配置详细设计.md#3-实例检测项目开关)已有5个HTTP入口。M02管理项目开关/规则，M05负责结果与算法；本批不新增PH校准、检测执行或小试下游范围。

## 1. 公共约束

Header Authorization；GET无Body、不要求写Header；POST/PUT需X-Request-Id(UUID)、X-Management-Revision与application/json。ID/版本十进制字符串，Decimal字符串，规则中的整数也通过value十进制字符串表达。成功外壳沿M01第17.1节；data下管理版本与外壳相同。所有写在SYSTEM管理守卫及相关业务检查后，同事务修改配置、审计、版本及幂等回执；不发送设备命令、不更改历史检测结果。

## 2. GET /lab/detectorconfig/{detectorId}/available-items

Path detectorId必填，无Query；功能lab:labdetector:config或lab:detectorconfig:edit，加真实设备实验室可见范围。data全部字段：detectorId:ID、detectClass:string（现有效分类）、items数组、managementRevision:string。每项itemId:ID、itemCode:string≤50、shortName:string≤50、itemCnName:string≤100、unit:string/null≤20、description:string/null≤200、enabled:boolean。只返回同分类有效项目，itemId升序为本批稳定显示顺序；无项目返回[]。

无lab_detector_item_config行时同类有效项目enabled=true（原默认启用），不是字段缺省；物理enabled=0映射true、1映射false。下列独立模拟夹具的7001尚无差异配置行，读应为true：

```json
{
  "code": 200,
  "msg": "操作成功",
  "requestId": "00000000-0000-4000-8000-000000000004",
  "managementRevision": "13",
  "data": {
    "detectorId": "4005",
    "detectClass": "BGA",
    "items": [
      {
        "itemId": "7001",
        "itemCode": "SIM-ITEM-01",
        "shortName": "模拟检项",
        "itemCnName": "模拟检项",
        "unit": "g/L",
        "description": null,
        "enabled": true
      }
    ],
    "managementRevision": "13"
  }
}
```

## 3. POST /lab/detectorconfig/{detectorId}/batch-save

Path detectorId；Body恰为{items:[{itemId:ID,enabled:boolean}]}；items必填非空、去重且只能来自当前候选，数量不超过当前有效候选数。功能权限同第2节，另要求真实实验室操作等级1（管理等级2包含）。设备身份不在Body重复，不接受actor/detectClass/managementRevision覆盖。

items是显式差异集合，未提交项保留；不是全量替换关系表。关闭某项目之前必须在同一业务检查边界核实M05待检/检测中引用，依赖未知503，不当作无样品。全部关闭需显式提交当前各项目false，空数组400而非恢复默认启用。提交候选校验、差异upsert、审计及管理版本同事务，全成全败。删除旧单行配置也必须走相同检查，不能绕过“删除关系即默认启用”的语义。

模拟请求（已确认无活动样品，管理版本13）：

```json
{
  "items": [
    {
      "itemId": "7001",
      "enabled": false
    }
  ]
}
```

成功回显完整当前候选视图，不只回传本次变化项，HTTP 200：

```json
{
  "code": 200,
  "msg": "操作成功",
  "requestId": "00000000-0000-4000-8000-000000000004",
  "managementRevision": "14",
  "data": {
    "detectorId": "4005",
    "detectClass": "BGA",
    "items": [
      {
        "itemId": "7001",
        "itemCode": "SIM-ITEM-01",
        "shortName": "模拟检项",
        "itemCnName": "模拟检项",
        "unit": "g/L",
        "description": null,
        "enabled": false
      }

    "managementRevision": "14"
  }
}
```

## 4. GET /detect/detection-rule/labs

无Query/Body；lab:detectionRule:list。只返回本期中试下游labType=4且当前有权实验室，按labId升序；成功data=[{labId:ID,labName:string}]，空集合合法。未选择实验室只是页面空态，不调用未授权全库读取。

独立模拟夹具1004为labType=4且当前有权，HTTP 200：

```json
{
  "code": 200,
  "msg": "操作成功",
  "requestId": "00000000-0000-4000-8000-000000000004",
  "managementRevision": "13",
  "data": [
    {
      "labId": "1004",
      "labName": "模拟中试下游实验室"
    }
  ]
}
```

## 5. GET /detect/detection-rule/config/{labId}

lab:detectionRule:list＋当前实验室可见；Path labId必填，无Query。真实labType必须4，不能信前端页签。data={labId:ID,items:[{ruleItem,operator:string/null,value:decimal-string/null}],managementRevision:string}。items固定为下述六条且按表顺序；旧未配置项两值均null，不自造阈值。无记录读取仍不自动插入。

| ruleItem | operator白名单 | value写入边界 |
| --- | --- | --- |
| density-difference | >=、<=、<、>、=、!= | ≥0、最多2位小数，decimal(10,2) |
| photometer-time | <=、< | 正整数≤2147483647，min |
| photometer-rds | >=、<=、<、>、=、!= | 正整数≤2147483647 |
| photometer-blank-concentration | >=、<=、<、>、=、!= | ≥0、最多2位小数，decimal(10,2)，mg/mL |
| solovpe-rds | >=、<=、<、>、=、!= | 正整数≤2147483647 |
| solovpe-r2 | >=、<=、<、>、=、!= | 最多3位小数、decimal(10,3)可表示范围；不另加未经确认的0—1限制 |

## 6. PUT /detect/detection-rule/{labId}/{ruleItem}

功能lab:detectionRule:edit＋真实实验室操作等级1/2；两Path值必填，ruleItem必须表内。Body只允许{operator:string,value:decimal-string}，均必填且不允许null；不是清空接口。未改变的其他五项不在本次Body中，也不能用前端草稿覆盖。初次插入遵守有效labId唯一约束及SYSTEM守卫；不是以唯一键异常代替业务幂等。

每条规则的独立模拟请求如下，各自以初始管理版本13运行；禁止在真实串行请求中复用相同请求ID或旧版本。

## 7. 错误与契约断言

| 场景 | HTTP/错误码 | 不变量 |
| --- | --- | --- |
| items空/重复/其他检测分类，错误operator/value/精度，非labType=4 | 400 INPUT_INVALID | 整体无配置改变，不能静默忽略错误行 |
| 输入对象身份/只读状态/版本字段 | 400 READ_ONLY_FIELD | 身份和管理版本只取Path/可信上下文/Header |
| 无功能/操作资格；无读取范围或不存在 | 403 PERMISSION_DENIED；404 NOT_FOUND | 不泄露范围外设备/实验室名称 |
| 旧管理版本、同键异体 | 409 MANAGEMENT_CONFLICT/REQUEST_CONFLICT | 保留原回执，不能生成新键覆盖旧草稿 |
| 关闭项目仍有待检/检测中引用 | 409 RESOURCE_IN_USE | 所有其他项目的变更也回滚 |
| 使用/配置依赖不可用，锁争用 | 503 DEPENDENCY_UNAVAILABLE/MANAGEMENT_BUSY | 不当作空闲、默认启用或成功保存 |

HTTP 409完整失败示例：

```json
{
  "code": 409,
  "msg": "检测项目仍有活动样品，无法关闭",
  "requestId": "00000000-0000-4000-8000-000000000004",
  "errorCode": "RESOURCE_IN_USE",
  "data": null,
  "fieldErrors": [],
  "retryAfterSeconds": null
}
```

逐接口设计断言：无差异行读enabled=true；false落库1、true落库0；空items拒绝；后端重验分类/引用，重复键同体回执不重复写；六规则全部有读取占位，但PUT不能null清空；更改一条规则不改其他五条；查询无副作用。M05按精确规则版本取快照，结果算法和RDS/R²含义仍由M05拥有，不在本文件擅改名为RSD。

本批补齐5入口的技术契约/模拟样例与精确读取筛选；不代表其他资源通用CRUD、消耗/液瓶接口及内部服务已全量验收。
