# M02 检测项目主数据逐接口契约

版本DD-20260913-T8-R8。覆盖DevDetectorItemController当前8个入口；实例开关另见[检测项目开关与规则](检测项目开关与规则接口契约.md)。本文件补目标字段、权限、幂等、事务、错误及样例，不代表接口已经运行验收。

## 1. 字段命名和公共规则

当前创建/更新DTO的请求字段是detectClass、itemCode、itemName、englishName、shortName、unit、groupName、offlineStatName、description；响应实体字段是itemCnName、itemEnName。保留这一已上线命名映射，不能要求前端把响应字段原样回传。请求只允许这9项，PUT另加itemId；iconPath、sortOrder、delFlag、审计、managementRevision均不在本期可写白名单。先前主设计ItemInput用itemCnName/itemEnName表达业务含义，本节给出实际HTTP字段后，以本节为准。

detectClass必填字符串≤30且为有效smp_detect_class；itemCode必填≤50；itemName/englishName必填≤100；shortName必填≤50；unit可省略/null≤20；groupName可省略/null≤100；offlineStatName必填≤100且为有效smp_offline_stat_name；description可省略/null≤200。字符串trim后校验，空可选字符串归一null。有效唯一键detectClass+itemCode，修改排除自身；显示名允许重复。示例MOCK_STAT必须由测试环境建立有效字典夹具，不冒充真实业务字典。

2026-10-24用户确认：Vi-CELL统计分类补充 `VCD`（活细胞密度）、`AvgDiam`（平均细胞直径），细胞活率沿用 `Viability`；保留统计名有效字典必填校验，不按型号放宽。主数据维护的中文/英文名称分别为活细胞密度/Viable Cell Density、细胞活率/Cell Viability、平均细胞直径/Average Cell Diameter。编号继续为VCD/Viability/AvgDiam，名称不参与源项目猜测匹配；单位保留既有配置，统计分类不授权单位转换。既有安装经正式字典与检测项管理接口维护，携带各自模块读口版本并记录审计；不重跑空库初始化。新空库仍按开发基线约定由管理员维护受控资源字典和检测项，不加入QA设备或检测历史种子。修正主数据不回写历史任务的冻结名称、测量值或签批快照。

ItemView固定itemId、detectClass、itemCode、itemCnName、itemEnName、shortName、unit、groupName、offlineStatName、description、createBy/createTime/updateBy/updateTime、managementRevision，不返回iconPath/sortOrder/delFlag/remark。ID和版本用十进制字符串，时间ISO8601/null。

写请求使用X-Request-Id与X-Management-Revision；相同请求ID同体且仍有权重放首次回执，同键异体409 REQUEST_CONFLICT，新键旧版本409 MANAGEMENT_CONFLICT。SYSTEM事务内完成校验、数据、关联清理、审计、版本和回执；失败不部分写。源码当前toAjax无ID/版本，属于待实施差异。

## 4. GET /device/detectoritem/check-unique

权限device:detectoritem:query；Query detectClass、itemCode必填，itemId修改时可选用于排除自身，Body空。可用返回data=true：
```json
{
  "code": 200,
  "msg": "操作成功",
  "requestId": "00000000-0000-4000-8000-000000000008",
  "managementRevision": "41",
  "data": true
}
```

当前Service在重复时返回false，Controller仍包装HTTP 200；当前页面validateUnique只按then/catch判断，未读取data，会把200+false当可用。目标统一为重复HTTP 409 CODE_CONFLICT，前端既有catch可阻止提交：
```json
{
  "code": 409,
  "msg": "该检测分类下的检测项编号已存在",
  "requestId": "00000000-0000-4000-8000-000000000008",
  "errorCode": "CODE_CONFLICT",
  "data": null,
  "fieldErrors": [],
  "retryAfterSeconds": null
}
```

提交仍须事务内重查唯一并由目标有效唯一约束兜底。预检查不锁定结果，不能代替POST/PUT冲突处理。异步响应只适用于发起时相同字段和itemId。

## 5. GET /device/detectoritem/{itemId}/check-delete

权限device:detectoritem:query。只读预检，重算同detectClass全部有效检测设备：无配置行视为启用，enabled=0视为启用。目标返回canDelete、referenceCount、managementRevision；不锁定删除结果。HTTP 200可删样例：
```json
{
  "code": 200,
  "msg": "操作成功",
  "requestId": "00000000-0000-4000-8000-000000000008",
  "managementRevision": "41",
  "data": {
    "itemId": "7501",
    "canDelete": true,
    "referenceCount": 0,
    "managementRevision": "41"
  }
}
```

有启用关系仍返回200及canDelete=false/referenceCount，不用异常隐藏计数；范围外敏感明细不返回。当前Service命中引用直接抛异常且成功无data，需适配。依赖无法可靠计数503 RESOURCE_FACTS_UNAVAILABLE，不能返回0。

## 7. PUT /device/detectoritem

权限device:detectoritem:edit。Body为POST完整业务表单＋itemId；PUT不是PATCH，必填字段均出现。示例：
```json
{
  "itemId": "7501",
  "detectClass": "BGA",
  "itemCode": "MOCK-PH",
  "itemName": "模拟酸碱度",
  "englishName": "Mock pH",
  "shortName": "pH",
  "unit": null,
  "groupName": null,
  "offlineStatName": "MOCK_STAT",
  "description": "模拟数据，仅用于契约测试"
}
```

展示描述修改可直接保存；detectClass、itemCode、unit、offlineStatName等解析字段改变时，必须在事务保护区内检查M05待检/检测中引用，存在则409 RESOURCE_IN_USE。detectClass变更还重检旧类和新类设备、清理旧类当前配置，历史结果保留原快照。当前Service在类型变化时直接删除旧类配置，只检查字典/唯一，未见M05活动样品检查；属于明确实现缺口。成功：
```json
{
  "code": 200,
  "msg": "操作成功",
  "requestId": "00000000-0000-4000-8000-000000000008",
  "managementRevision": "42",
  "data": {
    "itemId": "7501",
    "managementRevision": "42"
  }
}
```

## 8. DELETE /device/detectoritem/{itemIds}

权限device:detectoritem:remove。Path为1—100个逗号分隔唯一ID，Body/Query空，WriteMeta必填。事务内重算默认启用和显式启用关系，并检查M05活动引用；任一被使用409 REFERENCE_EXISTS/RESOURCE_IN_USE，整批不删。任一不存在404，不跳过。成功软删，历史引用及快照不改，返回removedIds按请求顺序及新版本：
```json
{
  "code": 200,
  "msg": "操作成功",
  "requestId": "00000000-0000-4000-8000-000000000008",
  "managementRevision": "42",
  "data": {
    "removedIds": [
      "7501"
    ],
    "managementRevision": "42"
  }
}
```

当前Service逐项检查并在同事务软删，具备部分全成全败基础；仍缺管理版本、幂等、M05活动引用及目标回执。

## 9. POST /device/detectoritem/export

权限device:detectoritem:export。Query同list但无分页，Body空；读取型POST，无WriteMeta/管理版本递增。ExcelUtil直接XLSX，MIME沿公共实现；目标列按ItemView业务字段顺序，排除管理版本和审计：itemId、detectClass、itemCode、itemCnName、itemEnName、shortName、unit、groupName、offlineStatName、description。空值留空，文本防公式注入。该入口未列入R4的25项，独立登记，不修改旧计数。生成前失败JSON，流中断判下载失败。

## 10. 错误、事务和源码差异

读取：400 INPUT_INVALID、403 PERMISSION_DENIED、404 NOT_FOUND、503 DEPENDENCY_UNAVAILABLE/RESOURCE_FACTS_UNAVAILABLE。写：另有400 READ_ONLY_FIELD，409 CODE_CONFLICT/REQUEST_CONFLICT/MANAGEMENT_CONFLICT/REFERENCE_EXISTS/RESOURCE_IN_USE，503 MANAGEMENT_BUSY。认证沿M01。完整资源占用失败：

```json
{
  "code": 409,
  "msg": "检测项目仍被待检或检测中的样品引用",
  "requestId": "00000000-0000-4000-8000-000000000008",
  "errorCode": "RESOURCE_IN_USE",
  "data": null,
  "fieldErrors": [],
  "retryAfterSeconds": null
}
```
