# M02 设备实例详细设计

## CB-20261024：独立台式控制器与罐体绑定（最新确认）

台式控制器为独立实验室实例，主键沿用 `lab_bench_reactor_controller.connection_id`，对外命名 `controllerId`。允许控制器尚未绑定罐体；一个控制器可绑定多个罐体，一个罐体最多绑定一个控制器。规范关联改为 `lab_bench_reactor.controller_id → lab_bench_reactor_controller.connection_id`，可空且索引不唯一，不新增表。关联必须同实验室、目标有效；变更仍须实验室操作权限、SYSTEM管理守卫、真实设备使用/引用检查及审计，不以型号、编号或名称猜测关系。

控制器 `reactor_id` 仅保留迁移兼容事实，允许NULL，停止新增业务依赖或双写；旧字段不得限制新控制器的独立生命周期或一控多罐关系。反应器旧 `controller_no` 亦为兼容列，真实编号只读自控制器 `controller_no`。型号采用统一 `dev_reactor_model` 的有效 `BENCH_CONTROLLER`，型号无实验室归属；`model_name` 为型号名称，`spec` 为规格，均不代替实例编号或资产号。小试上游按 `lab_lab.lab_type='1'` 与授权实验室集合过滤实例 `lab_id`，不按型号归属筛选。

默认连接新主接口为 `GET /lab/pumpconnection/controller/{controllerId}`、`PUT /lab/pumpconnection/controller/{controllerId}`。沿原查询/编辑功能权限和实验室准入，PUT沿Header/WriteMeta双头，读响应顶层返回SYSTEM `managementRevision`；`controllerId` 解析为 `connection_id`，响应同时保留 `connectionId`。`controllerNo` 取该控制器真实编号，通道按稳定 `channelId` 读写，不要求先绑定罐体。响应 `reactorId` 为旧兼容字段，可空且不得解释为完整罐体集合。

旧 `GET/PUT /lab/pumpconnection/reactor/{reactorId}` 保留兼容：由该罐体的 `controller_id` 解析控制器并复用同一配置链，禁止按控制器旧 `reactor_id`、编号或“最后一条”解析；未绑定返回配置未就绪，不创建控制器或自动绑定。旧调用不能通过控制器配置修改罐体绑定。一个控制器的默认连接及通道由多个罐体共用，配置前必须检查该控制器及全部已绑定罐体的使用状态，任一阻断或事实未知即整次拒绝，不以当前入口罐体空闲代替全量检查。

空库仍只执行开发基线01/02/03；既有库单独使用 [RM-04升级来源](RM-04-现有开发库控制器罐体绑定升级.sql)，明确确认目标、停写和备份后执行。仅依据唯一、同实验室且无冲突的旧 `reactor_id` 回填；已有不同绑定、失效目标或多连接歧义拒绝，不猜测、不覆盖。脚本支持修正冲突后重跑；MySQL DDL隐式提交，不能承诺整个DDL与回填原子回滚。没有执行SQL或运行验收的证据时仅标静态设计同步，不能宣称数据库/HTTP/浏览器通过。

2026-09-09。目标设计；当前代码差异单列，不表示接口已经实现。覆盖12类实例及台式控制器默认连接、打印排版。依据[实验室设置（V4.0 第 2 章）](../../需求说明书V5.1-1030_md/02-实验室设置.md)、[主设计及确认记录](详细设计.md)、[集成反应器参数契约](集成反应器型号与实例参数契约.md)。物理字段见[数据库字典](数据库表结构与字段字典.md)。

## 1. 页面及共同交互

沿用实验室设置下设备配置/其他设备入口与既有页签。首屏为筛选和结果，不增加统计卡、介绍区。筛选包括实验室、按类型适用的场地/型号/类型、关键词和日期；未选实验室表示所有有权实验室，绝不查询全库后在浏览器过滤。台式默认连接必须选择实验室，部署默认实验室仅在有权集合中才自动选中，否则留空。

设备实例列表按修改时间降序、主键降序；下游设备按需求采用创建时间降序、主键降序。起止日期用 timeField=createTime/updateTime 显式选择，默认updateTime，单端可填，上海时区起日含、结束日次日不含；列表与总数相同过滤。不解析展示字符串排序。无时间历史值显示“未知”，有日期条件时不匹配。

点击新增先加载当前实验室、型号和引用候选；修改读取详情及managementRevision。切换实验室/型号时清除不再合法的候选草稿并说明原因，不能悄悄把旧泵/秤绑定到另一实验室。提交失败保留非敏感输入，版本冲突需重新核对；取消关闭且不写入。删除/解除维护/下游禁用按原需求二次确认。前置检查仅用于提示，提交时仍校验。

## 2. 权限、状态和原子写入

实例读须相应功能list/query权限及实验室可见等级0；新增、编辑、维护、删除沿用当前实例功能权限与实验室可操作等级1，管理等级2包含操作等级。不得把型号库全局维护权限转换成实例权限。液瓶单独按管理等级2，详见资源配置设计。负责人仅表示设备责任人，不自动授予实验室权限。

编辑先按数据库原labId鉴权，转移实验室还须目标labId操作权限。任何引用必须存在、未删除、属于目标实验室、符合用途；场地引用必须在允许候选中。禁止客户端提供ownerName、品牌快照、审计、delFlag、运行状态绕过服务端取值。数据库ID和设备编号不同，不能用编号代替外键。

maintenance表示设备维护（对应既有status），occupancy表示M03预约/占用，connectivity表示M07通讯状态，三个维度分别返回。维护解除不自动释放占用，也不证明在线。M02没有手工将“使用中”改为空闲的接口。当前status=0/1的物理列按各表原语义适配，不将其直接命名为使用中。

保存流程：SYSTEM守卫 → 管理版本比较 → 原/目标实验室鉴权 → 唯一与引用复查 → M03/M05/M07使用状态复查 → 按白名单写主从表 → 操作审计、回执及版本 → 提交。所有批量删除先验证全部ID，任一失败整体回滚。管理版本只随配置写入变化，设备采集数据不反复推动全局管理版本。

涉及正在预约/使用设备的型号、实验室、控制连接、容量、泵速/系数、通讯身份变更，须先走业务释放流程；不能用修改资料绕过已有占用约束。仅不改变运行参数的备注/显示资料可独立提交。是否有活动使用由对应业务模块按设备关系计算，不能仅判断本设备status或实验室是否有任意项目。依赖不可用返回503 DEPENDENCY_UNAVAILABLE，不能当作空闲。

## 3. 字段约定与请求结构

ID为string（正整数十进制、最长19位），输入名称去首尾空白；未明确长度的编号50、名称100、备注100。小数以decimal-string传输，服务端BigDecimal，不四舍五入接受超精度输入；整数限对应数据库范围。可空字段以null清空，未提交字段不修改；必填字段不得null。status/布尔枚举使用明确适配，不把字符串“0”按JavaScript真假值处理。

通用WriteMeta为请求头组合：X-Request-Id=UUID、X-Management-Revision=非负十进制整数字符串；下文“＋WriteMeta”仅表示必须携带这两个请求头，不是Body/Query字段；请求携带表4所列可写字段和WriteMeta，修改还包含对应ID（有路径ID时不重复，旧接口重复时须一致）。新增ID、审计和删除标志服务端生成。相应ID名沿用现有接口，不强制改名为id。

WriteResult={id:string,managementRevision:string,requestId:string}；Detail由该类型可写字段＋第7节真实主键K＋只读型号字段＋Audit＋State组成（字段集合平铺，不新增通用id别名）。Audit={createBy:string/null,createTime:ISO8601/null,updateBy:string/null,updateTime:ISO8601/null}；State={maintenance:boolean/null,enabled:boolean/null,occupancy:IDLE/RESERVED/IN_USE/UNKNOWN,connectivity:ONLINE/OFFLINE/UNKNOWN,configurationReady:boolean,configurationIssues:string[]}。不适用字段返回null。占用/连接UNKNOWN必须显示未知，不能映射空闲。

列表返回rows、total、pageNum、pageSize；每行含详情中的标识、只读型号信息和对应需求展示字段，不返回通讯凭据；大聚合泵数组仅详情返回。页码从1起，pageSize默认10、上限100。详情404统一处理不存在及不可见对象；禁止泄露其他实验室引用名称。

## 5. 台式控制器及默认泵连接

复用lab_bench_reactor_controller和lab_bench_reactor_controller_channel，channel_id保持通道身份；独立控制器与罐体关系按《默认连接与打印排版接口契约》CB-20261024。PC-20261026用户确认新选择来自对应实验室天平：balance_kind=BALANCE、balance_id引用lab_balance.balance_id；旧明确FLOOR_SCALE引用允许原样保留。查询按类型、ID及实验室关联设备编号，不以两表ID恰好相同或空类型猜测身份。新选择核验同实验室启用未删除天平，不自动转换旧引用。

详情返回connectionId、labId、reactorId、controllerNo（只读）、balanceId、balanceKind（BALANCE或旧FLOOR_SCALE；未知为null）、remark、channels[]、managementRevision；Channel={channelId:string,channelNo:string只读,pumpType:string/null,pumpId:string/null,defaultSpeed:integer,maxSpeed:integer,materialName:string/null,feedContainer:string/null,speedStrategy:string/null}。defaultSpeed/maxSpeed为1–99999999正整数且defaultSpeed≤maxSpeed；泵型号和实际协议单位由能力契约带出，禁止统一假设RPM。液体和容器按各自字典值存储；策略允许不选或清空为null，非空按M04合法引用，不新增本期策略算法。

保存以连接为聚合，同一次校验并更新所有提交通道。禁止通过重排重新编号、删除遗漏通道或跨控制器复用channelId。初始化的通道数量/标识由设备部署配置确定；当前前端不开放更改物理布局。引用泵按pumpType白名单解析对应实例表并检查同labId、可用；默认配置不等于M03业务预约，不私自抢占设备。运行中的连接变更先结束/释放相应业务，不通过独立channel CRUD绕过聚合检查。

## 6. 删除和引用矩阵

| 对象 | 需检查的阻断条件 | 处理 |
| --- | --- | --- |
| 台式反应器 | 预约/正在使用；当前控制器连接及未解除液瓶布局引用 | 返回409 RESOURCE_IN_USE或REFERENCE_EXISTS，先按原入口解除配置 |
| 天平 | 已核明BALANCE种类的控制器引用；活动业务使用 | 先解除控制器连接 |
| 蠕动泵、空气泵 | 台式通道引用；集成反应器外置泵/空气泵引用；活动执行 | 先解除当前连接，不能自动断泵 |
| 检测设备 | M05待检测/检测中样品或未完成设备指令 | 历史完成结果不阻断软删除，保留历史显示 |
| 集成反应器 | M03未释放预约/占用，已取消本身不阻断，但真实残留占用须先释放；固定连接关系需合法处理 | 不将“已取消”直接判成已释放；删除不关闭实体设备 |
| 培养容器 | 未开始或已开始未结束培养、其他当前配置引用 | 已完成且已释放的历史引用可保留 |
| 地秤 | 集成反应器floor_scale_id/feed_scale_id及台式控制器FLOOR_SCALE当前引用 | 不因反应器空闲就允许删被绑定的地秤 |
| 下游设备 | 活动采集/检测/指令及当前业务引用 | 软删除并停止新的候选使用，不清除历史 |
| 声光报警器 | 当前设备和有效告警通道绑定 | 由对应入口先解除引用 |
| 打印机 | M05、M07及其他实际使用方的排队/发送/回执未知打印任务；当前业务引用 | 无法确认任务状态或来源覆盖时拒绝，不用“没有回执”判断空闲 |
| 继电器 | 当前设备连接及活动/未知命令 | 先释放引用，删除不自动开关继电器 |

附属固定泵、通道、排版采用原聚合的一致性处理；删除前审计记录必要配置快照，M03/M07运行快照及M08历史不能级联删除。具有remove功能权限仍须满足所有阻断条件，超级管理员也不豁免。

## 11. 小试控制器能力补齐

按资源管理明确条款，将mfcCount、thresholdWeightG、temperatureControl、weightControl、pressureControl五字段补入lab_bench_reactor_controller，不放入dev_bench_reactor。历史空值表示未知，不能自动填1或true。新部署从设备资料初始化，MFC正整数、达阈重量正整数g、三个开关boolean；物理通道来自控制器初始化，泵数量取有效初始化通道，不套用集成型号pump_count。

新增GET /lab/pumpconnection/{connectionId}/capabilities（query）与PUT同路径（edit），读取/提交五字段及WriteMeta；沿用实例实验室操作准入，仅空闲且没有当前模板/运行配置依赖时允许改变结构；有依赖先走配置调整流程，不直接删除它们。旧默认连接保存不带这些字段时保持原值。返回{connectionId,mfcCount,thresholdWeightG,temperatureControl,weightControl,pressureControl,managementRevision,configurationReady,configurationIssues}。

台式反应器与控制器的规范关联使用lab_bench_reactor.controller_id指向控制器connection_id，允许控制器独立存在且一控多罐；旧controller.reactor_id仅作迁移兼容，停止新增依赖。控制器编号是独立控制器表的只读事实，台式反应器新增/修改不录入也不改写；lab_bench_reactor.controller_no仅为历史兼容列。历史歧义关系不按“最后一条”静默选中。bottle_config.reactor_id保持反应器身份，不迁移为connection_id。2026-11-02 用户确认新建取样槽采用 bottle_config.controller_id 直接关联控制器；旧取样槽和补料槽维持旧路径，详见[液瓶接口与观测边界](液瓶配置逐接口与观测边界.md)。

培养状态删除口径以澄清记录最后D类已确认项为准：未开始/进行中/已逾期阻断；草稿/已取消/已结束/已过期本身不阻断。M03仍校验真实预约/占用释放，其他设备连接引用另查。旧“已开始或已取消”不作为独立阻断枚举。打印机删除技术已在历史澄清标为已处理，本设计复用其实际任务检查，不重复提出业务确认。
