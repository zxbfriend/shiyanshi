# M02 控制器能力接口契约

版本：DD-20260913-T8-R2。展开[设备实例第11节](设备实例详细设计.md#11-小试控制器能力补齐)已有GET/PUT，不新增业务操作。字段落点为[收尾后完整数据库字段字典](收尾后完整数据库字段字典.md#lab_bench_reactor_controller)中的lab_bench_reactor_controller；能力在控制器实例，不放到台式型号表。

## 1. 逐字段定义

| 字段 | 请求 | 响应 | 物理映射/约束 |
| --- | --- | --- | --- |
| connectionId | Path必填，正bigint十进制字符串；Body禁止重复身份 | 必填string | connection_id；由服务端解析真实reactor/lab |
| mfcCount | PUT五字段之一；有值时JSON整数，1—2147483647；按实例原契约省略不修改，显式null拒绝 | integer/null，旧未知null | mfc_count；物理int unsigned不等于设备能力上限；API用正int范围作为本批技术定案 |
| thresholdWeightG | 有值时正整数十进制字符串，1—999999999；省略不修改、null拒绝 | decimal-string/null，旧未知null；单位g | threshold_weight_g decimal(12,3)，API不接受非整数重量，读取保留精确十进制值 |
| temperatureControl | 有值boolean，省略不修改，null拒绝 | boolean/null | temperature_control，0→false、1→true、NULL→null |
| weightControl | 同上 | boolean/null | weight_control；不把JavaScript字符串0按真值处理 |
| pressureControl | 同上 | boolean/null | pressure_control；历史未知不默认true |
| managementRevision | PUT从X-Management-Revision取得，Body禁止 | 必填非负十进制string | 读取SYSTEM管理版本，成功写返回提交后的新版本 |
| configurationReady | 禁止客户端写 | 必填boolean | 服务端核验结果，不等于实机执行准入 |
| configurationIssues | 禁止客户端写 | string[]，完整时[] | 既有错误/配置原因，未知缺项沿CONFIGURATION_INCOMPLETE；不虚构默认能力 |

PUT至少显式提交一项可写能力；其他四项省略保留原值。整组读改写后的结果仍按现有配置规则验证；只读字段、空Body、超范围、非boolean或字段拼写错误整次拒绝。省略与null不同，沿实例第3节既有部分修改规则，不将省略项自动填false/1。若旧值未知，读取仍保留null；补齐和启用受原第11节依赖门槛约束。

## 2. GET /lab/pumpconnection/{connectionId}/capabilities

Authorization必填，无Query/Body，无写Header。功能权限lab:pumpconnection:query并叠加原实例实验室可见范围；功能码沿当前控制器已有query动作，本路径为目标设计，不声称已实现。只读、不写回执、不递增版本、不查询后自动初始化能力。成功外壳沿M01第17.1节，data为第1节全部响应字段。

模拟GET /lab/pumpconnection/5001/capabilities，旧五项能力尚未核准，HTTP 200：

```json
{
  "code": 200,
  "msg": "操作成功",
  "requestId": "00000000-0000-4000-8000-000000000002",
  "managementRevision": "13",
  "data": {
    "connectionId": "5001",
    "mfcCount": null,
    "thresholdWeightG": null,
    "temperatureControl": null,
    "weightControl": null,
    "pressureControl": null,
    "managementRevision": "13",
    "configurationReady": false,
    "configurationIssues": [
      "CONFIGURATION_INCOMPLETE"
    ]
  }
}
```

不存在或无读取范围返回404 NOT_FOUND；缺功能403 PERMISSION_DENIED。旧值未知通过null表达，不以依赖故障伪造0/false；无法读取可靠配置返回503 DEPENDENCY_UNAVAILABLE。

## 3. PUT /lab/pumpconnection/{connectionId}/capabilities

Authorization、Content-Type:application/json、X-Request-Id(UUID)、X-Management-Revision必填。功能权限lab:pumpconnection:edit，原实验室操作等级1或管理等级2；不接受浏览器自报labId/actor。现有型号维护权不能代替实例权限。

SYSTEM守卫→比较管理版本→从connectionId重读当前实验室及权限→检查真实空闲、当前模板/运行配置引用→白名单能力写入、审计、版本与幂等回执→提交。仅空闲且没有当前模板/运行配置依赖才允许能力结构变更；不能自动删除配置解除依赖。设备网络调用不在事务内，也不由该保存触发。相同操作者/请求ID及载荷回放原结果；同键异载荷REQUEST_CONFLICT；失败全部回滚。写期间锁竞争MANAGEMENT_BUSY，依赖不能核实时DEPENDENCY_UNAVAILABLE，不降级放行。

独立模拟夹具：5001属于当前可操作实验室，无模板/运行依赖、无活动/未知使用；测试已核准以下能力，真实环境须有真实证据。请求PUT /lab/pumpconnection/5001/capabilities，X-Management-Revision:13、X-Request-Id:00000000-0000-4000-8000-000000000002。

```json
{
  "mfcCount": 2,
  "thresholdWeightG": "10",
  "temperatureControl": true,
  "weightControl": false,
  "pressureControl": true
}
```

成功HTTP 200，data仍是能力视图，不将其误写成仅{id,requestId}的普通实例WriteResult：

```json
{
  "code": 200,
  "msg": "操作成功",
  "requestId": "00000000-0000-4000-8000-000000000002",
  "managementRevision": "14",
  "data": {
    "connectionId": "5001",
    "mfcCount": 2,
    "thresholdWeightG": "10",
    "temperatureControl": true,
    "weightControl": false,
    "pressureControl": true,
    "managementRevision": "14",
    "configurationReady": true,
    "configurationIssues": []
  }
}
```

旧X-Management-Revision冲突，HTTP 409：

```json
{
  "code": 409,
  "msg": "配置已变更，请重新核对后保存",
  "requestId": "00000000-0000-4000-8000-000000000002",
  "errorCode": "MANAGEMENT_CONFLICT",
  "data": null,
  "fieldErrors": [],
  "retryAfterSeconds": null
}
```

当前存在模板/配置引用，HTTP 409 REFERENCE_EXISTS；活动或未知使用为409 RESOURCE_IN_USE；两者均不写入、不隐式停设备。其他已登记错误：400 INPUT_INVALID/READ_ONLY_FIELD；404 NOT_FOUND；403 PERMISSION_DENIED；409 REQUEST_CONFLICT；503 DEPENDENCY_UNAVAILABLE/MANAGEMENT_BUSY。

## 4. 契约断言与状态

1. GET历史NULL原样返回；false与null不同，不返回虚构默认能力。
2. PUT省略四字段时保留原值；发送null或客户端configurationReady拒绝且管理版本不变。
3. 同键同体只写一次、同键异体409；旧版本不覆盖，审计及回执失败整次回滚。
4. 预先空闲、提交前出现模板引用或运行占用时正式写拒绝；超级管理员同样受限。
5. 数量非整数、0、2147483648及重量非整数/超过999999999均400；API数值上限仅为存储/序列化限制，不证明设备支持相应数量。
6. 成功后GET应回显相同能力及版本；未变的通道、称重连接、型号字典身份保持原值。

本批完成两项已有目标接口的设计展开；权限字符串仅对照现控制器query/edit注解，未证明capabilities控制器已实现。未运行SQL、HTTP、契约测试或设备操作。
