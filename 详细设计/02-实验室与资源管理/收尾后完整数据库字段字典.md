## M05 B1 通讯核验增补（2026-10-10）

`lab_communication` 新增 `verification_revision BIGINT UNSIGNED NULL`、`verification_status VARCHAR(16) NULL`、`verification_reason VARCHAR(64) NULL`、`verification_checked_at DATETIME(3) NULL`。四列共同为空代表从未核验；有值时版本必须大于0且不大于 desired_revision，状态只允许 ONLINE/OFFLINE/UNKNOWN，时间为 UTC，原因只允许服务端固定脱敏编码。版本不等于当前 desired_revision 时读取为 UNVERIFIED。不改变 apply_state、型号 configurationReady、队列或位置；CAS 只允许回写探活所用版本。同步目标 DDL 和空库基线，不执行历史 SQL。
## 通讯使用关联登记（2026-10-13 联合后端接线）

`lab_communication_usage` 由 M02 保存受控适配器登记，M05/M07 通过自有只读 Port 核验实际业务。没有登记不能推导空闲，登记不替代删除时实时核验。

| device_id | BIGINT | 是 | 正数设备实例 ID |
| lab_id | BIGINT | 是 | 服务端核验的实验室 ID |
