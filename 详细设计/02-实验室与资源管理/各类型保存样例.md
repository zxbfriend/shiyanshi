# M02 各类型保存样例

版本：DD-20260913-R2。依据[实例第3/4/7节](设备实例详细设计.md)、[型号第3/10/11/16节](设备型号库设计.md)。覆盖12类实例与8类型号的完整新增Body，修改复用同一白名单并按逐接口清单加入主键；集成实例主键放Path，其他类型放Body。实际可清空和可省略行为以各字段定义为准。

## 模拟前置数据与公共断言

这些是独立模拟数据库夹具，不能写入现场环境作为默认能力。实验室1001、用户101已存在且有操作权限；SIM_BRAND、SIM_BENCH、SIM_SCALE、SIM_DETECT、SIM_ANALYZER及mL/kPa/HTTP/WAVE必须先在相应现有字典注册为模拟有效值。分析仪图片路径代表文件服务返回且已校验的模拟文件，不能只凭此字符串跳过上传校验。2001—2008为本文件八类型号分别保存后的模拟ID；3001/3002为同实验室不同称重实例，角色分别非补料/补料且无活动引用。集成型号已核准模拟pumpCount=2，两个固定泵必须完整提交。上述值仅用于软件契约测试，真实型号/通讯/控制能力未因样例而核准。

每次独立用例从managementRevision=12开始，携带X-Management-Revision:12和X-Request-Id:00000000-0000-4000-8000-000000000001；串行执行则读取前一回执的新版本并更换requestId。不得将同一个示例UUID跨接口复用为生产请求。标准管理外壳按M01，以下返回的是data业务体。

所有保存用例均断言：未提供只读派生/审计字段；写入、审计、版本和回执同事务提交；同请求同体重放相同结果；同请求异体409；过期版本409；字典无效/非白名单/超精度400；无操作权403；依赖使用状态不可得503且无写入。创建成功不意味着设备configurationReady=true。

```json
}
```

## 类型专项反例

| 类型 | 修改上述Body的单个条件 | 预期 |
| --- | --- | --- |
| 台式 | maxCapacity小数或伪造capacityUnit | 400，不接受只读单位或静默换算 |
| 天平 | modelId指向泵型号 | 400引用类型错误 |
| 蠕动泵/空气泵 | speedFactor=0或10.0001 | 400，无配置变化 |
| 检测实例 | detectClass与型号不匹配 | 400，不猜测驱动 |
| 集成实例 | floorScaleId=feedScaleId或pumpNo重复/缺失 | 400，原聚合不变 |
| 容器 | specId所属类型与containerType不一致 | 400 |
| 地秤 | 已被非补料角色绑定时改isFeedScale=true | 409，不改角色 |
| 下游 | communicationType不属于型号允许集合 | 400 |
| 声光/继电器 | Body附relayStatus或报警执行参数 | 400，不下发设备命令 |
| 打印 | printLimit=0 | 400，不解释为不限 |
| 集成型号 | 有配置引用时修改pumpCount | 409，Q25阻断 |
| 检测型号 | singleSendLimit=100或0 | 400；workSendLimit=0独立表示不限 |
| 两类泵型号 | maxFlow=0或5位小数 | 400；流量L/min不自动当现场泵速g/min |
| 分析仪型号 | imagePaths为空或未验证外部URL | 400 |

本附件覆盖保存Body与回执，列表/详情/候选/导出/内部服务的完整样例仍须按各接口单独核查，不能用保存样例替代全接口验收。
