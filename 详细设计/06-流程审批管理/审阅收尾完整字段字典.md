撤回持久键 `uk_apr_rec_withdraw(withdraw_key)` 跨状态唯一；`ck_apr_rec_withdraw` 要求 WITHDRAWN 时四个撤回字段同时非空且证据为 schemaVersion=1 的 JSON 对象，其余状态全部为空。JSON schema 检查显式将缺路径的 SQL NULL 转为不通过。证据由服务端生成，完整 V1 字段及重放规则见[审阅收尾对账与启用契约](审阅收尾对账与启用契约.md)；申请证据、复核证据与撤回证据不可互相代用。

CHECK仅覆盖静态行形状；状态迁移、跨行权限、不可变性、JSON语义和外部事实由领域守卫执行。不因为CHECK通过宣称物理安全或历史真实性。新增关联均为逻辑关联，未加数据库外键。
