# 初始重量增量回退

SQL 19/20/21 均为设计交付，未运行。先备份并在隔离测试库演练，MySQL DDL不能依靠ROLLBACK撤销。

默认回退方式：关闭新写入口，保留新增列和全部候选/历史，回滚应用但不让旧版写入破坏新字段。存在已生效值、候选、审批交付或计算引用时禁止删列；未知来源也禁止删列。旧版本不能理解新候选schema2时只读隔离，不回写hash。

只有证明从未启用、四列均保持未知初值、无新候选/交付/计算引用且备份恢复演练完成，才能另行审批结构回退。本包不提供可误执行的DROP脚本。迁移后失败先关闭相关重量写入/依赖执行，不清理已经认可的业务事实；其他CRUD不受影响。
