# M03 数据库表结构与字段字典

## res_project_detection_rule（2026-10-23 项目检测规则覆盖）

定义源[PD-01](PD-01-项目检测规则表结构.sql)，纳入开发基线完整建表；不向基础数据初始化添加项目数据。唯一写拥有方M03。项目/lab/用户均逻辑引用，不新增物理外键。

| 字段 | 类型与语义 |
| --- | --- |
| project_id | bigint NOT NULL；复合主键第1列，关联有效res_project |
| lab_id | bigint NOT NULL；复合主键第2列，必须是项目参与的中试下游实验室 |
| items_json | JSON NOT NULL；数组精确六项，ruleItem唯一且编码/运算符/数值沿M02既有策略；ID不混入JSON，value为decimal-string/null |
| updated_project_version | bigint NOT NULL >0；本行最近保存后项目object_version，配置写共享项目聚合版本，不是独立CAS版本 |
| creator_user_id / modifier_user_id | bigint NOT NULL >0；可信会话创建/修改人ID |
| create_by / update_by | varchar(64) NOT NULL；可信会话账号名 |
| create_time / update_time | datetime(3) NOT NULL；服务端UTC审计时间 |

主键(project_id,lab_id)，lab_id普通索引。创建项目规则前像无配置不造默认行；读取时可回落真实实验室默认。配置不因批次软删消失，不回写实验室规则，不重算历史结果。现行接口及JSON语义见[项目级检测规则配置契约](项目级检测规则配置契约.md)。

2026-09-09，目标设计稿，未执行SQL。结构包含11张复用表、2张新增事实表；完整建表语句见[08目标结构](history/sql/08-项目培养目标表结构.sql)，迁移流程见[主设计第6节](详细设计.md#6-迁移与兼容安排)。本文件列出全部物理字段，包括旧兼容列，无省略列。

来源基线：`sql/ymsw.sql`，SHA256=B3F185BD23B399CAC0E1B12593F9F68D0E42CDE7C457EDD3B2F472A7286F4366。图谱结构仅用于定位，SQL及Mapper XML已直接核对；文件快照不等于现场数据库结构。

共同属性：InnoDB、utf8mb4、utf8mb4_0900_ai_ci；技术状态字段使用ascii_bin区分固定枚举，全部为逻辑关联，无外键。ID以正bigint存储、对外十进制字符串；版本为非负bigint，实体object_version从1起。新日期限制为MySQL DATE可表示的1000-01-01至9999-12-31，运算越界拒绝。所有新固定枚举均由代码维护，不能通过字典后台新增值或停用其中一态。

目标表保留原默认值供结构兼容；这不等于新API可省略必填事实。新实体显式填写facts_status=READY及相关目标字段，迁移增列的REVIEW/LEGACY/UNKNOWN仅用于阻止未经核准的数据被当成可操作事实。未知状态不能映射为草稿或空闲。

时间分层：planned_*、expire_date为上海业务日；新*_at明确存UTC；旧create_time/update_time/joined_time及M01原审计仍按既有上海datetime约定。旧start_time/end_time完全保留，核准前不做DATE()截断或时区重解释。
