### 1.1 GET /process/templates/pump-count-options（对外亦 /system/process/templates/pump-count-options）

- **用途**：补液方案编辑器读取当前可选泵数候选；候选是对集成反应器型号目录（`dev_integrated_reactor`）的聚合投影，非静态枚举。
- **路径双形**：服务内映射 `GET /process/templates/pump-count-options`（`ProcessTemplateController` 类级 `@RequestMapping("/process/templates")`）；经网关形态 `GET /system/process/templates/pump-count-options`（`/system/** StripPrefix=1`）。`/process/**` ext 路由不剥前缀，两形态等价。
- **请求参数**：无入参（源码 `listFeedingPumpCountOptions()` 无参）。
- **响应**：`AjaxResult.success(List<TemplatePumpCountOptionView>)`；每项 `{pumpCount:Long}`（`com.futurefab.system.domain.vo.m04.TemplatePumpCountOptionView`，仅一字段）。列表在应用服务侧已完成规范化：`filter(value>0).distinct().sorted()`（`M02TemplateModelResourceAdapter#findPumpCounts:69`），空集合与非法值（非正/重复）不外露。顶层无 `managementRevision`（本模块仅列表读口 `M04-011 pageTemplates` 使用 `@CurrentManagementRevision`，本口不借用）。
- **判权链**：`ProcessTemplateApplicationApplicationServiceImpl#listFeedingPumpCountOptions:1296` 首行调用 `requireFunction(TemplateKind.FEEDING, "query", "feedingPumpCountOptions", readPathActor())`（源码 :1301），即本口对应用服务判 `process:feeding:query` 功能码；未通过时抛 `ManagementGuardRejectException(FutureFabErrorCode.FORBIDDEN, "当前用户无 process:feeding:query 功能权限")`（源码 `requireFunction` :335—342）。
- **身份来源**：`readPathActor()`（源码 :348—372）从服务端会话事实（`RequestMetadataContext.getRequestId()`+`SecurityUtils.getUserKey()`）经 `actorContextPort.resolveActorContext` 解析；`actor` 为 null、sessionKey/requestId 不同源、或 Port 依赖异常一律走 `permissionDependencyUnavailable()` 失败关闭，不降级放行、不采用浏览器自报 actor。
- **守卫制式**：只读；无 `@ManagementGuardedWrite`、无 WriteMeta、无 Body 版本字段。不适用 `X-Request-Id`/`X-Management-Revision` 双头。
- **调用链与事务**：`ProcessTemplateController#listFeedingPumpCountOptions:231` → `ProcessTemplateApplicationApplicationServiceImpl#listFeedingPumpCountOptions:1296`（`@Transactional(readOnly=true)` 由类级只读事务保证）→ `TemplateModelResourcePort#findPumpCounts()`（`service/port/m02/TemplateModelResourcePort.java:18`）→ `M02TemplateModelResourceAdapter#findPumpCounts:61`（`service/impl/port/m02/`）→ `mapper.selectPumpCounts()`。读侧首尾对 `currentRevision()`/`requireSameRevision` 做同次调用内一致性检查（源码 :63、:70），revision 漂移即失败关闭；本链不写业务表。
- **外部依赖**：`TemplateModelResourcePort` 属 M02 归属；提供方不可用或返回 null/含 null 元素时按 `RESOURCE_FACTS_UNAVAILABLE` 失败，不返回空集蒙混。上一轮 Javadoc "当前从集成反应器型号表读取，后续由应用服务统一扩展其他设备来源" 是提供方内部事实，不外露。
- **失败路径**：
  - `FORBIDDEN`（403 语义）：`requireFunction` 判 `process:feeding:query` 不通过（源码 :339—341）。
  - `RESOURCE_FACTS_UNAVAILABLE`（503）：Port 返回 `counts` 为 null 或含 null（源码 `M02TemplateModelResourceAdapter:67`，"型号泵数事实不可得"）；`requireSameRevision` 前后版本漂移同源失败。
  - 权限依赖不可得：`readPathActor` 中 `actorContextPort` 抛非业务异常或 actor 身份不齐（源码 :364、:369）→ `permissionDependencyUnavailable()` 走统一失败外壳。
  - 未登录：会话事实缺失经上述依赖失败关闭。
- **源码证据**：`futurefab-modules/futurefab-system/src/main/java/com/futurefab/system/controller/ProcessTemplateController.java:229—235`；`service/impl/application/m04/ProcessTemplateApplicationApplicationServiceImpl.java:1296—1305`（判权行 :1301）、:335—342（`requireFunction`）、:348—372（`readPathActor`）；`service/impl/port/m02/M02TemplateModelResourceAdapter.java:61—72`；`domain/vo/m04/TemplatePumpCountOptionView.java`。

### 1.2 GET /process/templates/pump-speed-options?reactorType=...

- **用途**：补液方案编辑器读取泵速策略候选。`pump_speed_strategy` 属全局运行配置（自有模块权限 `lab:pumpSpeed:list`），本口以补液方案编辑器投影读口身份再经本模块 `process:feeding:query` 判权（源码 :1314—1317 服务端自述）。
- **路径双形**：服务内 `GET /process/templates/pump-speed-options`；经网关 `GET /system/process/templates/pump-speed-options`；两形态等价。
- **请求参数**：Query `reactorType`（`com.futurefab.system.domain.vo.m04.ReactorType` 枚举，源码 :13、:15 允许 `INTEGRATED_REACTOR`/`BENCH_REACTOR` 两值）。为空即失败关闭。
- **响应**：`AjaxResult.success(List<TemplatePumpSpeedOptionView>)`；每项字段 `strategyId:String`（十进制字符串）、`strategyName`、`labType`、`segmentType`（如 `THREE_STAGE`）、`effectiveInput:Object`（由 `legacyPumpSpeedContent` 组装的旧格式内容映射，源码 :1342—1377，含 `strategyType/labType/calibration/high/low/monitor/jitter/backflow/clog` 键，字段直取 `LabPumpSpeedStrategy` 对应列）。禁用策略（`status != "0"`）不入选候选，源码 :1326—1329 显式过滤。顶层无 `managementRevision`。
- **反应器类型 → 实验室类型映射**：`pumpSpeedLabTypes(ReactorType)` 集中在应用服务私有方法（源码 :1213—1224）；`INTEGRATED_REACTOR → [COMMON, PILOT]`，`BENCH_REACTOR → [COMMON, SMALL]`，其他值 → 空列表。前端只传业务枚举，映射不泄漏到前端。M03 入口 line 9 记载小试 Speed1—10 复用本读口，即候选按 `COMMON+SMALL` 筛选。
- **判权链**：`listFeedingPumpSpeedOptions:1308` 首行同 1.1 走 `requireFunction(FEEDING, "query", "feedingPumpSpeedOptions", readPathActor())`（源码 :1317）。
- **守卫制式**：只读；无 `@ManagementGuardedWrite`、无 WriteMeta、无 Body。
- **调用链与事务**：Controller → `ProcessTemplateApplicationApplicationServiceImpl#listFeedingPumpSpeedOptions:1308` → `labPumpSpeedStrategyMapper.selectLabPumpSpeedStrategyList(LabPumpSpeedStrategy{labType})`（按映射后的 labType 逐次查询、拼装）。读事务由类级只读保证，无业务写、无外部投递。
- **外部依赖**：`pump_speed_strategy` 属 M03/M02 侧配置表；本口仅读、不改；提供方表结构变更须同步影响 `legacyPumpSpeedContent` 字段映射。
- **失败路径**：
  - `INPUT_INVALID`：`reactorType == null`（源码 :1310—1313，"reactorType 不能为空"）。
  - `FORBIDDEN`：判权不通过（源码 :335—342）。
  - 权限依赖不可得：`readPathActor` 依赖失败或身份不同源（源码 :364、:369）。
  - 空候选：合法空返回（映射到非两种枚举时 `pumpSpeedLabTypes` 返回空 List，源码 :1223），不视为错误。
- **源码证据**：`ProcessTemplateController.java:237—243`；`ProcessTemplateApplicationApplicationServiceImpl.java:1308—1340`（判权 :1317）、:1213—1224（映射）、:1342—1377（`legacyPumpSpeedContent`）、:335—372（`requireFunction`/`readPathActor`）；`domain/vo/m04/TemplatePumpSpeedOptionView.java`；`domain/vo/m04/ReactorType.java:13、15`。
