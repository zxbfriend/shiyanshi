# 七类工作台能力与请求夹具

契约版本：DD-20260913-R2；HTTP协议头X-M05-Contract-Version仍为2，不将文档版本混作协议字段。依据[工作台契约](检测工作台接口与位置生命周期.md)第2—4节、[配置模板](可配置发送暂存与删除规则设计.md)第3节和[现场核准矩阵](现场能力核准矩阵.md)。

## 固定模拟前置

所有样例仅供隔离测试：当前用户有detect:workbench:add/query、目标实验室操作权限；sampleNo能解析到有权培养；位置字典包含下列列/行；profileRevision=3、queueRevision=7；设备与适配器能力均在模拟配置中显式核准。真实生产实例未核准时禁止套用样例启用。OSMO字段能力不从名称推导，以下无专用参数是明确的测试profile，不是对现场设备的核准。

Headers：Authorization为测试会话，Content-Type=application/json，X-Request-Id每个新逻辑请求用独立UUID，X-Management-Revision=12，X-M05-Contract-Version=2。重复同一次请求使用原UUID和原载荷。

## 非法输入和并发变体

| 变体 | 预期 |
| --- | --- |
| BGA temperature=40.1或37.05 | 范围或精度错误；INVALID_REQUEST，整次不预占 |
| Vi-CELL dilutionFactor=20.1或1.25 | 拒绝，不截断；合法2.1不得沿旧2.0上限拒绝 |
| Cedex itemId禁用／稀释右值101 | INVALID_REQUEST，项目来自当前设备，客户端名称不能覆盖 |
| 任一禁用字段夹带非null值 | INVALID_REQUEST，隐藏控件不构成服务端放行 |
| 列请求跨columnNo或重复channelNo | INVALID_REQUEST；本地全量校验，不部分派发 |
| sampleNo仅无匹配且allowNonCulture=false | NON_CULTURE_CONFIRM_REQUIRED；明确确认后重新预检；若真实关联无权始终拒绝 |
| 旧协议客户端 | CLIENT_UPGRADE_REQUIRED；不静默解释旧删除语义 |
| 位置复用后旧代次请求 | 冲突且不影响新样品；具体位置原因见规则判断契约 |
| 一批中接受/拒绝/未知混合 | PARTIAL或UNKNOWN及逐项事实；不能全批回滚重发 |
| 设备位置未知或现场能力未核准 | 保留issues与阻断状态；模拟通过不代表生产可发送 |

样例中的SIM_CELL、SIM编号必须由隔离夹具注册；不能直接当生产字典或培养编号写入。BGA/圆盘/项目字段约束来自现有输入模板，具体型号能力仍以适配器与现场核准矩阵为准。
