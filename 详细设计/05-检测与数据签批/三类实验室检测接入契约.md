# M05 三类实验室检测接入契约

版本：INTEGRATION-20261010。与[共同边界](../00-总纲与约定/00-三类实验室设备接入与执行边界.md)、[设备发送结果接收与位置释放契约](设备发送结果接收与位置释放契约.md)共同使用；不改变现行签批、受控更正和结果版本规则。

## 1. 代际、来源与检测通道

小试一期、二期、中试是业务接入范围；检测设备仍逐台按现行能力与通讯配置选通道。**2026-11-04 用户裁决：同一台设备只允许一种通信方式**，唯一来源是 `lab_communication`（`device_kind='DETECTOR'` + `device_id`，`communication_type` 取 `HTTP`/`NAMED_PIPE`）；派发快照与型号能力字段只能引用该配置，不得另行选择通道。SDMS、命名管道、文件或其他核准通道由现有检测适配器承接，不统一改走补液`DeviceCommandPort`。

一期保留原派发/检测服务时，新系统接收其可核准结果并建立来源映射，不再次派发同一样品。原结果主键必须连同来源系统实例、设备、原任务/派发身份和版本一起解释。不能按显示样品号、最近培养或最近发送任务自动归属；旧签名也不能直接冒充新系统用户授权与审核结论。

## 2. 派发与接收顺序

1. 派发前固定实验室、培养/样品、设备/位置、项目、配置版本和派发身份，按现行事务规则保存占用及发送意图。
2. 检测派发适配器调用核准通道，分别记录受理与执行事实。发送超时或回执丢失保留未决派发和位置占用；先核对原派发，不生成新身份重复送样。
3. 接收适配器校验可信服务来源和设备身份，保留原始证据，再交现行检测观测接收契约。逻辑`DetectionObservationService.accept(ObservationEnvelope)`不因本文成为新增公共HTTP接口。
4. M05按唯一关联定位样品/派发/项目，校验单位、质量、时间、序列和源版本；重复相同证据不重复生效，同身份冲突或关联不唯一进入隔离处理。
5. 分别维护设备执行终结、各项目结果齐全、结果可审核/可计算状态；位置释放按原契约的终结与对账规则办理，不以某个指标已返回或等待超时推断设备已释放。

错误、无测量值与未知分别按VALUE/ERROR/NO_MEASUREMENT/UNKNOWN语义保存，不能用0或上一次值填补。迟到结果依据原派发身份处理，不落到复用同一位置的新样品。手工修复关联、重测及源更正均保留操作者和版本，不能覆盖原始失败事实。

## 3. 补糖计算与异常交接

M07经现行跨模块契约取得符合确认/审核要求的有效结果及其版本，固定到计算和执行规格。M05接收结果不直接开泵；外部设备成功与业务审核通过也分别记录。

源结果更正、撤销或失效后，M07按现行版本屏障核对待执行任务和计算；已下发命令按执行事实处理，不能自动回滚已发生剂量或追加“补差”动作。对未来段是否需要重新计算和审批由M07/M06业务规则决定，不能覆盖正在执行的参数。

检测异常保留在M05；设备在线事实按M02现行观测边界处理。向M09交接检测告警时，先核对当前来源注册、事件版本及恢复关联；缺少注册须补齐契约后启用，不能假设已有M05通用告警事件。告警投递失败不回滚检测原始结果，也不解除位置占用。

## 4. 实施输入与验收

逐设备取得真实成功、部分失败、缺值、重复、乱序、迟到和源更正样例，以及派发身份、结果目录/接口、终结及位置释放证据。一期新旧结果关联的物理存储与桥接签名缺失时先冻结所属字段/接口，不更改一期旧表。

验收覆盖共同矩阵INT-AC01/06/07/09/10/13/15，另验证通信切换后的旧通道结果不误入新派发、重复接收不重复触发补糖、检测失败不会伪造有效GLC。未核准的结果不得用于自动计算；文档完成不等于现有派发/取数代码已完成三类现场联调。
