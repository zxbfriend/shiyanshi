# Load Sample页面与检测交接契约

日期：2026-11-07，S04第4组批C。对应S02-314—317，B8637—8713；V5.1《22-Load Sample（5.0）》L3—100。已查看原图image737、738、739、740、741；V4.0无此独立页。有效澄清为Q-S02-S7-LoadSample、Q-A08-CancelScope、Q-A08-PartialCompletion及后续撤销额外全局模式门槛的更正。

本专题补齐新增独立入口，不复制检测派发/结果系统。M07拥有页面动作、实验室模式及原执行方编排；M02提供资源/配置事实；M05拥有固定检测需求、派发、接收、结果及签批。原BatchJob释放职责保留，不能由本页新建第二释放执行器。本文不授权改旧库。

## 1. 入口、载具及逐行输入

入口为小试实验室Load Sample；它是手工装载后自动测样，不要求培养内取样测样的“已完成开始培养”。权限使用现有实验室操作范围及对应检测/执行动作权限，M07执行端重验；不能以可查看实验室代替设备操作资格。网页、SDK、M07动作编号由M07现有目录串行登记，本模块不另建控制HTTP入口。

| 页面对象 | 设计规则 |
| --- | --- |
| 载具 | 按本页原文为横向A—H、纵向自下而上1—6；孔号A1—H6；A/B列禁自动检测并置灰。此Load Sample页不等同已另行澄清的STP1/STP4，后者A—F×1—8不能无依据迁移到本页 |
| 录入顺序 | 按H6至A1展示，A/B行不可填写；服务端校验真实载具/孔号，不把显示序号当机器地址 |
| 孔位显示 | 原文只有空闲/有液体；草稿、确认、执行中为有液体。未填写为空闲；完成须满足第4节真实释放，不能由某一结果卡状态推断 |
| 样品ID | 使用[工作台身份规则](检测工作台接口与位置生命周期.md#v51样品身份与培养关联2026-11-07)及真实内部关联；不能为“必须有培养”而给独立Load Sample编造cultureId |
| BGA选中时 | 温度必填15—40℃、最多1位小数；这是本页手工温度，不套自动任务DEFAULT解析分支 |
| Vi-CELL选中时 | 单选细胞类型取有效数据字典；样品稀释1.0—20.0，最多1位小数，与项目稀释独立 |
| OSMO选中时 | 仅使用所选检测需求及合法设备能力，不另加原文没有的温度或稀释输入 |
| Cedex选中时 | 选有效设备配置中的测试项，可多选/按分组全选；无组为“未分组”；弹窗仅在对应通道空闲时开放，显示所选数量 |
| Cedex项目稀释 | 左值固定1；右值默认1，只有设备支持修改时可编辑1—100整数，不支持时仍为1；不增加样品级Cedex稀释列 |

没有选择的检测类型不要求其专属输入，不把隐藏旧值发送为启用参数。非法值原样提示，不能四舍五入变合法。历史中的容量µL保留真实来源；原文录入区未定义该值来源，不以截图1500造默认，见Q-4-02。

## 2. 操作与正常路径

| 操作 | 前置/输入 | 结果与边界 |
| --- | --- | --- |
| +1 | 当前行样品ID及原编号规则 | 向下一行填写增1后的编号；只改未提交输入，不复制内部ID、结果、签审或占用事实；遇A/B禁用行不得写入 |
| 清空 | 仅填输入，未草稿/确认/开始 | 清本行未提交内容；草稿/确认的取消走独立动作，执行中不提供清空 |
| 草稿 | 当前显式选中行及其输入 | 保存合法草稿并显示有液体，保留当次所选检测参数；未保存纯输入不是数据库记录 |
| 确认 | 仅草稿 | 提示核对样品位置；若当前为自动，二次确认切手动，成功后才记“确认”并将按钮变“开始”；已手动不重复发切换命令 |
| 开始 | 仅确认完成的记录 | 若当前手动，二次确认切自动；切自动前按实际所选任务及有效用量配置核耗材。等于需求算足够，共用关系按真实配置去重；不引入库存预留系统 |
| 取消 | 草稿或已确认且尚未开始 | 按原链保存取消事实，清本行当前填写，历史记录保留；已执行中不直接取消/清空，不借此向仪器发取消 |

开始时模式成功切自动后才启动原执行链，不能在设备调用前显示开始成功。实验室模式对整个实验室生效，自动模式对工作流/四台实际自动化接入检测设备的原限制保留；不用该限制扩到所有其他手工检测设备。模式切换不等于已有任务停止或孔位已释放。

页面对模式写入及自动测样动作仅呈现成功、失败、结果未确认。失败保留可修正的合法输入；结果未确认保留原请求身份/原记录并读取原进度，不自动换键重发、不显示成功。原文未要求的新全局未决状态阻断、人工恢复向导、强制停止、审批或清空按钮均不增加。

批量操作提交点击时的显式行集合并全量校验权限、孔号、版本和动作资格；不将签名台混选跳过规则移来。草稿保存等本地状态与审计同事务；模式切换/测样设备I/O均在事务之外，不能承诺多台设备物理全有全无。物理逐行失败或结果未确认须逐行显示真实结果，不能回滚数据库后再次启动已执行行。

## 3. M07→M05固定检测交接

1. M07沿唯一原执行方确认当前行装载与合法资源身份，固定所选类型/参数及当次来源记录，不在M05复刻搬运动作。模式尚未确认、设备调用结果未确认时不得伪造“已装载/已开始”交接事实。
2. 复用[自动检测契约](自动检测与跨模块结果契约.md)的MANUAL_AUTO、DetectionOrder及sourceOrder；按当前合法所选类型冻结expectedItems、样品/设备身份、温度、细胞类型、稀释与Cedex项目。M05不读取页面内存或最新模板重建参数。
3. M07调用既有DET-I03 prepareDetection，M05短事务内重验授权、设备规则、位置及编号，固定派发/绑定；DET-I04 executePreparedDetection在事务外调用设备。原请求重入复用当次固定绑定，不新建第二次检测。
4. 模式/搬运事实与仪器接受、实际检测、结果完整分开；M05通过既有DET-I05 getDetectionProgress按原orderId/dispatchId返回各样品/结果真实进度。没有结果不补0，不以已派发表示已检测。
5. 回传按[接收契约](接收事件持久化与结果字段设计.md)中稳定内部绑定、设备单通道及时间证据应用；重复接收不重复结果，部分结果不完成整行，晚到结果不能挂到复用孔位的新行。
6. DetectionOrder现有培养字段与独立无培养Load Sample的映射、来源记录在M07现有模型的承载、动作编号及原执行方法需M07同组交接定形。只挂现有DET-I03/04/05，不新增M05 SourceTask类或另起订单表；跨组尚未定形处列于第6节，不把它伪装客户已答。

## 4. 完成、取消与孔位释放

全部所选检测均真实完成，且原执行/搬运与BatchJob合法释放链已确认可复用，才显示该行完成及孔位空闲。未选类型不列入本行完成集合；所选BGA完成而Cedex未完，整行仍有液体。签名、审核不额外成为孔位释放前置。

M05仅交付检测完成/结果事实，不调用BatchJob释放；M07/原执行方消费原真实释放结果。设备检测位置腾位和Load Sample载具孔位腾位是不同对象，不能互相替代。取消未开始记录后是否已无物理占用沿原链事实处理，不用清空输入覆盖活动占用。

执行中异常保留原记录、绑定和已有结果，显示原因；沿已存在的合法处理入口查原进度，不制造停止成功、完成或释放。原文及有效澄清未授权的新异常工作流不设计。原BatchJob具体方法/完成映射尚缺接口资料时只跳过该适配点，正常录入与检测结果设计继续。

## 5. 历史查询

按原文显示所有已录入记录，样品ID模糊、开始时间、结束时间、操作用户联合查询；按开始时间倒序，同刻用原记录稳定ID分页，不以显示样品号或孔号作唯一身份。权限先于过滤/计数，当前孔位已复用不改变旧行归属。

列顺序为序号、孔号、容量µL、样品ID、BGA勾选/温度、Vi-CELL勾选/细胞类型/稀释、OSMO勾选、Cedex勾选、状态、开始/结束、操作用户、Cedex测试项按钮。测试项详情展示当次固定选择，不追今天的设备检测项配置；未选Cedex不出现有内容的假详情。未知实际起止或容量为空并提示未核验，不用创建/修改时间或截图值填充。

本页时间筛选为明确开始/结束动作时间，不能直接套原生94创建/修改OR规则。用户文本按字面匹配，不接受任意SQL表达式；不新增历史导出或设备统计按钮。
