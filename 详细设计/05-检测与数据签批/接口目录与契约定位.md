### 定位049 响应结构补充：scopeSummary 精确形状（2026-10-12 用户确认，来源等级【已确认】）

`M05-031` 预览响应中的 `scopeSummary` 字段形状**已定**（此前本模块两份「完整字段字典」无此条目，属登记遗漏而非阻塞——**该两份字典是数据库表列字典，`scopeSummary` 是接口响应结构，不属其语义边界，故不补登**）。

```json
{
  "scopeSummary": {
    "resultCount": 42,
    "versions": [
      { "objectVersion": "7", "resultCount": 10 },
      { "objectVersion": "8", "resultCount": 20 },
      { "objectVersion": "9", "resultCount": 12 }
    ],
    "resultSetHash": "sha256摘要",
    "extendedDetectClasses": [],
    "exclusions": []
  }
}
```

| 字段 | 职责 | 说明 |
| --- | --- | --- |
| `resultCount` | 展示 | 实际结果数，导出前必须输出供人工核对范围 |
| `versions` | **仅展示，不承担身份校验** | 按 `objectVersion` 聚合条数。**版本号不能唯一定位结果**（不同检测结果都可能有自己的第 7 版），故必须带 `resultCount` |
| `resultSetHash` | **绑定预览、防内容替换** | 服务端对完整「结果ID＋版本＋冻结内容身份」集合按**固定规则**计算；确认令牌绑定此摘要，提交时复算比对 |
| `extendedDetectClasses` | 展示 | 超出默认模板的检测类型集合 |
| `exclusions` | 展示 | 排除项及原因 `[{code,path,message}]` |

职责边界：**完整结果集合保存在服务端，不靠页面传回版本列表决定导出内容**；模板发布身份**另外**绑定到确认令牌；结果或模板变化时按既有 T-02 口径拒绝提交、要求重新预览。

⚠️ **【技术建议·待 owner 评审】**：`resultSetHash` 的**具体哈希算法与输入清单排序规则**尚未冻结（裁决已确认"要分开承担职责"，未确认"怎么算"）。实现前须由 M05 负责人补成精确合同。
