## 接口接入注意

`GET /detect/workbench/queue?detectorId=7` 的响应示意（示例 ID 和版本不是生产默认值）：

```json
{
  "code": 200,
  "managementRevision": "77",
  "data": {
    "profileRevision": "3",
    "queueRevision": "4",
    "serverTime": "2026-10-10T08:00:00Z",
    "columns": [],
    "positions": [],
    "displayRows": [],
    "issues": []
  }
}
```

`displayRows` 是显示集合，不是完整物理占位集合；无显示行不能推定设备空闲。`positions` 中无权或未知占位不应获得样品详情。管理写请求的 `X-Management-Revision` 只取顶层值。前端本轮仅修复读取契约，后续送检、暂存等动作的完整规则接入与验收仍按原计划逐批进行。
