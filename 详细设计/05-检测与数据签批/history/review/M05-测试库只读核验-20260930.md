## 连接与执行边界

- 实际库：`ymsw_v2`；MySQL 8.0.46。
- JDBC 使用重复读隔离和数据库会话 READ ONLY；实测 `@@session.transaction_read_only=1`，会话时区 `+00:00`，启用严格 SQL 模式。
- 只执行信息结构查询、SHOW CREATE TABLE、det_* 汇总查询及三个无业务身份的 SELECT 探针；最后关闭只读事务并 rollback。
- 未执行基线/增量/初始化脚本、DDL、INSERT/UPDATE/DELETE、FOR UPDATE、业务接口、设备命令或业务数据清理；没有更改 Nacos 或服务连接。

## 结构核对

依据 `docs/开发基线/README.md` 指定的 `01-完整建表.sql` 和来源清单，核对15张 det_* 表，加上 `sys_user`、`sys_oper_log`、`sys_data_change_log`、`sys_management_revision`、`sys_management_request`，共20张表。

- 比较364个字段的存在性、类型及可空性，未发现差异；整数显示宽度和类型内部空格按等价语义归一化。
- 比较97个基线索引的名称、唯一性、列顺序和列前缀，未发现缺失或差异。未把额外索引当作与基线不兼容。
- 核对65个基线命名 CHECK 约束均存在且 ENFORCED=YES。**没有执行约束拒绝测试，也没有证明每项约束表达式完全等价。**
- 本次没有全面比对字段默认值、字符排序规则、外键、权限、触发器及所有索引性能，不将本结论称为完整数据库基线验收。
- 新暂存 Mapper 需要的稳定创建人、对象版本、占位代次、运行时间证据以及检测项稀释字段已存在；版本存储、原始设备事件和更正表也存在。
- SYSTEM 管理版本初始化行数量为1；这不等同于守卫CAS、审计或幂等业务事务验证通过。
