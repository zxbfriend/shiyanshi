## 接口接入说明

沿用六个原路径和 DTO。写请求必须带 X-Request-Id、X-Management-Revision，并新增 X-M05-Contract-Version: 2；旧客户端缺版本头返回 CLIENT_UPGRADE_REQUIRED。管理版本取当前 006/007 顶层 managementRevision；requestId 为 UUID，同一次操作重试复用同键与原内容。配置/队列版本取 006，已有记录还必须带 expectedObjectVersion、expectedOccupancyGeneration。

入口权限 detect:workbench:query；首次暂存另需 detect:workbench:add，首次删除/清空另需 detect:workbench:edit，均在守卫内用可信身份检查。所有首次写入还复核实验室操作范围与本人身份。非培养样品须 allowNonCulture=true；培养号解析通过 M03 Port，范围拒绝不会退化为非培养样品。

清空先 007 action=CLEAR，再将返回 confirmationToken 和相同候选提交 029/030。批量结果按原序返回 DELETED/CLEARED/SKIPPED 与 reasonCode；SKIPPED 不推进样品版本。整批无变更只保存请求回执和操作日志，不伪造数据变更日志或推进队列。

常见错误：REQUEST_CONFLICT（同键内容改变）、STATE_CONFLICT（对象/队列/配置条件改变）、CONFIRMATION_EXPIRED_OR_CHANGED、FORBIDDEN_OR_NOT_FOUND、NON_CULTURE_CONFIRM_REQUIRED、INPUT_INVALID。不得据错误自行发送设备命令。

## 请求示例（说明用，版本与 ID 必须来自当前查询）

单条暂存 POST /detect/workbench/sample/save-draft，例为 OSMO 非培养样品：

```json
{"detectorId":"100","columnNo":"1","channelNo":"2","profileRevision":"7","queueRevision":"9","clientRowKey":"row-2","sampleNo":" sample a ","allowNonCulture":true}
```

正常 data 含 sampleId、objectVersion、occupancyGeneration、stored=true、clientRowKey、requestId、queueRevision；样品号保存为 SAMPLE A（内部空格保留）。更新暂存另传原 sampleId、expectedObjectVersion、expectedOccupancyGeneration，不得借更新迁移位置或改为他人的记录。

批删 POST /detect/workbench/sample/delete/batch：

```json
{"detectorId":"100","columnNo":"1","profileRevision":"7","queueRevision":"9","items":[{"sampleId":"200","expectedObjectVersion":"1","expectedOccupancyGeneration":"10"}]}
```

返回 data.batchRequestId 及 data.items，每项含 sampleId、outcome；跳过项另有 reasonCode、message。可读候选跨设备或跨列属于请求错误，在第一项修改前拒绝；不存在或无读取权统一不可操作，不暴露所属设备/列。
