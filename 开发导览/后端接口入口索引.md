# 后端接口入口索引

用途：在 IDEA 根据实际请求找到源码，随后跟踪被调用的应用方法及 Mapper。静态清点 system controller 目录中带 RestController 的 124 个 Java 文件，不含 auth、job、file 等服务的 Controller，不是接口数量或完成率。

分组依据是 Controller 实际导入的 `service.application.m0x`；跨模块或未采用该模式的类单列，不按名字猜测实现状态。类级路径只是定位线索，方法级注解、网关前缀和继承关系仍须打开源码核对。应用服务只列最多两个入口，完整导入见源码。列表中的类存在不代表全部方法已实现或已验收。

## 一 怎么使用

1. 从 Network 复制真实请求，先去掉部署代理前缀，再核对 gateway 是否 StripPrefix。
2. 找下表类级路径，打开 Controller 中对应 HTTP 方法。
3. Ctrl+B / Ctrl+Alt+B 跟服务；再定位真正调用的 Mapper 与 XML。
4. 对照现行模块接口、调用时序、错误码和测试。遇到 legacy 守卫或未实现依赖，继续核对公开可达链，不按类名认定功能已经完成。
