# 字段说明与计算公式（3.1）（3.2）

1.  常用字段
| **字段名称** | **说****明** |
|---|---|
| 培养id | 全局唯一编码 |
| 培养开始时间 | 年月日，date |
| 培养结束时间 | 年月日，date |
| 培养周期 | 根据开始结束时间计算，培养结束时间－培养开始时间 |
| 培养天数/当前阶段 | 当天为培养开始的第N天 |
| 关联容器 | 反应器/控制器编码 |
| 培养模式 | 小试默认普通培养中试普通/反应器培养 |
| 培养流程方案 | 工作流id List |
| 初始培养重量（g） | 创建培养ID或开启工作流时录入数值 |
| 总补液量（g） | 单位g； 小试每次补液任务执行成功后，将任务实际补料量追加到这里； 中试在执行任务后，去获取一下补料秤的读数，将每次补的量追加到总数。 |
| 总取测量（g） | 小试每次取测后，根据每次测试提取量，追加到减少量上，也可以通过反应器详情页面的追加取测量功能临时补充取测量，追加到减少总量上。单位g |
| 细胞类型 | 流程开始后录入 |
| 乳酸浓度 | 补糖计算模式未选择残糖+乳酸时才会有此指标：乳酸浓度=残糖确认操作时确认的Cedex相应检测项目的检测数值； 其他类型的操作不会引起乳酸的数据变化 |

2.  罐重/反应器重量/反应器培养体积
罐重/反应器重量的单位根据反应器的规格确定，前端展示时，需根据所选反应器的规格联动变化

1.  规格小于等于15L时，单位为g
2.  规格大于15L时，单位为kg
| **反应器类型** | **数据来源/计算公式** |
|---|---|
| 集成反应器 | 直接读取反应器的实际数值 |
| 台式反应器 | 计算公式：初始培养体积+接种体积+当前的总补料量－当前的总取样量 |

1.  补糖任务的目标补糖量
| **补****糖规则/计划方式** | **说明** | **数据来源/计算公式** |
|---|---|---|
| 按数值 | 直接输入补糖体积 | 目标补糖量 =本次补糖体积*补糖糖浓度 |
| 按规则 | 残糖+乳酸 | 目标补糖量=（目标残糖浓度-补糖前残糖浓度-补糖前乳酸浓度）*补糖前罐重 |
| 残糖 | 目标补糖量=（目标残糖浓度-补糖前残糖浓度）*补糖前罐重 |  |

2.  补糖任务后的糖浓度
不管按数值或是按规则生成的补糖任务，都根据实际的任务完成情况计算最新的糖浓度

| **反应器类型** | **数据来源/计算公式** |
|---|---|
| 集成反应器 | 糖浓度=（补糖前糖浓度*补糖前体积+本次实际补料体积*补糖糖浓度）/补糖后体积 |
| 台式反应器 | 糖浓度=（补糖前糖浓度*补糖前体积+本次实际补料体积*补糖糖浓度）/（补糖前体积+本次补料体积） |

1.  补料体积
| **任****务类型** | **计划方式** **/补料类型** | **说明** | **数据来源/计算公式** |
|---|---|---|---|
| 补料任务 | 数值/百分比 | 直接输入补料体积 | 补料体积=输入的补料体积数值 |
| 补糖规则 | 按数值 | 直接输入补料体积 | 补料体积=输入的补料体积数值 |
| 按规则 | 需达到指定糖浓度 | 补料体积=（目标糖浓度-补糖前糖浓度）*补糖前体积/补料糖浓度 |  |

2.  残糖量
残糖量=罐重*残糖浓度，其中残糖浓度用最近一次计算/确认得到的糖浓度

1.  目标补料量
| **任****务类型** | **计划方式** **/补料类型** | **说明** | **数据来源/计算公式** |
|---|---|---|---|
| 补料任务 | 数值 | 直接输入补料体积 | 目标补料量=输入的补料体积数值 |
| 百分比 | 直接输入补料体积 | 目标补料量=（初始培养体积+接种体积）*补料体积 |  |
| 补糖规则 | 按数值 | 直接输入补料体积 | 补料体积=输入的补料体积数值 |
| 按规则 | 需达到指定糖浓度 | 补料体积=（目标糖浓度-补糖前糖浓度）*补糖前体积/补料糖浓度 目标补料量 =补料体积 |  |

2.  补料任务后的糖浓度
| **反应器类型** | **勾选补糖时计算补料引起的糖浓度变化** | **不****勾选****补糖时计算补料引起的糖浓度变化** |
|---|---|---|
| 集成反应器 | 补料之后糖浓度=（补料前糖浓度*补料前体积+本次补料体积*补料糖浓度）/补料后体积 | 补料后糖浓度=补料前糖浓度*补料前体积/补料后体积 |
| 台式反应器 | 补料之后糖浓度=（补料前糖浓度*补料前体积+本次补料体积*补料糖浓度）/（补料前体积+本次补料体积） | 补料后糖浓度=补料前糖浓度*补料前体积/（补料前体积+本次补料体积） |

3.  液袋现重量/液袋的余量
液袋的余量为理论值，计算公式如下：

液袋的余量 = 液袋的容量-累积补液量
