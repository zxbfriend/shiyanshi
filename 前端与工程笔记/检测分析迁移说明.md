# 检测分析迁移

将 `futurefab-ui` 的 BGA、Vicell、OSMO、Cedex 检测工作台迁入 `app-smp-data`，检测记录使用同一左侧导航。授权菜单与原系统组件标识保持对应，四个工作台不再显示迁移占位页。

## 页面与交互

- 左侧参照 fabsyn 的 `portal/user-and-user-group` 导航布局，包含当前授权的检测页面，选中、悬浮、文字及图标均使用公共颜色变量。
- 右侧需求队列、检测结果、检测项明细和样品 ID 修改历史均使用公司 `vxe-grid`；记录查询及详情表格继续使用 VXE。
- 保留设备类型差异：BGA 温度、Vicell 细胞类型与稀释系数、Cedex 检测项分组选取，以及各设备的载架、列签和发送方式。
- 迁移暂存、单条/批量发送、填充、复制、清空、结果刷新、样品 ID 修改、上传/撤回、签名/撤销、作废/撤销、异常标记与打印入口，保留原接口及状态、权限、通讯、数量与样品校验。
- 结果操作超过三个时收进“更多操作”，固定操作列保持可见；查询条件可展开。详情可跳转检测记录并传入实验室、设备和检测类型。
- 未保存输入离开时确认，提交期间锁定页面/设备切换。设备切换及组件卸载后的过期响应不再落地；轮询刷新保留本地输入，已成功提交的行清除未保存标记。

## 代码位置

- `packages/app-smp-data/src/router/index.ts`：四类工作台及检测记录的路由、懒加载和仪器 props。
- `packages/app-smp-data/src/app.vue`：检测页面导航与 RouterView。
- `packages/app-smp-data/src/views/detection-workbench/index.vue`：四类设备共用的 Ant/VXE 视图。
- `packages/app-smp-data/src/workbench/`：已迁为 TypeScript 的设备控制逻辑、队列规则、轮询、列配置和公共样式。
- `packages/sdk-smp-api/src/workbench.ts`：工作台接口，复用认证与错误处理客户端。
- `packages/app-smp-data/src/views/detection-record/index.vue`：授权实验室选项和工作台查询条件联动。

## 验证

45 项单元测试通过，涵盖队列权限、通讯中断、发送容量、样品编号、Cedex 检测项载荷、接口方法与参数、设备切换及卸载后的响应隔离。数据应用和门户的构建、类型检查以及公司 UI/Less 检查通过。

浏览器使用隔离的内存接口验证：BGA 温度输入与暂存、Vicell 细胞类型/稀释及发送确认、Cedex 检测项选择与暂存、OSMO 暂存、结果详情、“更多操作”、未保存输入保护和检测记录联动。正式微前端容器下验证表格高度与滚动，1024px 窄屏改为上下排列。验证文件已清理。

本次未向实际检测设备发送需求，设备执行、真实打印及签名/作废等后端业务闭环仍需在测试环境联调。

后续路由/TypeScript 改造说明与验证范围见[路由与 TypeScript 架构](路由与TypeScript架构.md)。
