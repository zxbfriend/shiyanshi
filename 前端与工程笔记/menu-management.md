# 菜单管理迁移

入口：系统设置 → 基本设置 → 菜单管理，前端路由 `/settings/menu-management`，对应原组件标识 `system/menu/index`。

- 树表使用公司 `vxe-grid`，参考 `fabsyn-frontend` 的 `portal/application-menu`，通过 Sortable 拖拽手柄调整同级顺序并自动保存。拖动不改变父子关系；筛选期间禁用拖动，避免遗漏隐藏行。
- 保留目录 / 功能 / 按钮、上级菜单、路径、组件、路由名称和参数、图标、权限、缓存、可见性、启停状态及显示排序等配置。新增菜单的显示排序默认取同级末尾，仍可在弹窗内调整；列表也支持通过拖拽调整同级顺序。
- `menuName` 保留原中文名称；新增 `menuNameEn` 保存英文名称。导航优先使用配置的英文，留空时继续使用内置翻译或中文。中文、英文名称均可搜索。
- 顶级目录通过 `entryType` 配置 `lab`、`settings`、`data`，子菜单继承入口类型。原 `setting` / `data` / `lab-a` 路径仍兼容。入口类型不授予权限，也不代表未迁移的业务组件已可用。
- 实验室入口以授权菜单为准，保留目录名称、英文名称和顺序；不根据 `/lab/lab/options` 的设备筛选选项展开或改名。只有显式设置 `meta.labId` 时才校验可用实验室列表。没有子菜单的实验室目录显示概览空状态；子菜单全部隐藏或无权限时不生成入口，也不补业务权限。
- 使用原 `/system/menu` 接口及权限。批量排序在事务中完成；接口拒绝不完整批次、重复 ID、已删除菜单及循环父子关系。删除仍执行子菜单和角色关联检查。
- 保存、删除和排序后刷新授权导航，无需重新登录。

## 图标与三级菜单展示

- 图标字段使用公共 `IconPicker`（`sdk-smp-common`），从系统已经加载的图标库选择，支持按名称搜索、图标库筛选、分页和当前图标预览。导航通过公共 `MenuIcon` 渲染所选图标；未识别的历史值保留原值并使用原导航默认图标。
- 新图标存储为 `图标包:图标名称`，兼容已有语义名称及不带包名的图标。选择“不使用图标”保存 `#`，兼容现有后端对空字符串不更新图标的行为。
- 编辑二级目录时可设置“三级菜单展示方式”：默认方式、顶部下拉菜单、左侧菜单。默认方式保留原检测分析侧栏及其他菜单下拉布局。侧栏统一由门户渲染，支持折叠、调整宽度以及权限过滤；配置型左侧菜单固定贴合工作区左侧，右侧内容继续使用公共侧栏组件的标准 padding、分隔带和圆角；检测模块不再重复创建侧栏。
- 无需后端或数据库变更。展示方式保存在现有 `query` JSON 的 `__smpMenuDisplay` 属性中（`dropdown` / `sidebar`），恢复默认时删除该属性，其余路由参数保持不变。原参数不是 JSON 对象或合并后超过字段的 255 字符限制时，会提示并保留原值。
- 拖拽手柄使用原生提示，并在选择、开始和结束拖拽时关闭表格浮层，避免独立 tooltip 因 DOM 移动而残留。状态标签使用主题色、标签背景及错误状态颜色变量。

验证：相关导航、图标和主题测试共 40 项通过；公共 SDK、设置/数据应用和门户构建及类型检查通过。隔离浏览器数据已验证图标搜索与选择、保存回填、侧栏与下拉即时切换、侧栏折叠、拖拽排序及提示关闭。真实后端菜单保存仍需在登录会话中验收。
