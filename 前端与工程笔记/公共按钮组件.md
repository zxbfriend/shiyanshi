# 公共按钮组件

两个原组件统一迁入 `@futurefab/ui-sdk-smp-common`，源码和样式使用 TypeScript / Less：

| 原组件 | 新目录 | 导出 | 事件 |
| --- | --- | --- | --- |
| sdk-eqfuse-common 的 icon-button | `src/components/icon-button/` | `EqIconButton`，别名 `IconButton` | `click` |
| sdk-ees-basic 的 button-tip | `src/components/button-tip/` | `EesButtonTip`，别名 `ButtonTip` | `onClick` |

```vue
<script setup lang="ts">
import { EqIconButton, EesButtonTip } from '@futurefab/ui-sdk-smp-common';

function handleAdd(event: MouseEvent) {
  // 在调用页面继续执行原有权限检查和业务操作。
}
</script>

<template>
  <EqIconButton
    icon="#icon-codesign-btn-add"
    tooltip="新增"
    @click="handleAdd"
  />
  <EesButtonTip
    icon="#icon-codesign-btn-add"
    text="新增"
    size="small"
    is-border
    @onClick="handleAdd"
  />
</template>
```

业务页面的文案继续使用语言 SDK 的 `t()`；此处示例直接写出文字以说明接口。

## 保留的行为

- `EqIconButton` 为 16px 图标按钮，支持 tooltip、active、disabled、placement、getPopupContainer；使用公司 Ant Tooltip。
- `EesButtonTip` 支持 SVG、字体图标、文字按钮、溢出文本四种形态，保留 `isBorder`、`isTooltip`、`isActive`、`isOtherClass`、`isGray`、`loading`、`btnWidth`、`marginRight`、`textStyle` 等选项；使用公司 VXE Tooltip。
- ButtonTip 默认按钮尺寸 32px，small 图标按钮 24px；内部图标 normal 为 20px、small 为 16px。
- `app.use(EesButtonTip)` 仍可全局注册原名称；组件 ref 仍提供 `hasTooltip()`，可使用导出的 `ButtonTipExpose` 类型。
- 两个组件都只负责展示和禁用态，调用页面继续保留原有权限和提交逻辑。

## 图标与主题适配

`#icon-name` 和 `icon-name` 优先从现有图标注册表解析，省去运行原始 iconfont.js 的要求。可通过 `iconPack` 指定 `common`、`ypa-icons` 或 `ypa-icons1`，解决同名图标问题。

未命中注册表的 `#symbol-id` 保留 `<use>` 方式，由调用方提供 SVG symbol；未命中的字体图标类也保留原来的 `<i class="iconfont ...">` 方式，由调用方提供字体样式。组件不会把未知图标替换成其他图案。

原 EES 样式中的颜色角色映射至 SMP 主题变量；尺寸、圆角及图标大小保留在组件局部样式中，不引入 EES 的全局样式覆盖。

ButtonTip 同时修复了原实现的生命周期问题：卸载时释放 ResizeObserver，按实际文本溢出判定提示，点击只关闭自身提示。按钮显式使用 `type="button"`，不会误提交所在表单。
