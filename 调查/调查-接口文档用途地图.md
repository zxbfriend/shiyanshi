# 调查：docs/接口文档 用途地图

> 调查日期：2026-11-04　范围：`docs/接口文档/` 全目录 421 个文件
> 性质：只读分析，未修改客户文档、代码或配置。本目录依 AGENTS.md §5 属客户提供只读材料。
> 统计：421 文件 = 子目录 406 + 根目录 15；其中 Zebra 打印机 SDK 344 个（含 270 个 html），其余 77 个。

## 0. 结论摘要

1. **目录不是一份统一的"接口文档"**，而是 5 类材料混装：①厂商二进制 SDK（Zebra 打印机，占 344/421）②旧系统本地服务/设备通讯整理稿 ③外部平台接口文档（SDMS、Innovel/CCPD、NPP、LDMS、Inno、AAD）④旧系统数据库导出（cdp/npp/IV_CDP_16）⑤项目自研方案稿（补料调度统一方案）。
2. **284 个 html 的真实构成**：270 个是 Zebra 官方 javadoc 自动生成物（`documentation/` 下的 `class-use/`、`*-index.js`、`stylesheet.css` 为证据），14 个是中文手写分析页（`lang="zh-CN"` + 内联 CSS + 无 generator 标记）。
3. **可作实现依据的只有少数**：外部平台接口文档（NamedPipe、SDMS、NPP/CCPD、LDMS、Inno）与厂商设备手册；大量 md/html 是对旧系统反编译或前端源码的**内部整理稿**，只能作语义参考，不能当契约。
4. **重复明显**：8 组 MD5 完全相同的重复文件、1 个文件名误导的测试参数副本、2 个空占位 md、1 组 SDK 压缩包与解压目录重复。
5. **来源普遍未署名**：只有 pdf/docx 手册和 SDK 可确认厂商来源；中文 md/html 大多无作者信息，按内容风格判为内部整理，仍需标"来源待确认"。
